# 标准化评测协议 v0：感知与运动闭环

状态：调研阶段的预注册草案，未执行。目标是给第一项“局部地形/状态估计影响人形步行”的实验提供一致口径。选定机器人和baseline后，把任务常数写入配置并冻结；正式测试后不按结果改指标或挑场景。

## 1. 先固定实验问题

每版只回答一个问题，例如：增加观测mask和年龄，能否降低局部地图延迟/缺测造成的跌倒，同时保留任务进度？如转向动作模仿、操作或导航，应创建新协议版本，不沿用不适用的指标。

日志至少包含代码commit、环境/算法版本、资产校验、训练配置、checkpoint、所有种子、训练预算和评测配置。定义physics步长、policy步长、传感器周期、传输/处理时延、动作限幅和部署可用信息。

## 2. 数据与场景划分

采用训练、开发、固定测试三部分。训练随机化参数只按训练和开发结果选；测试集不能用于调奖励、挑checkpoint或估计误差分布。

- **分布内测试**：同参数范围但新的地形实例和随机种子。明确它仅检验同分布泛化。
- **分布外测试**：保留未训练的地形结构/参数区间、组合方式、误差模型或材料条件。仅换seed不能叫OOD。
- **真实数据**：按场地和采集session划分；同一次采集的相邻帧不能分别落入训练和测试。
- **动作数据**：按源序列、主体或动作类型划分，具体轴取决于主张；重定向/切片前划分，去除近重复。

建议pilot后冻结三个层次：干净输入、训练覆盖的扰动、未见扰动。地形可从平地、斜坡、台阶、不规则地形、稀疏踏点中选任务实际支持的类别。建议每类固定20个测试地图，至少3个独立训练种子；资源允许时增加种子。上述数量为建议配置，正式实验须记录最终采用值及原因，不能在看到结果后增删困难类别。

任务常数（选定baseline时必须填写到配置）：目标位置/距离、最大时长、初态分布、允许命令、到达容差、非足接触规则、跌倒阈值、可接受速度区间、随机扰动范围。没有这些常数，不进入正式结果表。

## 3. 必须同时报告的指标

| 维度 | 指标和计算口径 | 为什么需要 |
|---|---|---|
| 任务 | 成功率：在固定时限完成目标且未违反终止条件的episode占比 | 不把一直站着算成功 |
| 失败 | 跌倒率、碰撞率、超时/停滞率，分开统计并说明可否重叠 | 成功失败有不同原因 |
| 效率 | 成功episode报告完成时间；全部episode报告进度、实际终止时长和失败类型 | 防止只在幸存轨迹上算好看的效率 |
| 跟踪 | 机体系线速度RMSE、偏航角速度RMSE；仿真用真值，实机用独立参考测量并报告参考误差；记录评测区间 | 不让降低命令速度成为隐藏变量 |
| 接触 | 踏空、脚底支撑比例、接触滑移；定义接触判定与阈值 | 人形面足不能只看脚中心 |
| 动作 | 动作变化、关节/力矩限制触发率 | 检查是否靠不现实动作获得收益 |
| 感知 | 高程/速度误差、落脚附近误差、缺测率、置信度校准 | 地图整体RMSE不足以解释控制 |
| 时序 | 传感器到动作的观测年龄、处理/推理耗时、p50/p95、丢帧 | 平均推理耗时不能代表闭环延迟 |
| 成本 | 环境交互步数、wall-clock、硬件、峰值显存、网络参数 | 区分算法改善与额外资源 |

若报告机械功率，可计算正机械功积分或绝对机械功积分，但必须注明定义；它们不能未经验证直接叫电能。若计算CoT，说明质量、重力、行进距离、分母接近零时的处理，并把停滞episode单列，避免除零和幸存偏差。

## 4. 必须的参照与消融

1. 所选官方运动baseline，明确其本体/外感知输入，保持原训练设置并记录必要改动。地图扰动实验要求原策略已有地图输入；额外纯本体对照单独定义和训练。
2. 真值状态/真值地图作为诊断参照。额外信息一般有利，但该实验数值不是严格数学上界。
3. 受扰动输入的相同baseline。
4. 简单工程对照：mask、观测年龄、保守边缘收缩、增大历史窗口或训练随机化，按研究问题选择。
5. 提议方法，及移除/打乱关键特征的消融；控制模型容量、数据、传感器和预算。

**固定策略实验**回答输入错误是否导致失败；**分别重训实验**回答该输入表示是否支持更好的策略。两者必须分表，不能把一个策略的分布外掉点当成另一方法普遍更优的证据。真值供critic/teacher使用与供部署actor使用也必须分清。

控制指标不能使用被研究或已注入误差的速度估计作为唯一参考。感知延迟实验使用已发生的旧观测，不能通过未来真值插值“补偿”；滤波器使用真实可用的历史。数据归一化参数来自训练集，评测时固定。记录同一数据在各模块的坐标系和时戳。

## 5. 统计与可视化

对各训练种子分别报告指标，再汇总均值和离散程度；任务成功率同时报告样本量和区间估计。不要将同一策略的大量episode当作大量独立训练种子。使用bootstrap时按训练种子/地图适当分层，注明采样单位；配对测试尽可能使用相同地图、初态和扰动实现。

必须输出：学习曲线；按地形/扰动拆分的结果；误差或延迟强度—成功率曲线；感知误差与接触/动作时序；固定5–10个失败案例。保留同一组回放用于跨版本对比，另记录新失败，不只挑漂亮视频。
