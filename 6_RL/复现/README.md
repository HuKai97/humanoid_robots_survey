# 复现计划

状态：尚未开始，2026-09-29。本轮只有文献调研与准备，没有安装、下载权重或运行训练。

## 先选最小闭环

| 阶段 | 任务 | 选择依据 | 验收 |
|---|---|---|---|
| B0 | Gymnasium连续控制小任务 + PPO | 学会观察、动作、优势、更新与评测 | 能解释一次更新；多次运行结果与视频 |
| B1 | 官方人形或足式本体步行baseline | 优先有完整训练代码、匹配机器条件的任务 | 从回放到重新训练；观测/动作/频率表 |
| B2 | 加入局部地形观测或状态估计 | 复用B1，减少同时改变的变量 | 真值、受扰动、可部署估计三类对照 |
| B3 | 验证一个感知交叉假设 | 从B2的失败案例提出 | 固定测试集、消融、负结果与成本 |

候选B1包括Humanoid-Gym、Isaac Lab已有相应人形任务或MuJoCo Playground的G1任务；最终只能在确认硬件、传感器需求、论文配置与代码开放程度后选定。不能因项目页展示效果好就跳过环境审计。工具来源见[资源选择](../related_work/05_资源与复现选择.md)。

## 每个baseline先填写

- 官方仓库URL、commit、论文版本、LICENSE、下载时间。
- OS、Python、CUDA/驱动、torch/JAX、simulator、算法库版本。
- 机器人资产、关节顺序、执行器模型、动作尺度、限幅、PD参数。
- physics timestep、policy timestep、decimation、传感器更新时间与时戳语义。
- actor与critic观测列表、历史长度、归一化、reset和timeout处理。
- 奖励每项、终止条件、课程、域随机化与种子。
- 代码、资产、数据、权重的可获得性分别记录；缺少者不能假装齐全。

## 先检查中间过程

站姿和单关节控制 → 坐标系/重力方向 → 命令与动作对应 → 接触和奖励分项 → 正常重置与时间截断 → checkpoint和归一化加载 → 训练/评测分离。

论文数字仅记在“作者报告”栏；自己未运行的表格留空。对失效或无法复现的配置保留原因，不只保存最成功seed。

## 复现报告格式

在 `复现/<方法>/复现报告.md` 记录目标、作者设置、实际设置、不同之处、运行命令、日志/视频位置、标准化评测、未解决问题与结论。报告应写清达到R0回放、R1训练还是R2感知闭环；定义见[资源文档](../related_work/05_资源与复现选择.md)。
