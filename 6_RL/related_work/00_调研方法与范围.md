# 调研方法与范围

调研日期：2026-09-29。目标读者：具备传统机器人感知经验、希望进入人形机器人强化学习的研究者。本轮是有范围的代表性调研，不是穷尽检索，也不声称覆盖该日期前所有工作。

## 怎样使用 research-workflow

已阅读上游 [README](https://github.com/skJack/research-workflow)、[SKILL.md](https://github.com/skJack/research-workflow/blob/main/SKILL.md)、初始化脚本与六份文档模板。保留它的目录职责、进度交接、先复现再凝练问题、结果只追加、预先固定评测等原则。本地内容是面向本课题重新编写的中文文档，并未安装这个 skill 或运行远程脚本。

| 上游安排 | 本项目处理 | 原因 |
|---|---|---|
| 询问项目名、目标、术语 | 用用户已给出的方向和背景命名；投稿和deadline标待定 | 入门调研已有足够上下文 |
| `related_work/` 中论文PDF和源码 | `papers/` 中中文解析，保存论文/项目/代码链接 | 用户明确要求不下载论文 |
| 先复现、再提假设 | 本轮交付复现计划和“待验证候选假设” | 调研不等于已执行复现 |
| `experiment/results.md` | 保留空结果表并标注尚无实验 | 避免把计划和作者数字写成我们的成绩 |
| 评测规范、数据说明和handoff | 均建立并填入当前已知信息 | 下次可以接续学习和复现 |

## 文献选择

按三个分支选取：F为算法和足式控制基础，H为人形全身控制和模仿，P为感知、估计与运动控制。重视方法影响、对初学者的解释价值、官方材料可核验性、对传统感知的连接价值；未以引用量或GitHub星数排序。

检索包括：`humanoid reinforcement learning locomotion`、`humanoid whole-body motion tracking`、`perceptive humanoid parkour depth elevation map`、`legged state estimation reinforcement learning`、`teacher student sim-to-real`，以及论文精确标题、作者项目页和官方仓库。先检索原论文摘要/HTML，再交叉查看作者项目页与仓库；只使用可访问的一手来源支持技术结论。工具的搜索摘要仅用于发现线索。

“最新”需谨慎：网页抓取会延迟，arXiv无版本链接会更新，代码主分支与论文提交版可能不同。每篇保留核验日期和版本信息；2025–2026材料视证据标为预印本/项目公开，不由年份推断同行评审状态。

## 证据等级

- **A**：阅读了论文全文HTML中的相关方法/实验部分，并结合作者材料。仍未核验全部补充材料，也没有复现作者数字。
- **B**：论文摘要加作者项目页/官方仓库；方法解读受这些材料约束，不能写成全文精读。
- **C**：主要只能获得摘要；只能做概览，不作细粒度设计或性能判断。

具体卡片说明实际阅读范围，可能使用A/B混合标签。阅读全文不代表证实所有主张；“作者报告”不等于本地验证。图像不可见、HTML转换缺失或仓库未开放之处明确保留限制。

## 比较边界

不把不同机器人、地形、控制频率、传感器和训练预算的成功率直接排成名次。不把动画人体等同于人形实机，不把四足sim-to-real等同于人形sim-to-real，不把动作先验等同于环境感知，不把轨迹跟踪等同于导航，更不把RL与所有模仿学习混用。

本轮未下载PDF、LaTeX、数据、权重或论文代码；未安装仿真环境、运行训练或接入实机。`metadata/`与`references.bib`用于检索管理；正式投稿前仍应核对作者列表、发表版本、会议和BibTeX。

## 之后怎样更新

新增论文先查是否是既有arXiv的版本更新；沿用卡片模板写证据范围；添加元数据；更新矩阵和阅读顺序。每月可按上述关键词补检一次；只有复现揭示具体失败模式后，才把候选方向升级为课题主张。
