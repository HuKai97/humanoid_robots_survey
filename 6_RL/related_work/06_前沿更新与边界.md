# 前沿更新与证据边界

检索截止：**2026-09-29**。本文件是本轮调研中人形全身控制分支的补充，不是覆盖所有 2026 年论文的系统综述。详细解析见 [H01–H08 元数据](metadata/humanoid.json)，2026 年感知与动态技能组合前沿另见 [P08：Perceptive Humanoid Parkour](papers/P08_Perceptive_Humanoid_Parkour.md)；没有下载论文、源码、模型或训练数据，也没有执行复现。

## 已核验的推进路线

| 关注的问题 | 代表工作 | 阅读时抓住的变化 |
|---|---|---|
| 只有本体传感能否稳定走路 | [Humanoid Transformer](papers/H02_Humanoid_Transformer.md)、[Humanoid-Gym](papers/H03_Humanoid_Gym.md) | 历史观测、特权训练、随机化、可部署接口 |
| 人体动作如何跨形态执行 | [H2O](papers/H01_H2O.md)、[ExBody](papers/H05_ExBody.md) | 动作筛选与重定向；精确跟踪和稳健行走之间的任务取舍 |
| 从遥操作走向视觉自主技能 | [HumanPlus](papers/H04_HumanPlus.md) | RL 底层提供执行能力，视觉行为克隆负责具体任务 |
| 敏捷动作怎样减小现实差异 | [ASAP](papers/H06_ASAP.md) | 用真实轨迹校正模拟器，再在仿真微调 |
| 多个动作怎样形成可调度能力 | [BeyondMimic](papers/H07_BeyondMimic.md) | 跟踪管线加状态—动作扩散，测试时通过目标代价引导 |
| 感知如何串接动态全身技能（2026） | [Perceptive Humanoid Parkour](papers/P08_Perceptive_Humanoid_Parkour.md) | 动作匹配、专家技能与深度感知学生的组合；详见 P08 的证据与开源边界 |
| 运动能力能否随数据和算力扩展 | [SONIC](papers/H08_SONIC.md) | 通用运动 token 与多种上层输入，共享低层控制器 |

这不是严格线性替代关系。比如外部视觉导航、无视觉平衡、视频动作模仿和物体操作解决不同问题，后出的工作不自动在所有指标上胜过早期基线。

## SONIC：2025 论文与 2026 工程发布要分开

论文于 2025-11-11 首发。截止本轮访问，官方仓库记录：2026-02-19 发布 GEAR-SONIC 权重与部署栈；2026-04-10 发布训练代码；2026-06-16 发布减少参考前瞻的低延迟 checkpoint。因此“只开源推理”或“训练代码尚未发布”已不是本轮可支持的描述。这些是软件与模型发布，不是新增的 2026 论文。[论文](https://arxiv.org/abs/2511.07820) · [官方发布记录](https://github.com/NVlabs/GR00T-WholeBodyControl)

公开训练指南提供评估、微调和从头训练路径，并明确完整规模训练需要大量算力。对初学者更实际的是先理解输入输出、评估现有模型或缩小动作集。官方模型卡中不同版本的参考前瞻不等于总系统延迟，且编码器、解码器和观测配置需要匹配。[训练指南](https://nvlabs.github.io/GR00T-WholeBodyControl/user_guide/training.html) · [模型卡](https://huggingface.co/nvidia/GEAR-SONIC)

## 这轮特别核对的误读

1. **论文换题名不等于新工作。** arXiv:2303.03381 的 v1 为 Learning Humanoid Locomotion with Transformers，v2 为 Real-World Humanoid Locomotion with Reinforcement Learning。本库只计为 H02 一条。[版本记录](https://arxiv.org/abs/2303.03381)
2. **单 RGB 遥操作不等于完全不需要外部定位。** H2O 以 RGB 估计操作者动作，但原文使用动捕估计机器人线速度。[H2O §VI-B](https://arxiv.org/html/2403.04436v1#S6.SS2)
3. **策略不需要里程计不等于数据采集不需要。** ASAP 最终 actor 使用本体状态和相位，真实校准轨迹采集仍用动捕。完整流程使用了真实交互数据。[ASAP §II–III](https://arxiv.org/html/2502.01143v1)
4. **避障演示不等于视觉避障。** BeyondMimic 项目明确标注动捕提供航点、障碍位置并辅助状态估计；用 VIO/LIO 和地图替代它是需要实测的扩展。[官方说明](https://beyondmimic.github.io/)
5. **系统里用了 RL 不等于每一层都由 RL 学得。** HumanPlus 上层主要是行为克隆，BeyondMimic 还包含扩散学习；每层数据、损失与部署接口要分别列明。[HumanPlus](https://humanoid-ai.github.io/) · [BeyondMimic](https://beyondmimic.github.io/)
6. **开源不等于全文已复现。** BeyondMimic 官方仓库明确主要覆盖 tracking；本轮所有“复现重点”均是计划，不是本地实验结果。[仓库范围](https://github.com/HybridRobotics/whole_body_tracking)

## 对感知研究者的判断

我们基于这些已核验接口的判断是：感知不会因为底层策略变强而消失，任务反而更明确了。人形需要把动作目标放到正确的坐标和时间上，需要判断脚下是否可通行、手旁是否可接触，也需要知道感知什么时候不可靠。一个可控的初始研究范围是先固定成熟运动策略权重，测试现有输入的误差敏感性；若增加几何或置信度通道，再固定任务、骨干与预算分别重训，检验闭环表现能否提升。

这仍然是候选问题，不能直接宣称新颖。后续检索应沿“estimation-aware control / uncertainty-aware locomotion / perceptive humanoid / contact-aware retargeting / global motion tracking”展开，逐项比较最近工作、真实传感器条件和部署限制。至少把感知指标与机器人任务指标放在同一张表里，避免仅用离线精度论证控制收益。
