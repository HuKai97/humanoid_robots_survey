# 术语速查

| 术语 | 中文与直觉 | 容易混淆之处 |
|---|---|---|
| RL | 强化学习，通过交互优化长期回报 | 不是所有机器人神经网络都是RL |
| MDP / POMDP | 马尔可夫决策过程 / 部分可观测版本 | 传感器观测通常不包含完整物理状态 |
| policy / actor | 策略，产生动作的模块 | 有的输出高层命令，有的输出关节目标 |
| critic / value | 评估长期收益的模块 | 通常是训练辅助，不等于外部评价员 |
| reward / return | 单步奖励 / 累积回报 | 回报提高不保证真实任务成功率提高 |
| advantage | 相对当前状态平均水平的动作好坏 | 不是立即奖励 |
| PPO | 常用的策略优化算法 | 不是机器人模型，也不是安全保证 |
| GAE | 广义优势估计 | 调节偏差与方差，不修复仿真模型 |
| on-policy / off-policy | 使用当前附近策略的数据 / 可用其他行为策略数据 | 区别于在线部署和离线部署 |
| proprioception | 本体感知，如关节和IMU | 并非机体线速度一定可直接测量 |
| exteroception | 外感知，如相机、LiDAR | 导航、落脚和操作需要的信息不同 |
| privileged information | 训练时可见、部署不可得的额外信息 | 必须查其是否泄漏到actor |
| asymmetric actor–critic | actor与critic观测不同 | 不必存在两阶段teacher–student |
| teacher–student / distillation | 教师—学生与蒸馏 | 可是行为克隆，不自动等于RL |
| domain randomization | 训练时随机化动力学/传感器/环境 | 随机化范围越大不一定越好 |
| system identification | 系统辨识，估计物理/执行器参数 | 与估计瞬时机器人状态不同 |
| sim-to-real / sim-to-sim | 仿真到实机 / 一个仿真器到另一个 | 后者成功不能替代前者 |
| BC | 行为克隆，拟合示范动作 | 受分布偏移影响，不直接优化交互回报 |
| DAgger | 通过策略访问的状态聚合专家标注 | 需要能查询专家，不能凭空获得标签 |
| motion tracking | 跟踪参考动作 | 不表示可以自主决定去哪里 |
| retargeting | 将人体/其他骨架动作重定向到机器人 | 运动学可行不等于动力学可行 |
| AMP | 对抗式动作先验 | 判别器风格奖励不同于逐时刻轨迹跟踪 |
| whole-body control | 全身协调控制 | 既可指优化控制，也可指学习控制 |
| elevation map | 局部高程图，常以二维网格存高度 | 多层/悬空结构可能不能单值表达 |
| occupancy / ESDF | 占据 / 欧氏有符号距离场 | 计算和存储成本不同于高程图 |
| latency / age of information | 处理传输延迟 / 当前使用观测的年龄 | 网络推理耗时不等于总闭环延迟 |
| OOD | 分布外 | 应说明地形、传感器或动力学哪一维变化 |
| oracle | 使用额外真值的诊断参照 | 不是可部署baseline，也未必是严格数学上界 |

基础定义参照[RL概念教程](https://spinningup.openai.com/en/latest/spinningup/rl_intro.html)；机器人特定用法应结合[逐篇文献](02_论文对比矩阵.md)的观测、动作和部署说明阅读。
