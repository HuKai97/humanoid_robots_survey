# H05 · ExBody：哪些人体动作必须跟，哪些可以放松

- **论文**：Expressive Whole-Body Control for Humanoid Robots，Xuxin Cheng、Yandong Ji、Junming Chen、Ruihan Yang、Ge Yang、Xiaolong Wang。
- **时间 / 平台**：2024-02-26 首发；RSS 2024；Unitree H1，19 自由度。
- **类别 / 优先级**：RL 全身控制、部分身体模仿；P1，理解任务分解的代表。
- **证据深度**：A；v1 HTML、项目页、官方仓库已核验；未下载论文、未执行代码。访问日期：2026-09-29。

## 一分钟总结

ExBody 的核心是**上身模仿动作，下身优先保证可行行走**。当人和机器人形态不同，强迫每一个腿部关节都精确复制人类，反而可能更不稳。它用一个全身 RL 策略同时满足上肢表达与根部运动要求，展示走路挥手、舞蹈等动作。[项目页](https://expressive-humanoid.github.io/)

## 详细介绍：问题与方法

动画领域的人体模型常有更多自由度，且可使用真实硬件不具备的控制能力。论文将目标拆成上身表达与根部运动：前者包含上身关节及肩、肘、手关键点，后者描述速度、姿态和高度等根部命令；腿部不强制逐帧复制人类关节角。它采用动作数据中的状态初始化，使训练尽早接触有意义的姿态组合。[问题定义](https://arxiv.org/html/2402.16796v1#S2)

| 项目 | 已核验的设计 |
|---|---|
| Observation | 根部角速度、roll/pitch、航向误差、关节位置/速度、上一动作及目标；实机策略不读取真实线速度和绝对高度 |
| Action | 19 维关节 PD 目标 |
| Reward | 上身关节/关键点跟踪，根部运动跟踪，加控制正则 |
| Training | 人体动作重定向、参考状态初始化、随机化仿真训练 |
| Deployment | 本体反馈加表达/移动目标；移动命令可由操作者给出 |

“全身控制”在此意味着控制全身保持协同，不意味着逐关节全身复制。CMU 动作数据也不是带机器人动作标签的行为克隆数据；这里用其定义目标和回报。[方法](https://arxiv.org/html/2402.16796v1#S3)

## 证据与局限

项目提供 H1 真机表达动作、人与机器人互动和不同地面行走展示。论文比较了全身强跟踪、不同数据初始化等设计；其结论支持当前平台和任务上的约束放松，不是证明腿部精确跟踪在所有应用都不需要。[项目与对比](https://expressive-humanoid.github.io/)

官方实现公开重定向、训练和模型导出流程，训练配置入口包括 `h1_mimic_config.py`。复现时可以从目标定义与 reward scale 入手，而不用先理解所有数据处理脚本。[官方代码](https://github.com/chengxuxin/expressive-humanoid)

限制很具体：表达动作不是接触丰富的操作任务；在没有环境几何反馈时，挥手轨迹不能自动保证避障。论文的数据筛选也排除了部分环境交互动作。要做搬物、扶栏、精准落脚，仍需补充相应约束和评测。[数据与讨论](https://arxiv.org/html/2402.16796v1)

## 与传统感知的关系

研究建议：根据地形/接触风险决定哪些目标必须严格执行。例如在平地放松腿部模仿，在踏石上要求感知给出的可落脚区域；手靠近障碍时增加距离场约束。新意不能只是把高度图接到网络，而应验证“感知何时改变约束”比始终强跟踪、始终放松、简单切换三种基线更好。

你的几何经验可以用于坐标系与可达性判断。还要检验感知错误时切换是否来回振荡、脚步与上肢任务是否冲突；这里的候选方向尚未完成新颖性排查。

## 阅读 / 复现重点

先画出表达目标与根部目标，然后对照 full-body tracking 消融。最小实验固定一条上身动作，改变移动速度与地面；分别记录上肢误差、跌倒率和速度跟踪，不能只看总 reward。后续 ExBody2 是另一篇工作，不应把它的全身精细跟踪能力算到本篇。
