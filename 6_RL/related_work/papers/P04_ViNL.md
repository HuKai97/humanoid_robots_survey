# P04｜ViNL: Visual Navigation and Locomotion Over Obstacles

> Kareer、Yokoyama、Batra、Ha、Truong；arXiv 2022，ICRA 2023；AlienGo 四足实机。优先级：选读，导航背景优先。证据 A：论文 HTML＋官方代码 README。访问：2026-09-29。

## 一分钟总结

正式题名是“Over Obstacles”，不是“Over Rough Terrain”。它将视觉导航和视觉运动控制组合起来，使机器人在室内到达目标时跨过小杂物。核心认识是：导航避障和足部避障并不等价，小物体可以跨过，大物体需要绕行。[论文摘要](https://arxiv.org/abs/2210.14791)

## 详细机制与输入输出

| 项目 | 本文设置 |
|---|---|
| 传感器/表示 | 两个不同俯仰角的深度相机；视觉与本体结合，时序网络保留局部信息 |
| 导航层 | 深度、目标相对距离/方向；输出前向和转向速度 |
| 运动层 | 本体状态、速度命令及地形表示；输出关节位置目标给 PD |
| 奖励 | 导航鼓励路径效率并减少碰撞；运动跟踪命令并保持步态 |
| 训练 | 先训基础运动，再适应杂物，最后学习用深度预测特权地图的编码 |

导航在 Habitat 学习，运动在 Isaac 中学习；官方仓库明确区分这两个子系统。因此这不是一个从导航目标直接联合优化全部关节的单网络方法。[官方代码与结构说明](https://github.com/SimarKareer/ViNL)

最后阶段固定运动策略，用带时序的视觉模块预测它需要的地形特征。记忆有具体用途：物体经过前向相机后进入脚下盲区，后腿仍需知道它在哪里。训练时的特权地图并不等于部署时具备完整真值地图。[论文 HTML：第 III 节](https://arxiv.org/html/2210.14791)

## 对传统导航经验的启发

以下是我们的解释：你可以把导航和运动之间的速度接口当成调试切口。先确认“想走哪里”合理，再确认“身体能否跟上”。若系统绕不过椅子，可能是局部地图、目标选择或速度跟踪的问题；只报最终导航成功率无法定位责任。

一个实用的研究方向是让导航代价感知到底层能力，例如同样的高度，在低速、快速或携带负载时具有不同风险。还可以把动作执行误差反馈给上层，使导航知道期望位移与真实位移的偏差。不过这些是我们基于论文组织方式提出的延伸，不是本文已经验证的结论。

## 证据边界与人形迁移

论文任务偏向室内小杂物；不能据此推出极限跑酷性能。导航训练与真实动态运动之间还存在姿态抖动、接触及定位误差。目标相对位置来自自运动估计，不应将“视觉导航”理解为完全不需要定位信息。

人形有更高相机视点、不同脚下盲区和更窄的通行姿态。建议保留高层目标定义，重新训练下层，并重估可跨越物体范围。另需区分“不能踩的障碍”与“可以踩的踏脚石”，相同几何对象在任务中可能具有相反标签。

## 可复用技能与复现重点

你已有的视觉里程计、目标相对坐标、地图更新及导航评测经验非常契合。本轮已确认官方代码可访问，但未测试安装；仓库采用历史版本仿真依赖，不应机械执行 README 后期待兼容当代软件栈。

最小评测建议同时报告到达率、路径效率、脚部碰撞次数及速度跟踪误差，并按房间布局划分训练/测试。先复现固定速度命令的杂物跨越，再接导航。我们的候选消融是关闭视觉记忆、增加定位延迟、改变上/下相机视野，以区分长期导航与短期接触记忆各自的贡献。
