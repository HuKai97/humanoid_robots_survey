# F07 · 学习敏捷运动：sim-to-real 不只靠随机化

- **论文**：Learning agile and dynamic motor skills for legged robots。
- **作者 / 年份**：Jemin Hwangbo, Joonho Lee, Alexey Dosovitskiy, Dario Bellicoso, Vassilios Tsounis, Vladlen Koltun, Marco Hutter；Science Robotics 4(26), eaau5872，2019。
- **类别 / 平台**：学习执行器模型 + RL + sim-to-real；ANYmal **四足实机**。
- **优先级 / 核验**：P1；2026-09-29；证据 A（原论文 HTML 含方法/补充章节、ETH 官方记录）。[论文记录](https://arxiv.org/abs/1901.08652) · [ETH 收录](https://www.research-collection.ethz.ch/items/63b8fb50-299f-4995-bd1d-63a9f2b7ba75)

## 一分钟总结

这篇展示了仿真里训练的神经网络策略如何控制真实 ANYmal 跟踪速度、快速运动和跌倒恢复。重要思想是把可信的刚体模型与从真机数据学到的 actuator network 组合：后者模拟执行器及底层软件的真实响应，再配合随机化训练控制策略。RL 不会自动让仿真变真实；关键误差源需要被识别和处理。[原论文 §Introduction、Method](https://ar5iv.labs.arxiv.org/html/1901.08652)

## 为什么重要，方法如何分工

理想 PD 或瞬时力矩模型可能忽略弹性、延迟和底层闭环。作者先在真实系统收集执行器数据，用监督学习拟合指令/历史到实际力矩的映射，再把这个网络放进仿真动力学环路。控制策略本身通过 **TRPO** 训练；不要因后来足式系统普遍使用 PPO，就把本文也写成 PPO。[原论文 Method](https://ar5iv.labs.arxiv.org/html/1901.08652)

这里有两种网络、两种学习目标：actuator network 预测真实执行器输出，policy 决定为任务选择什么指令。前者属于数据驱动系统辨识，后者才是 RL 控制。真机数据用于建模，不等于在真机上通过 RL 探索学会跑步。

## 观测、动作与训练部署

| 项目 | 原文设计 |
|---|---|
| observation | 重力方向、机体状态估计、关节角/速度、短期关节历史、上一动作与指令；起身任务移除不适用的高度观测 |
| action | 关节位置目标；仿真中通过执行器网络得到力矩 |
| reward | 按任务设置速度跟踪、力矩、关节运动、足滑、姿态等成本；恢复任务另有设计 |
| train | 刚体与接触仿真 + 学习执行器；TRPO、课程和随机化 |
| deploy | 输入真实可测/可估状态，策略输出位置指令交给硬件执行器 |
| sim-to-real | 提高执行器模型真实性，同时处理物理参数与观测误差 |

详见 [原论文 Observation and action、Training in simulation 与补充成本项](https://ar5iv.labs.arxiv.org/html/1901.08652)。执行器网络不应误当成部署时替代真实电机的控制层。

## 证据与局限

论文包括实机技能及不同执行器模型的比较，说明建模质量会影响迁移。作者也明确指出：奖励、初始状态与建模仍需专业知识，不同技能不是自动整合为一个通用控制器。执行器间存在强耦合时，逐关节独立拟合也可能不够。对人形的启发是方法论；本文没有验证高自由度人形全身接触。

## 与传统感知的关联

**调研推断**：你已有的系统辨识、时间同步、滤波和误差分析能力可以直接迁移。特别是论文根据可观性选择观测，并对起身任务删除不合适的高度估计，说明“更多状态”未必更可靠。可将状态估计残差与控制失败联系起来，区分感知误差、执行器误差和策略不足，再针对最大误差源提出方法。
