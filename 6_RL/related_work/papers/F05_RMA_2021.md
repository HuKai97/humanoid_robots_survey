# F05 · RMA：从本体历史里推断“现在的环境变了”

- **论文**：RMA: Rapid Motor Adaptation for Legged Robots。
- **作者 / 年份**：Ashish Kumar, Zipeng Fu, Deepak Pathak, Jitendra Malik；RSS 2021。
- **类别 / 平台**：特权信息训练、在线潜变量估计、sim-to-real；Unitree A1 **四足实机**，不是人形实验。
- **优先级 / 核验**：P1；2026-09-29；证据 A（原论文 HTML、作者项目、项目所链接代码）。[论文记录](https://arxiv.org/abs/2107.04034) · [项目](https://ashish-kmr.github.io/rma-legged-robots/)

## 一分钟总结

RMA 先让仿真策略知道地面摩擦、载荷等“答案”，并把这些环境信息压缩成潜变量；再训练一个模块，从机器人近期状态和动作历史中预测该潜变量。真机上靠历史推断环境变化，无需在线重新优化网络权重。这是从传统状态估计转入学习控制时非常值得读的连接点。[原论文 §I、§III](https://ar5iv.labs.arxiv.org/html/2107.04034)

## 两阶段方法及其直觉

第一阶段，环境编码器把仿真可知的摩擦、质量分布、电机强度、地形等因素编码成 z，基础策略以 z 和当前状态、上一动作作为输入，使用 RL 学行走。第二阶段，冻结基础策略与编码器，训练 adaptation module 从状态—动作历史预测 z。历史由正在使用预测潜变量的策略产生，能覆盖估计不准确造成的偏离。[原论文 §III-A/B](https://ar5iv.labs.arxiv.org/html/2107.04034)

直觉是：同样的关节指令在重载、打滑或不同地面上产生不同响应，历史里含有环境变化的信息。潜变量服务控制，不必逐个准确恢复可解释物理参数；不能直接把其某一维叫“摩擦系数”。

## 输入输出、奖励与部署

| 项目 | 原文设计 |
|---|---|
| observation | 关节角/速度、躯干 roll/pitch、足接触指示，以及上一动作和环境潜变量 |
| action | 12 个关节的目标位置，经 A1 PD 控制器转为力矩 |
| reward | 前进、少侧移与转动，加功耗、冲击、平滑性、滑动等惩罚 |
| train | RaiSim 中训练基础策略；用监督学习训练历史到潜变量的适应模块 |
| deploy | 两模块异步运行；作者系统中基础策略 100 Hz，适应模块 10 Hz |
| sim-to-real | 环境随机化、地形多样性、可部署本体输入和历史适应联合使用 |

具体接口与频率来自 [原论文 §III–IV](https://ar5iv.labs.arxiv.org/html/2107.04034)，不是对所有 RMA 实现的默认配置。

## 证据与边界

作者展示 A1 在不同地面、载荷和扰动下的实机结果，并比较无适应模块等基线；项目材料支持其零真机微调部署主张。[作者实验页](https://ashish-kmr.github.io/rma-legged-robots/)

它依靠接触后的反馈进行适应，没有视觉提供前方障碍预见。可辨识性、训练随机化覆盖和估计延迟仍会限制性能；A1 的成功不能直接推出高重心、单脚支撑的人形同样稳定。历史推断也不等于不再需要姿态与接触测量。

## 与传统感知的重叠

**研究推断**：把几何地图和视觉材质信息作为前馈，把本体历史作为反馈，可研究接触前预测与接触后校正怎样融合。另一方向是估计潜变量不确定性，让控制器知道何时不应过信当前估计。必须比较纯本体 RMA、纯视觉、融合及故意失真视觉，并按场景划分，避免只证明多一个网络参数有用。

## 阅读与复现检查

建议在 [F06 并行训练](F06_Massively_Parallel_2021_2022.md) 后精读。检查特权量是否泄漏到部署 actor、历史窗口是否按实际时间对齐、reset 后缓存是否清空，以及“适应”是否只是前向推理。
