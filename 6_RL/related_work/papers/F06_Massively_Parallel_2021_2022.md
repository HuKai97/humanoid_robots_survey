# F06 · 并行 RL：理解现代足式机器人训练框架的骨架

- **论文**：Learning to Walk in Minutes Using Massively Parallel Deep Reinforcement Learning。
- **作者 / 年份**：Nikita Rudin, David Hoeller, Philipp Reist, Marco Hutter；2021 预印本 / CoRL 2021，PMLR 论文集于 2022 出版。
- **类别 / 平台**：GPU 并行训练、课程学习、sim-to-real；主要是 ANYmal C **四足实机**。
- **优先级 / 核验**：P0；2026-09-29；证据 A（原论文 HTML、出版方条目、官方代码）。[论文记录](https://arxiv.org/abs/2109.11978) · [PMLR](https://proceedings.mlr.press/v164/rudin22a.html)

## 一分钟总结

这篇不靠另造一个 RL 算法，而是让物理仿真、观测/奖励计算、策略推理和更新尽量留在 GPU，用大量并行机器人快速学习。它还解释了并行规模、轨迹长度、超时处理及地形课程为什么一起影响结果，是读 legged_gym 风格代码的入口。作者报告平地少于 4 分钟、复杂地形约 20 分钟；这是原实验设置中的结果，不是你机器上的耗时承诺。[出版方摘要](https://proceedings.mlr.press/v164/rudin22a.html)

## 方法：快不只是机器人数量多

PPO 每次更新的数据量可写作“环境数 × 每环境步数”。增加环境数时，不能无限缩短每条轨迹，否则会损害 GAE 使用的时间信息。论文还区分跌倒终止和时间上限截断，后者需处理 critic 的 bootstrap。地形被分成难度等级：完成得好进入更难地形，表现差退回较容易地形，避免全部机器人始终停在同一难度。[原论文 §2–3](https://ar5iv.labs.arxiv.org/html/2109.11978)

## 控制接口与迁移

| 项目 | 原文设计 |
|---|---|
| observation | 机体线/角速度、重力方向、关节位置/速度、上一动作，周围地形高度采样及指令 |
| action | 关节目标位置，低层 PD 生成力矩 |
| reward | 速度跟踪为主，配合非期望运动、力矩、关节运动、动作变化和碰撞等项 |
| train | Isaac Gym 中 GPU 并行仿真和 PPO，地形课程 |
| deploy | 策略接入真实状态与地形估计，再通过低层执行器控制 |
| sim-to-real | 摩擦随机化、观测噪声、外力扰动；针对 ANYmal 使用学习执行器模型 |

其中执行器模型使用 LSTM 描述响应历史；这是模拟执行器的一部分，不应误读成策略本身必须是 LSTM。[原论文 §3.2–3.3](https://ar5iv.labs.arxiv.org/html/2109.11978)

## 证据与局限

论文分析并行规模与性能的关系，并把策略转移到真实 ANYmal 验证。快训练缩短了迭代周期，但没有消除奖励设计、机器人建模和部署工作，也没有证明四足配置可直接复制到双足。地形高度来自可靠估计这一接口条件尤其重要：训练输入的高度采样，与真实点云建图并不是同一个工程问题。

## 与感知经验的连接

**研究推断**：你可先保留现成策略与奖励，建立从深度/激光到局部高度图的稳定接口，集中测量定位漂移、时延、遮挡和地图置信度对跌倒率的影响。这比同时修改 RL 算法和感知更容易识别贡献。将训练中的独立随机噪声换成依据实测残差构建的相关误差模型，是可检验的候选方向，但新颖性仍需继续查文献。
