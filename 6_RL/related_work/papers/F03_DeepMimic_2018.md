# F03 · DeepMimic：从动作参考到物理可执行的模仿

- **论文**：DeepMimic: Example-Guided Deep Reinforcement Learning of Physics-Based Character Skills。
- **作者 / 年份**：Xue Bin Peng, Pieter Abbeel, Sergey Levine, Michiel van de Panne；ACM TOG / SIGGRAPH 2018。
- **类别 / 平台**：参考动作模仿 + RL；Bullet 中的物理仿真人体、Atlas 模型等，**没有证明 Atlas 实机完成这些技能**。
- **优先级 / 核验**：P1；2026-09-29；证据 A（原论文 HTML 的方法与实验、作者页、官方仓库）。[作者项目](https://xbpeng.github.io/projects/DeepMimic/index.html) · [论文记录](https://arxiv.org/abs/1804.02717)

## 一分钟总结

给一段动作捕捉或关键帧轨迹，让策略在物理引擎里学出能跟随参考、还能回应任务目标的控制。核心不是逐帧播放动画，而是通过关节控制产生接触与运动。它让“像人一样动”成为可优化的模仿奖励，是理解后来机器人全身动作追踪的重要起点。[作者项目](https://xbpeng.github.io/projects/DeepMimic/index.html)

## 解决什么问题，怎样解决

只奖励向前走容易得到不自然姿态；仅把参考轨迹交给普通追踪器又可能难以应对扰动。DeepMimic 把参考动作匹配与任务目标加权组合，用 PPO 训练策略。两个重要训练设计是：从参考轨迹的不同状态初始化，而不总从第一帧开始；角色明显失败时提前结束，减少在无意义状态继续采样。原文给出相关消融，而不只是展示动作视频。[原论文 §5–6](https://ar5iv.labs.arxiv.org/html/1804.02717)

## 控制接口与训练部署

| 项目 | 原文设计 |
|---|---|
| observation | 各身体连杆的相对位置、旋转、线/角速度，局部坐标表达；参考相位及任务目标 |
| action | 各关节 PD 目标姿态，由 PD 产生力矩 |
| reward | 关节姿态、速度、末端位置和质心的模仿项，再加任务项 |
| train | PPO + GAE；参考状态初始化、失败提前终止 |
| deploy | 仿真中的策略推理及 PD 执行；有任务可加入地形高度图 |
| sim-to-real | 原作没有完整真机迁移评测，不能直接据此声称可上人形硬件 |

上述接口和高度图分支见 [原论文 §3、§5](https://ar5iv.labs.arxiv.org/html/1804.02717)。

## 证据与局限

作者展示多个角色、翻转和武术等技能，以及目标条件和多技能组合。它证明了动作参考与物理控制能够结合，但参考质量、相位同步、角色形态和动作重定向仍是实际限制。真实人形还有电机限幅、延迟、足底接触、状态估计误差及机械结构约束；这些不能因为视频里有 Atlas 模型就忽略。

## 对感知研究者的价值

**调研推断**：视觉人体姿态估计可提供动作来源，但“估计出来的骨架”距离“机器人可追踪参考”还隔着尺度、坐标系、关节映射、接触一致性及动力学可行性。你的几何标定、轨迹平滑和多传感器融合能力适合改善参考质量。评价最终应同时报告追踪误差和失败率，防止平滑后看起来更好却破坏落脚时序。

另一条切入是把传统局部地形图接入策略。原文的高度图是仿真地形输入，不等同于已经解决了相机/激光到地图的真实感知链路。

在 PPO/GAE 后读本篇，再读 [F04 AMP](F04_AMP_2021.md)，比较“追踪指定参考”与“匹配动作风格分布”。复现前检查动作文件的坐标与时间单位、关节顺序、PD 增益、参考状态初始化，以及训练/测试是否使用同一参考片段。
