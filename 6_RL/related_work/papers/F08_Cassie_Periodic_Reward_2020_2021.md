# F08 · Cassie 周期奖励：不依赖动作参考也能指定双足步态

- **论文**：Sim-to-Real Learning of All Common Bipedal Gaits via Periodic Reward Composition。
- **作者 / 年份**：Jonah Siekmann, Yesh Godse, Alan Fern, Jonathan Hurst；2020 预印本，ICRA 2021。
- **类别 / 平台**：周期奖励设计、循环策略、sim-to-real；Cassie **双足实机**，不是带双臂的完整人形。
- **优先级 / 核验**：P1；2026-09-29；证据 A（原论文 HTML、作者实验室会议视频、官方仿真库）。[论文记录](https://arxiv.org/abs/2011.01387) · [实验室 ICRA 2021 介绍](https://www.youtube.com/watch?v=AISy0hxo6-0)

## 一分钟总结

这篇在“逐帧模仿参考”与“只奖励向前走”之间选择另一条路线：明确描述每只脚什么时候应摆动、什么时候应支撑，用足力和足速度的周期成本定义步态。改变左右相位差与摆动/支撑比例，可指定走、跑、跳等行为，不必提供整条关节参考轨迹。[原摘要](https://arxiv.org/abs/2011.01387)

## 方法：只规定接触结构，留给 RL 寻找具体动作

摆动期惩罚足接触力，让脚离地；支撑期惩罚足速度，让脚稳定承重。相位边界用概率分布表达并平滑过渡，训练使用奖励的确定性期望，而非每步随机抽一个奖励。左右脚相位偏移和各相位占比表达不同步态；跳步 skipping 需要更复杂的相位安排。[原论文 §III](https://ar5iv.labs.arxiv.org/html/2011.01387)

该设计保留运动自由度，却仍编码了步态知识。“无参考轨迹”不等于“无人为先验”。同时论文仍加入速度指令跟踪、姿态、动作变化、力矩及骨盆运动等辅助项。

## 控制接口与训练部署

| 项目 | 原文设计 |
|---|---|
| observation | 骨盆姿态/角速度、关节角/速度的估计，速度指令，周期时钟与相位比例 |
| action | 关节位置目标以及 P、D 增益的修正量，不只是固定增益下的目标角 |
| reward | 周期足力/足速成本 + 指令、平滑性和效率等辅助项 |
| train | MuJoCo / cassie-mujoco-sim；LSTM actor/critic、循环 PPO 与对称性相关损失 |
| deploy | 真实传感状态与指令输入循环策略，由快速 PD 层执行 |
| sim-to-real | 随机化阻尼、质量、摩擦、坡度、编码器偏移等 |

接口来自 [原论文 §IV–V](https://ar5iv.labs.arxiv.org/html/2011.01387)。循环网络内部记忆需要随 episode 正确重置。

## 结果与局限

作者展示单步态实机运动及多步态策略的连续切换。[实验室视频](https://www.youtube.com/watch?v=AISy0hxo6-0) “全部常见步态”是论文任务范围，不代表一个策略无条件掌握任意步态与复杂环境。原文讨论了同时改变相位比例和偏移时出现混合、不理想步态的训练困难；多步态结果的覆盖也应与单步态结果分开读。

Cassie 的弹性腿、足部结构和自由度影响具体实现；迁移到带上肢的人形需重新处理全身动力学和接触，并增加真实地形感知的验证。

## 与感知的交叉机会

**调研推断**：地形图、可通行性和落脚区域可用于调节高层速度与步态参数，本体策略负责稳定执行。更直接的课题是联系接触状态估计与周期奖励：有坡面、足滑或落脚误差时，计划相位不一定等于真实接触相位。可比较固定时钟、接触反馈校正和带置信度的融合，但需先确认现有相关工作，不能直接声称新颖。
