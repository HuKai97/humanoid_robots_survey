# ViT 精读问答（Q&A）

> 这些问题来自初读 `vit.md` 时的疑问，答案已与原文核对。对应解释也已融合进 `vit.md` 正文，两篇配合阅读。

## Q1. "只要数据足够大，大规模训练就能压过卷积的归纳偏置"——归纳偏置是什么意思？

**答**：**归纳偏置（inductive bias）是学习算法对"未知数据应该长什么样"的先天假设**。机器学习本质上是在有限样本上猜一个函数去解释无限可能的未知数据，没有假设就没法泛化——而"假设"就是归纳偏置。

CNN 自带两条硬编码的假设：

1. **平移等变性（translation equivariance）**：输入平移，输出跟着平移。实现方式是卷积核在整张图上滑动、权重处处共享——不管猫出现在左上角还是右下角，同一个"猫形状检测器"都能认出来，不用为每个位置各学一套权重。
2. **局部性（locality）**：每个输出像素只依赖输入的一小块邻域（感受野有限），因为卷积核只有 3×3/5×5 大。这是"世界是局部相关"的假设：相邻像素才需要互相参照。

Transformer 的自注意力**没有这两条假设**：任意两个位置都可以直接交互，权重与空间距离无关，连"相邻更相关"都要自己从数据里学。

"大规模训练压过归纳偏置"的意思：数据足够多时，模型能从数据里**学出**比手工假设更灵活的规律（比如注意力自发学会了"先看局部、再看全局"的分层模式），手工假设反而成了天花板。所以 ViT 在小数据上输（没有假设可依赖），在大数据上赢（不用被僵硬的假设束缚）。

**追问：为什么没有假设就没法泛化？**

把"泛化"的本质摆出来就清楚了：**训练样本是有限的，而输入空间是无限的**——我们要用几千张猫的照片，推断出对"所有可能出现的猫图像"都成立的判断规则。这时会出现一个根本性困境：**与训练集表现一致（误差为 0）的函数有无穷多个**。一端是"死记硬背的查表函数"（见过的样本报正确答案，没见过的乱猜）；另一端是"真正学出猫的视觉规律"（毛色、轮廓、胡须、姿态等通用特征）。两者在训练集上成绩一模一样，没有任何假设约束时，训练算法**无法在这两者之间取舍**——它完全可以选中查表函数，测试集上一塌糊涂。这就是过拟合的根源，也是"无假设 → 无泛化"的完整链条。

这个道理有两个经典注脚：

- **休谟的归纳问题**：从"有限的观察"跳到"普遍的规律"，逻辑上永远不保真——太阳今天升起来了，不能逻辑推导出明天也升。学习算法同样如此，必须借助额外假设才能完成这一跳。
- **没有免费午餐定理（No Free Lunch Theorem）**：数学上可以证明，不假设数据的分布，任何学习算法在所有可能任务上的平均表现完全一样（一样好，也一样差）。也就是说，**没有假设的学习算法根本不存在"普遍优势"**；算法之所以在某类问题上有效，完全是因为它对这类问题做了对的假设。

所以归纳偏置的真实身份是：**对"世界规律长什么样"的赌注，用它来把无穷大的候选函数空间缩小到一个可管理、且大概率正确的子集**。CNN 赌"自然图像是局部相关、平移不变的"，于是把候选函数限制在卷积结构集合里——集合小、其中大部分函数都合理，少量样本就能选出泛化好的函数；ViT 不赌这些，就必须靠海量数据去"重新发现"同样的规律。赌注与数据是互补的：假设越少，需要的数据越多。

## Q2. 此前把自注意力用于图像的工作都是"近似注意力"路线，因为逐像素全局注意力的复杂度不可接受——前面是怎么做的？为什么不行？

**答**：先算一笔账：自注意力的核心是让**每个像素和所有其他像素两两算权重**（$QK^\top$ 矩阵）。224×224 的图有约 5 万像素，两两组合就是 5 万² ≈ 2.5×10⁹ 个权重，还要乘一遍 V——计算和显存都直接爆炸，而且 99.99% 的像素对（比如左上角和右下角）根本不需要交互。

之前的工作只能绕路，都在"改注意力"上做文章：

- **Parmar et al. 2018（Image Transformer）**：每个像素只关注自己的一个小邻域（局部注意力），复杂度降为 O(N·k)。
- **Child et al. 2019（Sparse Transformer）**：把注意力限制在手工设计的稀疏模式上（固定步长间隔、分块），近似全局注意力。
- 还有一派把自注意力当卷积的"插件"（Non-local、Stand-Alone Self-Attention 等）。

**为什么这些都不够好**：为了迁就"逐像素"输入，注意力模式被手工剪得支离破碎——近似、复杂、实现繁琐，还丢掉了全局信息传递的流畅性，工程收益不抵复杂度。

**ViT 的破局点是换了个问题**：不去费力近似"像素级注意力"，而是先把图像压成 patch 序列——224² 图像切成 16×16 patch 后只剩 14×14 = **196 个 token**，196² ≈ 3.8 万，全局注意力自然就便宜了。于是第一次能用上**原汁原味、不掺水**的全局自注意力。改输入粒度，而不是改注意力——这是范式转变。

## Q3. CNN 有平移等变性和局部性两条归纳偏置，Transformer 没有，所以中等数据上 ViT 不如 ResNet；但数据拉大后 ViT 反超——详细解释？

**答**：分两段看。

**小数据阶段（ImageNet-1k，1.3M）**：归纳偏置相当于"免费赠送的先验知识"。CNN 因为卷积核滑动共享、感受野局部，用很少的样本就能学会通用视觉特征（边缘→纹理→形状的层次）；就算数据少，这个"骨架"本身是合理的。而 ViT 什么都没有——空间结构、局部相关性全部要从零学。1.3M 样本对 ResNet 够用，对 ViT-Large 不够：它把训练集的噪声和特例都记住了（过拟合），泛化反而差。论文 Figure 3 的实证是：小数据上 **ViT-Large 准确率不如 ViT-Base**——模型越大、样本不够时摔得越狠。

**大数据阶段（ImageNet-21k 的 14M、JFT 的 300M）**：样本不再稀缺后，局面反转。CNN 的归纳偏置从"帮助"变成"限制"——局部感受野让它难以利用远距离关系（全局上下文），而且 3×3 卷积堆出来的层次结构是**写死的**，没法根据数据调整。ViT 有全局感受野 + 足够样本，能学到更灵活、更适合数据的特征，于是反超 ResNet。

打个比方：归纳偏置像"新手教程"——刚上路时它教你正确的走法（小数据时有用）；但成了老手还被教程框住（大数据时），就限制了发挥。

**追问：卷积的层次结构"写死"是什么意思？难道 ViT 可以调整？**

"写死"指的是**连接骨架（处理方式）由人预先定死，不是权重不能训练**。CNN 训练时能学的只有卷积核的**数值**，但结构性的东西全在训练开始前就固定了：每层只看 3×3 邻域、感受野按"每层 +2"的固定节奏增长、哪层下采样、通道怎么分配、特征必须按"边缘→局部纹理→更大区域"的顺序逐层抽象——这些是超参数，数据只能决定核的取值，改变不了这套流程本身。

ViT 能"调整"的恰恰是 CNN 定死的那个东西——**"谁看谁"由数据动态决定**：

1. **注意力权重是内容自适应的**：CNN 的卷积核一旦训好，对所有输入一视同仁（同一组权重扫全图）；ViT 的注意力权重是**对每张图、每对 token 现场计算**的——同一张图里，模型对纹理区域的关注和对平滑背景的关注完全不同，CNN 做不到这种"按内容分配注意力"。
2. **感受野是动态的**：CNN 第 N 层的感受野大小是算死的；ViT 每层每个 token 理论上都能直达全图任意位置（全局感受野），实际"看多远"由训练出的注意力模式决定。
3. **"先局部、后全局"的层次是自发涌现的**：CNN 的层次处理是被 3×3 卷积 + 池化**强制出来**的；ViT 没有任何这样的设计，但 attention distance 可视化显示浅层 head 关注邻近 patch、深层 head 关注距离逐渐拉大——同样的分层结构是从数据里**自己长出来**的，这正是"大规模训练战胜归纳偏置"的微观证据。

一句话对照：**CNN 的骨架是设计师画死的（数值可调），ViT 的信息路由是数据决定的（结构本身随数据塑造）**。代价就是 ViT 需要海量数据才能把这些结构从零学到——没有免费的灵活性。

**再追问：为什么"分层自发涌现"能作为"大规模训练战胜归纳偏置"的证据？**

关键在**论据的强度来自"同构性"**：ViT 的 12/24/32 层在架构上完全一样，每一层的注意力都是全局可达的——**架构没有规定"浅层看局部、深层看全局"**。那么训练结束后出现的分层（attention distance 随深度单调增长）不可能来自架构，只能来自**数据与任务**。剩下的问题是：为什么数据会"教出"这个模式？

1. **自然图像的统计规律**：空间相邻的 patch 高度相关（同一物体、同一纹理区域），相距越远的 patch 相关性越弱。注意力本质上是"按相关性分配信息流"的机制，最优分配自然反映相关性结构——先聚合强相关的邻居，再整合弱相关的远方。
2. **梯度下降的最优解**：浅层就做长距离聚合是次优的——远处 patch 噪声大、相关性弱，直接全局混合会污染尚未建立的低层特征；先局部聚合、逐层扩大范围，是优化在图像任务上找到的更稳更优的路径（类比拼图：先拼局部块，再拼整图）。
3. **任务的要求**：分类要回答"整张图是什么"，最高层的表示必须携带全局语义——深层 attention distance 拉大是任务的必然结果。

于是证据链闭合：**如果归纳偏置编码的规律真是"只有人类设计才能注入"的，那么没有任何这种设计的 ViT 应当学不到分层；但 ViT 学到的分层与 CNN 的假设不谋而合——说明归纳偏置编码的其实是"数据里本就蕴含的客观规律"，而客观规律是可以用数据换取的**。这就是"战胜"的完整含义。更进一步：ViT 在深层能直接建立 CNN 需要堆很多层才能达到的长距离依赖，说明数据学出的规律还可以比手工假设更灵活——"战胜"不只是复制，而是超越。

## Q4. 每个 patch 展平后经可训练线性投影得到 D 维 patch embedding——具体怎么算？

**答**：以 ViT-Base、224×224×3 输入、patch 大小 16 为例，一步步算：

1. **切块**：224×224 的图切成 (224/16)×(224/16) = **14×14 = 196 个 patch**，每个 patch 是 16×16×3 = **768 个像素值**。
2. **展平**：把每个 16×16×3 的小块拉直成一个 768 维向量 $x_p^i \in \mathbb{R}^{768}$。
3. **线性投影**：用一个**所有 patch 共享**的权重矩阵 $\mathbf{E} \in \mathbb{R}^{768 \times D}$（D=768），每个 patch 向量右乘它：$x_p^i \mathbf{E} \to \mathbb{R}^{D}$。196 个 patch 并行做，得到 196 个 D 维 token。
4. **等价实现**：论文明确指出，这一步完全等价于一个 **stride=16、kernel=16、输出通道 D 的卷积层**——"patch embedding 就是一个大卷积"，这也是为什么后来很多实现直接用卷积写。

最后再叠加位置编码和 class token，就得到输入序列 $\mathbf{z}_0$（见 `vit.md` 的公式）。

## Q5. 在最前面拼接一个可学习的 [class] token，其对应输出位置作为图像整体表示用于分类——什么意思？

**答**：分类任务需要**"整张图的一个向量"**去做 1000 类的判断，但 Transformer 编码器的规则是"几个 token 进、几个 token 出"——196 个 patch 进去就是 196 个输出，没有哪个天然代表"整张图"。怎么办？参考 BERT 的做法：**额外塞一个"代表"进序列**。

- 在序列最前面拼一个**可学习的向量** $x_{class} \in \mathbb{R}^D$（随机初始化，随训练优化）。
- 它和其他 196 个 patch 一起走完所有编码层。因为**自注意力是全局的**，每过一层，class token 都和所有 patch 交换信息，逐步"汇总"全图内容。
- 训练结束后，class token 这个位置被优化成"专门负责汇总"的角色；最后一层的输出 $\mathbf{z}_L^0$ 接 LayerNorm + 分类头，输出类别。

两个自然的追问：

- **为什么它是"代表"而不是别的 patch？** 因为它在序列首位、所有层都能和全部 patch 交互，训练会把它"训成"汇总者。换成任意 patch 理论上也行，只是 BERT 惯例如此。
- **用平均池化行不行？** 行。论文附录实验显示"class token vs 全局平均池化"效果相当——**"怎么汇总"不是本质**，本质是"有个汇总步骤"。后来的很多工作（如一些 ViT 变体）就直接用平均池化替代。

## Q6. 加上可学习的位置编码（1D，按 patch 序号）——什么意思？

**答**：先问为什么要它：自注意力是**置换不变**的——把输入 token 顺序打乱，输出也跟着相应打乱，注意力权重只看 token 内容、不管 token 位置。换句话说，Transformer 分不清"这个 patch 在第 2 行第 5 列"。把一张图切成 patch 后顺序一打乱，模型看到的就是"一袋拼图碎片"，必须显式告诉它每块的位置。

ViT 的做法：

- 给每个 patch 序号 $i$（0~195，按从左到右、从上到下的扫描顺序）分配一个**可学习的 D 维向量** $\mathbf{e}_i$，初始化后随训练一起优化。
- 直接**加法**加到 patch embedding 上：$\mathbf{z}_i = x_p^i \mathbf{E} + \mathbf{e}_i$。
- "1D 按 patch 序号"的意思是：不是给 256×256 个像素编码，而是只给 196 个 patch 编序号；二维空间结构（谁在谁左边、谁在谁上面）不显式给出，而是靠训练从数据里**隐式学到**（比如模型会学到"序号差 14 的两个 patch 是同一列的邻居"）。

为什么用"可学习"而不是原版 Transformer 的固定正弦编码：论文试过 1D 可学习、2D 可学习、相对位置编码等，**效果差异不大**，就选了最简单的 1D 可学习方案（详见 Q11）。

## Q7. 为什么不要解码器（编码器和解码器的区别）？为什么是 pre-norm，有什么好处？

**答**：两个独立的问题。

**① 编码器 vs 解码器**

| | 编码器（Encoder） | 解码器（Decoder） |
|---|---|---|
| 注意力 | 双向：每个 token 看所有 token | 因果掩码：每个 token 只能看自己及之前的 |
| 额外结构 | 无 | 多一层交叉注意力，看编码器输出 |
| 输出 | 同长度表示序列 | 逐个生成，长度可变 |
| 用途 | "理解"输入 | "生成"输出 |

解码器的存在理由是**自回归生成**（像翻译：一个词一个词吐出来，每个词只能看前面的词）。而图像分类是**判别任务**：输入 196 个 patch，输出 1 个标签，不需要"逐个生成"，只需要"理解整张图"。所以 ViT 只需要编码器——这也是 ViT 和 NLP 原版 Transformer（机器翻译需要 encoder-decoder）最直观的区别。

**② pre-norm vs post-norm**

- **Vaswani 原版是 post-norm**：$x_{l+1} = \mathrm{LN}\big(x_l + \mathrm{Sublayer}(x_l)\big)$，LayerNorm 放在**残差之后**。问题是梯度要穿过 LN 再回传，深层网络早期训练梯度不稳定，必须精心设计学习率 warm-up。
- **ViT（学 GPT-2）用 pre-norm**：$x_{l+1} = x_l + \mathrm{Sublayer}\big(\mathrm{LN}(x_l)\big)$，LayerNorm 放在**残差分支里、残差连接之外**。这样主路径上是一条干净的恒等映射（identity + 残差），**梯度流通顺畅、训练更稳**，可以去掉或大幅缩短 warm-up，深层模型更容易收敛。

一句话：pre-norm 是当时大 Transformer 工程实践的共识（GPT-2 验证过），ViT 直接沿用，属于"省事且稳"的选择。

## Q8. 为什么预训练 224、微调 512 是 work 的？为什么不保持一致？

**答**：这其实是"**预训练求性价比，微调求精度**"的工程权衡，能 work 有两个技术前提：

**为什么预训练用 224（省钱）**：token 数随分辨率的平方增长。224²/16² = 196 个 patch；512²/16² = 1024 个 patch——分辨率×2.3，token×5.2，而注意力成本是 token 的平方级，贵约 27 倍。预训练要跑 14 个 epoch、几亿张图，用 224 省下的算力极其可观。

**为什么微调能升到 512（不亏）**：patch 大小不变（仍是 16），只是图变大 → **patch 变多**。ViT 靠两个机制兼容这种变化：

1. **位置编码可插值**：预训练的位置编码是 14×14 网格（196 个向量），微调时用 2D 插值重采样成 32×32 网格（1024 个向量），模型立刻"知道"新分辨率下的空间布局，不需要从头训。
2. **注意力本身对序列长度没有限制**：Transformer 天然接受任意 token 数，换分辨率只是换序列长度。

**为什么不从头到尾都用 512**：预训练全程 512 太贵（算力×27）；全程 224 又浪费了微调阶段"成本低、收益直接"的提点机会——更高分辨率带来更清晰的纹理和细节，分类准确率通常直接受益（ViT-L/16 微调 512、ViT-H/14 微调 518，都是这个逻辑）。

## Q9. 主要结果中，这个模型相当于什么水平？和经典模型对比？

**答**：ViT-H/14 的 ImageNet top-1 **88.55%**，放在 2020-2021 年是**顶尖一档**：

| 模型 | ImageNet top-1 | 说明 |
|---|---|---|
| ResNet-50（2016） | ≈76% | 经典 CNN 基线 |
| ResNet-152（2016） | ≈78% | 加深版 |
| EfficientNet-B7（2019） | 84.4% | 当时 CNN 缩放标杆 |
| Noisy Student（2020） | 88.4% | EfficientNet-L2 + JFT 半监督，**当时的 ImageNet SOTA** |
| **ViT-H/14（本文）** | **88.55%** | 与 Noisy Student 并列顶尖 |
| **ViT-L/16（本文）** | 85.30% | 比 ViT-H/14 小，同样很强 |

两个更重要的对比维度（论文的原话）：

- **vs 同数据预训练的 CNN**：JFT 预训练的 ViT-L/16 **全面超过**同样 JFT 预训练的 BiT-L（ResNet152×4 级别的强基线），而且**预训练算力大幅更少**——ViT-L/16 用 8 核云 TPUv3 约 30 天就能训完。
- **vs 算力预算**：论文专门做了"同等算力预算"对比，ViT 普遍优于 ResNet——同样的钱，ViT 成绩更好。

所以结论不是"ViT 绝对精度碾压一切"，而是"**同等投入下，ViT 成为最优解，且预训练更便宜**"。

## Q10. 整个模型的架构说详细一点。

**答**：以 ViT-Base、224×224 输入为例，按张量形状（shape）逐步跟踪数据流。shape 记法：`[B, 序列长度, 特征维度]`（B=batch，通常省略不写）：

```
输入图像:            [B, 224, 224, 3]        # 或 [B, 3, 224, 224]
① 切 patch:          [B, 196, 768]           # 14×14 网格 = 196 个 patch，每个 16×16×3=768 个像素值
② patch embedding:   [B, 196, 768]           # 共享线性投影 E∈R^{768×768}（等价 stride-16 卷积）
③ 拼 class token:    [B, 197, 768]           # 序列最前插入一个可学习向量 [1, 768]
④ 加位置编码:        [B, 197, 768]           # 逐元素相加（class token 也有自己的位置向量）
⑤ 12 层编码器:       [B, 197, 768]           # 每层 shape 不变，只变换内容
   每层内部：
   - pre-norm LN:                 [B, 197, 768]
   - 多头自注意力（12 头）：
        Q/K/V 投影:               [B, 197, 768] → 拆成 12 头 [B, 12, 197, 64]
        注意力矩阵:                [B, 12, 197, 197]   # 每头 197×197 个两两权重
        输出拼接回:                [B, 197, 768]
   - 残差 + pre-norm LN + MLP:    [B, 197, 768] → 升维 [B, 197, 3072] → 降回 [B, 197, 768]
⑥ 取 class token:     [B, 768]               # 取第 0 个位置的输出
⑦ 分类头:             [B, 768] → LN → 线性层 → [B, 1000]   # logits
```

几个值得注意的 shape 细节：

- **全流程只有两处维度变化**：①处"像素数 → patch 数"（224²→196）与⑦处"表示 → 类别"（768→1000）；其余 12 层编码器输入输出 shape 完全一致——Transformer 的招牌特性"序列等长等宽"。
- **注意力矩阵是显存的绝对大头**：每头 [197×197]，12 头共 12×197×197 ≈ 46.6 万个元素，再乘 batch。这就是"二次复杂度"的实体（对应 Q13）。
- **头维度 = 隐层维度 ÷ 头数**：768/12 = 64，多头并行计算后拼接回 768。

三个变体的配置（论文 Table 1）：

| 变体 | 层数 | 隐层维度 | MLP 维度 | 头数 | 参数量 |
|---|---|---|---|---|---|
| ViT-Base | 12 | 768 | 3072 | 12 | 86M |
| ViT-Large | 24 | 1024 | 4096 | 16 | 307M |
| ViT-Huge | 32 | 1280 | 5120 | 16 | 632M |

注意全流程**没有任何卷积**（patch embedding 那步可以写成一个卷积，但本质是线性投影）：纯 Transformer 完成图像理解。预训练在 224² 分辨率、微调升到 512/518²（见 Q8）。

## Q11. 位置编码（1D 可学习 vs 2D vs 相对）差异不大；注意力能学到局部模式、越深层 head 关注距离越远——什么意思？位置编码有哪些类型？

**答**：两个发现拆开说。

**① 位置编码的类型**（为什么需要它见 Q6）：

- **绝对位置编码——可学习**：每位置一个可训练向量。ViT 用 1D 版（按 patch 扫描序号编 196 个向量）；也可以 2D 版（行、列各一组向量拼起来，显式编码二维坐标）。
- **绝对位置编码——固定正弦/余弦**：原版 Transformer 用不同频率的 sin/cos 函数组合，不需训练，且理论上能外推到训练时没见过的更长序列。
- **相对位置编码**：不编码"绝对位置"，而是在注意力权重里加"两个 token 相对距离"的偏置（T5、Swin 都属此类）。
- **无位置编码 + 内容含位置信息**：把位置信息画进输入本身（如给图像加坐标通道）——后来的工作常用。

ViT 的附录实验把 1D 可学习、2D 可学习、相对位置编码都试了，**差距很小**，于是采用最简单的 1D 可学习。结论：**分类任务对位置编码的具体形式不敏感**，"只要有位置信息"就行。

**② 注意力学到的模式**：论文可视化发现——浅层 head 的注意力集中在邻近 patch（像 CNN 的浅层局部滤波），而越深的层，head 的平均关注距离（attention distance）越大（像 CNN 深层感受野扩大）。这说明即使**没有任何卷积先验**，Transformer 也从数据里自发学出了"先局部、后全局"的分层处理方式。这正是"规模战胜归纳偏置"的微观证据：手工假设（局部性）是能靠数据学出来的。

## Q13. 什么是二次复杂度？后续 Swin 如何解决？

**答**：**二次复杂度**指标准自注意力里，注意力矩阵 $QK^\top \in \mathbb{R}^{N \times N}$ 的计算量与显存随 token 数 N **平方**增长（$O(N^2)$，再算乘 V 是 $O(N^2 D)$）。N 本身随分辨率平方增长，所以分辨率一提，代价暴涨：224²/16² 只有 196 个 token；512²/16² 有 1024 个（×5.2，注意力×27）；1536×1536 的图像 N≈9216，单个注意力矩阵近 8500 万元素，显存直接爆掉。ViT 只能靠"用更大 patch"缓解（P=32 变体），治标不治本。

**Swin Transformer（Liu et al., ICCV 2021）的解法**——三件套：

1. **窗口注意力（window attention）**：把特征图分成不重叠的局部窗口（如 7×7），注意力**只在窗口内**算。复杂度从 $O(N^2)$ 降到 $O(N \cdot W^2)$（W=窗口大小，固定），**随分辨率线性增长**——高分辨率不再爆炸。
2. **移位窗口（shifted window）**：窗口之间不交流怎么办？相邻层之间把窗口划分**平移半个窗口**，让上一层窗口边缘的信息跨到下一层窗口中心。逐层交替，信息层层渗透，全局感受野逐步建立。
3. **层级结构（金字塔）**：像 CNN 一样逐阶段下采样（patch merging），产出 4 个分辨率的多尺度特征图——这同时解决了 Q14 说的"无多尺度、无密集输出"问题，检测/分割任务直接可用。

一句话：Swin 把"全局注意力"换成了"窗口内注意力 + 跨层信息传递"，在保留 Transformer 能力的同时把复杂度拉回线性，并补上了多尺度金字塔。另一个方向是 NaViT（2023）：保留全局注意力，但允许任意分辨率、把不同尺寸的 patch 序列"打包"提高利用率（后来的 Qwen2-VL 采用），属于效率优化而非架构替代。

## Q14. 原文是"图像分类专用"设计：全局固定分辨率、无多尺度、无密集输出——后续如何改？

**答**：原文三个限制，逐一被后续工作拆掉：

**① 固定分辨率**（预训练 224²，其他尺寸靠位置编码插值）
- **DeiT（2021）**：用知识蒸馏 + 更强数据增强，只靠 ImageNet 就能把 ViT 训好，摆脱对 JFT 级大数据的依赖。
- **位置编码插值**成为通用技巧，让微调分辨率任意切换（Q8 的 512/518 就是例子）。
- **NaViT（2023）**：原生支持任意长宽比与分辨率（patch 打包），彻底去掉"固定网格"假设。

**② 无多尺度**（只有一个特征图，没有金字塔层级）
- **Swin（2021）、PVT（2021）**：引入金字塔结构 + 逐阶段下采样，产出多尺度特征图，可直接接入检测/分割框架。
- 这使 Transformer 骨干与 FPN/RPN 等成熟的 CNN 检测体系兼容。

**③ 无密集输出**（只有全局分类头，没有逐像素输出）
- **DETR（2020）**：Transformer 做目标检测（集合预测）。
- **Segmenter、Mask2Former、ViT-Adapter** 等：把 ViT 中间层 patch 特征解码/上采样，做语义分割等密集预测。
- 基本思路：中间层输出本来就有空间对应关系，加解码器或适配器即可转成密集输出。

对 VLM 而言最重要的后续不是这些，而是 **CLIP（2021）用 ViT 做视觉塔做图文对比学习**——ViT 的"分类专用"限制被彻底甩开后，它成了整个多模态时代的视觉编码器标准件。

## Q15. "数据量越大，模型越大越好，如果数据量不够，大模型反而更容易过拟合"——展开说？

**答**：这是论文 Figure 3（数据规模消融）的直接结论：

- **原理**：模型参数量大 → 假设空间大 → 能拟合更复杂的规律，但同时也有更强的"死记硬背"能力。样本充足时，大模型把容量用在真实规律上（好）；样本不足时，它连训练集里的噪声和特例都记住了（过拟合），测试集泛化差。
- **ViT 把这个现象放大**：因为它的归纳偏置本来就少，连"空间局部性"都要自己学——样本不够时，它连最基础的视觉结构都学不扎实，再叠加大模型的过拟合倾向，跌得更狠。所以 ImageNet（1.3M）上 ViT-Large 反而 **不如** ViT-Base；到了 JFT（300M），才出现 ViT-Huge > ViT-Large > ViT-Base 的正常排序。
- **工程含义**：选模型规模要看数据预算。数据少 → 用小模型或强正则（DeiT 证明：加上蒸馏和增强，小数据也能训 ViT）；数据多 → 放心上大模型。这条"数据-模型匹配"原则贯穿整个 VLM 时代（也是本项目做 VLN 时选骨干的第一条原则）。
