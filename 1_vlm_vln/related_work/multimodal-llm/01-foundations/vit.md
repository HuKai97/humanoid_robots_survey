## 一句话

**把图像切成 16×16 的 patch 当"单词"，用纯 Transformer 编码器做图像分类——只要数据足够大（14M~300M 张图），大规模训练就能压过卷积的归纳偏置。**

## 背景与动机

- **Transformer 已在 NLP 大规模成功**（BERT/GPT 预训练范式），但计算机视觉仍由 CNN 主导。此前把自注意力用于图像的工作（局部注意力 Parmar et al. 2018、Sparse Transformer Child et al. 2019 等）都是"近似注意力"路线：逐像素全局注意力要为每对像素算权重（224² 的图约 5 万像素，两两组合≈2.5×10⁹），计算与显存都不可接受，只能把注意力剪成局部邻域或稀疏模式——近似、复杂，还丢了全局信息，工程收益不抵复杂度。
- **本文的关键洞察**：不去费力近似"像素级注意力"，而是**改输入粒度**——把图像切成 patch 序列（224²/16² = 196 个 token），序列长度从"像素数"降到"patch 数"，全局注意力自然就便宜了（196²≈3.8 万），于是第一次用上了原汁原味的全局自注意力。
- **预判失败再翻盘**：CNN 自带两条归纳偏置（inductive bias，即算法对未知数据"应该长什么样"的先天假设）。为什么没有假设就无法泛化：训练样本有限，而误差为 0 的函数无穷多——"死记硬背查表"和"学出真实规律"在训练集上无法区分，没有假设就无从取舍（没有免费午餐定理：不假设数据分布，任何算法都没有普遍优势）；归纳偏置就是"世界规律长什么样"的赌注，用来把候选函数空间缩小到合理子集。CNN 赌的是**平移等变性**（卷积核滑动共享，物体挪到哪都能认出）和**局部性**（输出只依赖局部感受野）。Transformer 一条都没有，连"相邻像素更相关"都要从零学，所以中等数据（ImageNet-1k，1.3M 张）上 ViT 不如 ResNet：样本不够时，既无先验可依赖、大模型又容易过拟合（ViT-Large 甚至不如 ViT-Base）。但数据拉上去（ImageNet-21k 的 14M、JFT 的 300M）后，**"大规模训练战胜归纳偏置"（large scale training trumps inductive bias）**：数据足够时，模型能从数据里学出比手工假设更灵活的规律，写死的归纳偏置反而成了天花板——ViT 反超。

## 方法

### 总体结构（最简形式）

1. 图像 $x \in \mathbb{R}^{H\times W\times C}$ 切成 $N = HW/P^2$ 个 $P\times P$ patch（$P=16$ 或 $32$）。
2. 每个 patch 展平后经**可训练线性投影**得到 $D$ 维 patch embedding（等价于卷积核=patch 大小的 Conv2D）。
3. 在最前面**拼接一个可学习的 `[class]` token**（完全仿照 BERT），其对应输出位置作为图像整体表示用于分类。
4. 加上**可学习的位置编码**（1D，按 patch 序号）。
5. 送入**标准 Transformer 编码器**（ViT 不含解码器；层归一化前置，与 Vaswani 原版不同，采用与 GPT-2 一致的 pre-norm）。
6. 输出：`[class]` token 经 LayerNorm 后接 MLP 头分类。

$$
\mathbf{z}_0 = [x_{class};\, x_p^1 \mathbf{E};\, x_p^2 \mathbf{E}; \dots;\, x_p^N \mathbf{E}] + \mathbf{E}_{pos}
$$

（后续编码层即标准多头自注意力 + MLP + 残差 + LayerNorm。）

**以 ViT-Base 走一遍数据流**（形成具体直觉，shape 记作 `[序列长度 × 特征维度]`）：`[224×224×3]` 图像 → 切成 196 个 16×16 patch（`[196 × 768]` 像素值）→ 共享线性投影到 768 维（`[196 × 768]`，等价于一个 stride/kernel=16 的卷积层）→ 拼上 class token（`[197 × 768]`）→ 加位置编码（shape 不变）→ 12 层编码器（每层内部：多头注意力把 `[197 × 768]` 拆成 12 头 `[12 × 197 × 64]`、注意力矩阵 `[197 × 197]`；MLP 升维到 3072 再降回）→ 取 class token 输出（`[768]`）→ LayerNorm → 线性映射到 1000 类。全流程只有"像素 → patch"与"表示 → 类别"两处维度变化，其余 12 层等长等宽（完整逐步 shape 见 `vit_q&a.md` Q10）。

### 两个关键设计

- **class token 从哪来**：分类需要一个"整张图的向量"，但编码器是"几个 token 进、几个 token 出"，没有天然代表全图的输出。于是仿 BERT 在序列最前拼一个可学习向量，靠全局注意力逐层汇总全图信息，最后一层取它的输出做分类（附录显示用平均池化替代也差不多——"怎么汇总"不是本质，"有汇总步骤"才是）。它和其余 token 走完全相同的编码层，只是位置特殊、被训练成"汇总者"。分类损失只接在最后一层的 class token 上，所以模型要把有助于分类的信息传给它，才能降低损失。
- **只用编码器 + pre-norm**：解码器是为自回归生成设计的（因果掩码、交叉注意力），图像分类是判别任务，只需编码器"理解整张图"。LayerNorm 放在残差之外（pre-norm，学 GPT-2）而非残差之后（Vaswani 原版 post-norm），让主路径保持干净的恒等映射，梯度流通顺畅、训练更稳，可省去学习率 warm-up。
- **Hybrid 变体**：输入不一定是原始 patch，也可以是 CNN 的中间特征图（ResNet50 前几层输出当 patch，patch 大小等效 1×1）。用于研究"注入卷积归纳偏置"还剩多少价值。

### 模型变体（论文 Table 1）

| 变体 | 层数 | 隐层维度 | MLP 维度 | 头数 | 参数量 |
|---|---|---|---|---|---|
| ViT-Base | 12 | 768 | 3072 | 12 | 86M |
| ViT-Large | 24 | 1024 | 4096 | 16 | 307M |
| ViT-Huge | 32 | 1280 | 5120 | 16 | 632M |

命名约定：`ViT-L/16` = Large 变体 + 16×16 patch。**patch 越小序列越长，算力越贵**（序列长度与 patch 面积成反比）。

## 实验与结果

### 实验设置

- **预训练数据**（三档递增）：ImageNet（1.3M 图 / 1k 类）→ ImageNet-21k（14M 图 / 21k 类）→ JFT（300M 图 / 18k 类）。
- **流程**：大监督数据上预训练 → 下游任务微调（fine-tuning）。下游含 ImageNet、ImageNet-ReaL、CIFAR-10/100、Oxford Pets/Flowers、19 任务的 VTAB 套件。
- **微调细节**：预训练在 224² 分辨率，微调提高到 512（ViT-L/16）与 518（ViT-H/14），沿用标准做法（含 Polyak 平均）。**预训练低分辨率、微调高分辨率**是"预训练求性价比、微调求精度"的经典权衡：token 数随分辨率平方增长（224²→196 个 patch，512²→1024 个，注意力成本约 ×27），预训练几亿张图用 224 最划算；微调阶段靠位置编码 2D 插值无损换分辨率（patch 大小不变、序列变长，Transformer 天然兼容），用小成本换来更清晰细节带来的提点。
- **算力**：TPUv3；ViT-H/14 预训练约 **2.5k TPUv3-core-days**；ViT-L/16 在 8 核云 TPUv3 上约 30 天可训完。

### 主要结果（论文 Table 2、摘要）

| 指标 | 成绩 |
|---|---|
| ImageNet（ViT-H/14） | **88.55%** |
| ImageNet-ReaL | **90.72%** |
| CIFAR-100 | **94.55%** |
| VTAB（19 任务平均） | **77.63%** |

- **vs CNN 对标**：JFT 预训练的 ViT-L/16 全面超过同样 JFT 预训练的 BiT-L（ResNet152×4 级别的强基线），且**预训练算力大幅更省**；更大的 ViT-H/14 进一步拉开差距。
- **计算效率**：同等算力预算下，ViT 普遍优于 ResNet（"少花钱多办事"）。
- **放在当年是什么水平**：88.55%（ViT-H/14）与当时的 ImageNet SOTA Noisy Student（88.4%，EfficientNet-L2 + JFT 半监督）并列顶尖，远高于 ResNet-50（≈76%）、EfficientNet-B7（84.4%）等经典 CNN；ViT-L/16（85.30%）更以少得多的预训练算力全面超过同数据预训练的 BiT-L。所以 ViT 的成色是"同等投入下最优"，而不是单纯堆绝对精度。

### 消融与核心发现

1. **数据规模是胜负手（Figure 3）**：ImageNet（最小档）上 ViT-Large 反而**不如** ViT-Base——大模型过拟合；只有到 JFT-300M 才显现"越大越好"。9M/30M/90M/300M 子集实验同样显示性能随数据量单调提升。
2. **小算力下 Hybrid 略优，大模型下差距消失**：CNN 特征当输入的混合模型在 ViT-Base 级别稍有优势，但 ViT-Large/Huge 级别纯 Transformer 追平——归纳偏置只在**数据和模型都小**时才值钱。
3. **Transformer 未饱和**：在实验范围内性能没有饱和迹象，论文直接预测了后续更大规模的 scaling。
4. **位置编码不敏感，注意力自发分层**：自注意力是置换不变的，必须显式提供位置信息。论文比较了 1D 可学习、2D 可学习、相对位置编码，效果差异不大，故选最简单的 1D 方案。更有意思的是注意力可视化：浅层 head 关注邻近 patch（局部滤波），深层 head 的平均关注距离随层数增长——没有任何卷积先验，Transformer 也自发学会了"先局部、后全局"的分层处理，这正是"规模战胜归纳偏置"的微观证据。所谓 CNN 层次"写死"与 ViT 的"可调整"，区别在于：CNN 定死的是**连接骨架**（3×3 邻域、感受野固定增长、逐层抽象流程），训练只改滤波器数值；ViT 的"谁看谁"由注意力按输入内容**动态计算**（权重对每张图现场生成、感受野全局可达），同样的"局部→全局"分层是数据里自发涌现而非设计出来的（详见 `vit_q&a.md` Q3 追问）。这个观察之所以能充当"规模战胜归纳偏置"的证据，是因为 ViT 各层完全同构、每层注意力全局可达——架构没规定"浅层看局部、深层看全局"，分层只能是数据与任务（自然图像的空间相关性 + 分类需要全局语义）塑造出来的：归纳偏置编码的规律，原来可以用数据换取。

## 关键结论

1. **"大数据 + 纯 Transformer"可以替代 CNN 的架构归纳偏置**——这是 ViT 最响的结论。
2. 对算力友好：同等预算下 ViT 效果更好。
3. 尺度定律初现：模型与数据同时扩大，性能未见顶。

## 局限（论文自认 + 公认）

- **数据饥渴**：中等数据（ImageNet 级别）从头训练时不如 CNN，需要百万级以上预训练数据才划算——本质是"数据-模型匹配"问题：模型越大、假设空间越大，数据不够时反而更容易过拟合（Figure 3：小数据上 ViT-L 不如 ViT-B）。
- **微调仍依赖大量下游数据**；对检测/分割等密集预测任务，当时表现不如专用 CNN（后续由 Swin、DETR 等补上）。
- **图像分类专用的三处硬编码**：① 固定分辨率（靠位置编码插值才支持其他尺寸）→ 后来被 NaViT 的任意分辨率/长宽比取代；② 无多尺度（单一特征图、无金字塔层级）→ Swin/PVT 引入逐阶段下采样金字塔；③ 无密集输出（只有全局分类头）→ DETR（检测）、Segmenter/Mask2Former（分割）等把 patch 特征解码成密集输出。
- **二次复杂度**：标准注意力是 O(N²)（N=token 数），且 N 随分辨率平方增长，高分辨率输入撑爆显存。Swin 的解法：窗口内注意力（复杂度降到 O(N·W²)，随分辨率线性增长）+ 移位窗口（跨窗口交换信息）+ 金字塔下采样；NaViT 则走"任意分辨率打包"的效率路线（后被 Qwen2-VL 采用）。视觉塔对高分辨率的处理演进史，正是后来 VLM"动态分辨率"能力的来源。

## 对本项目（VLM / VLN）的启示

1. **ViT 是后续一切 VLM 的视觉编码器原型**：CLIP-ViT、SigLIP、InternViT 都是它的直接后代。读 ViT = 读懂了所有 VLM 视觉塔的底稿。
2. **"规模换归纳偏置"的方法论**直接预言了 VLM 领域的演进：VLN 从手工设计（图、记忆）走向"大数据 + 通用骨干"（Navid/NaVILA 用 VLM 代替专用导航网络），是同一条逻辑的延伸。
3. **patch 化 + class token**：VLN 全景观测（36 视角拼图）与 VLM 多图输入（anyres 切片）都在重复"把图像切块当序列"的 ViT 操作。
4. 数据规模是第一性：对本项目最实际的提醒是——**做 VLN 时，先评估自己的数据量与 ViT 数据需求线的位置**，再决定从零训视觉塔还是直接用预训练塔。

## 一句话总结
ViT 是将纯 Transformer 成功用于图像分类的代表性工作。它把一张 224×224 的图像划分为 196 个互不重叠的 16×16 patch，将每个 patch 展平并线性映射为 embedding；再在序列前加入一个可学习的分类 token，并加上位置编码，送入 Transformer Encoder。自注意力在 patch token 之间建立全局关系，最后用分类 token 的输出到分类头完成分类。ViT 缺少卷积的局部性等归纳偏置，因此通常更依赖大规模预训练数据；在足够的数据和计算资源下，它能取得优于当时卷积网络的分类效果。
