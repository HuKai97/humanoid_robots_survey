# SelfOcc：用视频监督几何，占据预测不再完全依赖三维标签

## 一分钟总结

**定位：数据成本路线的关键论文。** SelfOcc 从图像获得 BEV/TPV 三维特征，解码为 SDF，再渲染到其他时间的图像，用视频一致性学习占据。它说明无稠密三维标注也能学习空间结构，但“自监督”并不表示不需要位姿、相机参数、先验模型或语义伪标签。[CVPR 原始页](https://openaccess.thecvf.com/content/CVPR2024/html/Huang_SelfOcc_Self-Supervised_Vision-Based_3D_Occupancy_Prediction_CVPR_2024_paper.html)

## 论文与证据

- **标题**：SelfOcc: Self-Supervised Vision-Based 3D Occupancy Prediction；Huang 等；CVPR 2024，预印本 2023。[arXiv](https://arxiv.org/abs/2311.12754)
- **官方代码**：[huang-yh/SelfOcc](https://github.com/huang-yh/SelfOcc)。已核验训练、几何 IoU、深度与可视化入口，未安装执行。
- **实际阅读级别**：论文 HTML §3 方法、MVS 损失、§4 实验设置和附录的语义监督来源；会议摘要及官方 README。未逐式推导完整附录，未下载论文。核验日期：2026-09-29。

## 训练与推理输入输出

训练使用视频序列及位姿/标定，通过跨时刻约束学习；推理从图像预测当前三维表示，可生成占据、深度等输出。特别要拆开两件事：几何可以不使用三维占据真值训练；nuScenes 语义预测使用 OpenSeeD 产生的二维语义伪标签，因此不能声称“语义完全由无标签 RGB 视频自行发现”。[原文实现与附录 B](https://arxiv.org/html/2311.12754)

## 方法步骤

1. 将多视角图像特征提升到 BEV 或 TPV 表示。
2. 用解码器查询三维位置，得到 SDF 及渲染需要的颜色/语义属性。
3. 沿射线积分，将预测三维场渲染为图像或深度，并与其他时刻的观测比较。
4. **MVS-embedded** 深度学习沿射线考虑多个深度候选，用光度匹配误差直接优化 SDF 诱导的渲染权重；配合占据相关正则学习空间结构。[方法 §3](https://arxiv.org/html/2311.12754#S3)

## 关键概念解释

**SDF** 是到表面的有符号距离；零水平集描述边界，符号用于区分占据内外。**Volume rendering** 将一条射线上多个位置贡献组合成可比较的二维观测；渲染图像相似不代表所有三维位置已被真实看见。**自监督视频一致性** 是利用同一场景不同视角之间的几何关系构造损失，仍然依赖正确对应关系。

SDF 的数值不能自动当作机器人已验证的 ESDF：前者是模型学习的隐式场，后者作为规划距离查询时通常还需要清晰的障碍证据、未知空间处理与误差界。即使两者单位都是米，也必须实测距离与符号可靠性。

## 实验应看什么

原文同时报告 occupancy、深度估计和新视角深度合成；这几个任务的最优配置并不一定相同。重点看 SDF 与 density field 的对比、MVS 损失、时序监督比例和正则化消融，检查“更好的图像/深度”是否真正带来更好的占据。[论文实验](https://arxiv.org/html/2311.12754#S4)

复现应分别报告几何 IoU、语义 mIoU、伪标签覆盖率、动态区域误差及评价 mask。与全监督方法比较时，在表格中明确三维标签、二维语义模型和位姿的使用情况，不能只写一栏 self-supervised 就认为监督成本完全相同。

## 局限与人形迁移分析（本调研推断）

它对人形最有吸引力的是大量未标注视频能够用于表征学习。然而机器人自身手臂、行人及被操作物体都在运动，单纯跨帧光度一致性容易失效；镜面、反光、曝光变化和运动模糊也是不利条件。需要用自遮挡/动态 mask、可靠位姿以及可用深度辅助诊断，而不是假设几何会从所有视频自然收敛。

人形原地转头虽提供视角变化，却未必提供充分平移基线；近距离观察还伴随相机中心随关节运动。建议先在静态室内、精确标定和可靠轨迹下验证，再增加运动物体与关节变化。生成的占据适合做学习先验，与实测深度融合前应保留来源和置信度，不可直接把 SDF 的正侧当成确认自由。

## 阅读与复现检查点

- 能明确列出训练使用的各类信息：RGB、位姿、内外参、二维伪语义；与推理输入分开。
- 用简单平面场景检查射线方向、SDF 符号、深度单位与渲染结果。
- 先关闭动态区域，检查光度误差和占据误差是否同向变化，再逐步恢复复杂场景。
- 把少量真实深度保留作独立验证，不作为模型自证正确的可视化来源。
- 与 [Occ3D](../occ3d/README.md) 对照标签成本，与 [GaussianFormer](../gaussianformer/README.md) 对照三维表示；两条线分别解决监督和表示问题。
