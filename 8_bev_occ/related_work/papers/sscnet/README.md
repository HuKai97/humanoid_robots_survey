# SSCNet：从深度图理解语义场景补全

## 一分钟总结

**定位：必须理解的任务起点，工程复现可后置。** SSCNet 把“哪里有物体”和“它是什么”放到同一个三维体素预测问题里：输入单张深度图，输出视锥内包含遮挡区域的几何占据和语义。它教会你的关键区别是：传感器测到的表面只是证据，网络补全的物体内部和背面属于推断；二者不能不加区分地写进机器人安全地图。[会议原始页](https://openaccess.thecvf.com/content_cvpr_2017/html/Song_Semantic_Scene_Completion_CVPR_2017_paper.html)

## 论文与证据

- **准确标题**：Semantic Scene Completion From a Single Depth Image；Song 等；CVPR 2017。arXiv 首发于 2016 年，两种年份不能混作发表年份。[arXiv](https://arxiv.org/abs/1611.08974)
- **官方入口**：[项目页](https://sscnet.cs.princeton.edu/)、[官方代码](https://github.com/shurans/sscnet)。已核验仓库 README 的训练、测试、数据准备入口；未下载论文、代码、数据或权重，未运行代码。

## 任务、输入和输出

输入是单视角深度观测；输出是相机视锥内的三维体素状态和类别，不局限于深度点所在的可见表面。训练需要完整体积标签。论文以室内场景为重点，使用合成场景 SUNCG，并在真实室内数据上验证。[论文摘要](https://openaccess.thecvf.com/content_cvpr_2017/html/Song_Semantic_Scene_Completion_CVPR_2017_paper.html)

这与传统轮式机器人 occupancy grid mapping 的工作分工不同：后者通常将测量按位姿反复融合；SSCNet 主要研究从不完整观测预测完整场景，没有替你解决跨时刻地图维护、回环修正、动态障碍衰减和定位误差传播。

## 方法步骤与关键概念

1. 将深度观测变成适合三维卷积处理的体积输入；阅读代码时应检查距离表示、截断范围、符号约定和体素坐标，不要凭名称猜测自由空间编码。
2. 用端到端三维卷积网络同时学习几何占据与语义；膨胀三维卷积扩大上下文范围，使局部残缺表面能够利用周围布局信息。
3. 输出体素级分类，通过联合学习利用“形状支持类别、类别支持形状”的关系。网络并没有对每个被补全体素提供新的物理观测。[项目说明](https://sscnet.cs.princeton.edu/)

**SSC** 是 Semantic Scene Completion：semantic 指占据体素所属类别，completion 指预测未完整观测的空间。**体素**是三维网格单元。**膨胀卷积**通过间隔采样扩大感受野；它是上下文建模方法，不是概率置信度估计。**遮挡未知**表示缺乏观测，**自由**表示有证据支持无障碍；补全预测为 empty 不自动等于已观测 free。

## 实验应看什么

阅读时分别检查几何 completion IoU 与 semantic mIoU，确认是否包含可见表面、遮挡区域、无效体素以及各类平均方式。建议对照“只做几何”和“联合语义”消融，看改进来自何处，而不只抄总分。可视化应同时显示输入深度、已观测表面、推断体素，特别检查椅腿和桌下空隙。此处不给未经完整协议核对的数值排名。

## 局限与人形迁移分析（本调研推断）

对你而言，深度输入与传统几何感知经验连接最自然；人形头部 RGB-D 可以提供类似输入，但室内家具先验不能证明台阶边缘、玻璃、细线缆或陌生杂物的占据可靠。体素分辨率不足会吞掉细杆，也会把桌下可通行空间填实。预测的 floor 类别还不包含承重、摩擦、坡度和落脚可达性。

建议采用两个字段：观测证据层记录测量得到的 free/occupied/unknown，推断层记录补全类别与置信度；规划能使用后者提示探索或风险，但要能够识别其来源。人形应用还应按身体高度分别评估足部、膝部、躯干与头部碰撞漏检。这些是系统设计建议，并非 SSCNet 已验证的人形能力。

## 阅读与复现检查点

- 第一遍能画清“深度 → 体积 → 3D CNN → 占据/语义”，说明每一步哪些信息来自测量。
- 第二遍核对输入距离场、损失、有效区域 mask 和 evaluation script；本轮尚未逐行核验这些实现细节。
- 若以后复现，先查旧依赖兼容性：官方仓库基于 Caffe、Matlab，并列有数据转换脚本；不能直接假设现代 PyTorch 环境可跑。[官方 README](https://github.com/shurans/sscnet)
- 先做一段自己的 RGB-D 静态室内序列，检查相机轴、体素原点、单位；再研究学习模型，避免坐标错误被误判成网络问题。
