# VoxFormer：先建立稀疏几何，再补全完整场景

## 一分钟总结

**定位：连接深度几何经验与视觉 Transformer 的重点论文。** VoxFormer 的直觉是：图像特征真正支持的是可见表面，先用深度提出少量可能占据的三维查询，再从这些位置向未观测体素传播信息。它的前半段稀疏，后半段仍会恢复完整体积，因此不能把它等同于全流程稀疏 OCC。[NVIDIA 作者页](https://research.nvidia.com/labs/lpr/publication/li2023voxformer/)

## 论文与证据

- **标题**：VoxFormer: Sparse Voxel Transformer for Camera-based 3D Semantic Scene Completion；Li 等；CVPR 2023。[原始论文](https://arxiv.org/abs/2302.12251)
- **官方代码**：[NVlabs/VoxFormer](https://github.com/NVlabs/VoxFormer)。已核验论文到官方仓库的链接与 README；未下载代码、深度预测器或权重，未运行训练。
- **实际阅读级别**：论文 HTML §3 的输入输出、两阶段流程、深度提案和注意力方法；作者页与官方 README；未完整复核全套实验。核验日期：2026-09-29。

## 输入、输出和任务边界

模型从 RGB 图像及几何投影关系预测当前自车坐标系内的稠密语义体素。框架可利用单帧或历史图像；深度由外部预测器提供，原文讨论单目及双目深度来源。因此“camera-based”不能简写成“所有配置只用一个单目网络且无其他预训练来源”。主要评估任务为 SemanticKITTI SSC。[任务定义与深度来源](https://arxiv.org/html/2302.12251#S3)

## 方法步骤

1. **类别无关提案**：深度反投影形成几何输入，轻量网络做深度纠正并预测粗分辨率二值占据，选择候选 voxel queries。
2. **图像取证**：仅让选中的查询投影到可见图像，通过 deformable cross-attention 采集图像特征。
3. **稀疏到稠密补全**：未选体素填入可学习 mask token，与已有特征一起做 self-attention，推断缺失区域。
4. 上采样与分类头产生完整语义体素；提案阶段和语义阶段的监督目标不同。[论文方法 §3.4–3.6](https://arxiv.org/html/2302.12251)

## 关键概念

**Query** 是带位置的可学习特征载体，不是实测点。**Deformable attention** 围绕参考位置学习少量采样点，减少对全部图像位置计算注意力的负担。**Mask token** 表示待推断的三维位置；它不表示该处已知为空，也不是机器人概率地图里的 unknown 概率分布。把“提案没选中”“不可见”“自由空间”混成一个标签，会同时破坏几何理解和评估。

## 实验应看什么

重点比较单帧与时序配置、不同距离范围、深度质量以及提案模块的影响。论文强调近距离改进，但不要由此直接推出机器人脚边的厘米级可靠性：原数据的传感器布置、体素尺度和类别与人形任务不同。[论文实验入口](https://arxiv.org/html/2302.12251#S4)

复现实验应单独记录提案 recall：真实障碍在第一阶段有没有候选支持？再测补全的 precision，避免第一阶段漏检被第二阶段看似完整的输出掩盖。效率比较须纳入外部深度网络、历史图像编码、数据传输和最终体素展开，不能只计 Transformer 主干时间。

## 局限与人形迁移分析（本调研推断）

人形已有双目或 RGB-D 时，“可靠几何提案 + 图像语义”的思路很适合小规模试验，但深度在反光面、遮挡边缘和低纹理区域的系统误差会影响查询位置。手臂或身体自遮挡也会产生无关的近距离提案，需要机器人自身模型和时间同步来剔除。

时序采样依赖位姿变换；头、胸与底座的相对运动要求每个时刻独立外参，而不是只填一个固定车载 camera-to-ego 矩阵。建议在重力对齐的局部地图坐标里维护体素，并把头部姿态误差纳入扰动试验。网络补全可以帮助探索遮挡区域，但它不提供可直接用于全身避碰的保守保证。

## 阅读与复现检查点

- 能手画 stage-1 与 stage-2 的输入、输出、监督，以及哪个环节从稀疏恢复稠密。
- 核对 depth estimator 的训练来源与输入配置，避免比较时悄悄引入双目或额外数据。
- 分开可视化实测/预测深度、稀疏提案和最终补全，定位误差进入链路的位置。
- 若以后复现，先固定单帧配置，再加历史帧；独立校验历史帧投影和运动模糊影响。
- 输出进入地图前增加 observed/predicted 标记；此字段是建议扩展，不是原始论文已提供的机器人接口。
