# Voxblox：从表面融合得到可用于规划的距离场

## 元数据与证据

- **原题**：Voxblox: Incremental 3D Euclidean Signed Distance Fields for On-Board MAV Planning。
- **作者**：Helen Oleynikova、Zachary Taylor、Marius Fehr、Juan Nieto、Roland Siegwart。
- **发表**：IROS 2017；预印本2016，`arXiv:1611.03631`。
- **来源**：[论文条目](https://arxiv.org/abs/1611.03631)、[代码](https://github.com/ethz-asl/voxblox)、[官方文档](https://voxblox.readthedocs.io/en/latest/)、[规划系统](https://github.com/ethz-asl/mav_voxblox_planning)。
- **证据阅读级别**：摘要、官方README和接口说明；没有逐节复核原文公式、没有运行。未下载PDF/source。核验日期：2026-09-29。
- **定位 / 优先级**：几何重建到碰撞规划的桥梁，P0；原实机为微型飞行器，不是人形。

## 一分钟总结

Voxblox 把 TSDF 的表面融合和 ESDF 的距离查询连接起来，并支持增量更新。读它要回答：为什么漂亮的重建网格还不足以给规划器使用？因为优化器希望快速查询候选位置距最近障碍的距离，而非每次从全部表面重新搜索。[论文摘要](https://arxiv.org/abs/1611.03631)

## 输入与输出

输入是点云/深度观测及位姿；输出包括TSDF、表面网格和ESDF。位姿估计由上游提供。原验证围绕机载建图与轨迹优化，不能直接扩展为足底接触、双臂操作或动态人群避障都已解决。[官方项目](https://github.com/ethz-asl/voxblox)

## 方法详解

基础解释：TSDF把表面附近的有符号距离截断到有限区间，在多帧之间加权融合，可写作 `D_new=(w_old D_old+w_obs D_obs)/(w_old+w_obs)`。零等值面给出表面；融合能平滑测量噪声。该公式用于理解，不替代原文完整噪声模型。

ESDF描述空间点到最近障碍表面的欧氏距离。TSDF常由视线方向局部距离构建，截断区外也没有完整距离，因此不能直接拿TSDF值当全局碰撞间隙。Voxblox从TSDF增量建立ESDF，将新观测的影响传播到相关体素，避免每帧完全重建。[论文条目](https://arxiv.org/abs/1611.03631)

工程阅读应拆成传感器积分、受影响区域更新和查询三层。沿着规划调用查清：返回值是否有效，是否插值，边界如何处理，unknown是否被单独表达。只查看可视化，很容易漏掉规划实际读取的距离含义。[官方文档](https://voxblox.readthedocs.io/en/latest/)

## 实验应该怎样读

摘要报告单CPU核心实时运行；硬件、分辨率和地图规模决定实际速度，不能用这句话承诺你平台的延迟。还应区分表面误差与距离误差：重建表面看起来准确，远处距离近似仍可能影响优化。将建图精度、距离查询误差、规划成功率分开记录。[规划项目](https://github.com/ethz-asl/mav_voxblox_planning)

本调研建议用可解析平面/盒子验证距离，再用真实回放测试薄桌沿、缺测玻璃和传感器遮挡；不要把所有失败归为规划器问题。新障碍出现和旧障碍移除必须分别测试，二者依赖不同证据。

## 局限与人形迁移判断

ESDF适合身体避障、手臂接近与搬物轨迹；脚步支撑仍需高程和接触面。可将身体近似成球或胶囊，结合距障值和形状半径计算余量，但要验证机器人几何覆盖与时间采样误差。拿起物品后，附着物也应进入碰撞体。

缺少距离不能视为无穷远。人形的手臂遮挡、头部摆动和下楼盲区使unknown处理格外重要。位姿误差会让细杆变厚或表面错位，动态人和自身身体也会污染融合，所以自体过滤、地图有效期和运动补偿应当作为基线组成部分。

## 阅读与复现检查点

- 比较同一平面的点云、TSDF零面和ESDF切片。
- 记录体素大小、内存、积分时间、ESDF更新与查询时间。
- 注入小姿态误差，观察墙面和碰撞余量变化。
- 用脚、躯干、手臂三种高度查询桌下与楼梯。
