# EmbodiedOcc++：几何约束与选择性记忆更新

## 一分钟总结

在 EmbodiedOcc 的高斯记忆框架上，它重点处理两个问题：室内墙面、地面等平面结构怎样保持整齐；连续观测重叠区域时怎样把更新集中在不确定的位置。对有几何算法背景的你，这篇很适合理解“几何先验如何进入学习式 OCC”。

## 元数据与证据

- 标题：**EmbodiedOcc++: Boosting Embodied 3D Occupancy Prediction with Plane Regularization and Uncertainty Sampler**。
- Hao Wang 等，2025；[官方仓库](https://github.com/PKUHaoWang/EmbodiedOcc2) 标注 ACM MM 2025 并公布代码发布记录。
- [论文记录](https://arxiv.org/abs/2504.09540)、[已读 HTML v1](https://arxiv.org/html/2504.09540v1)。
- 核验日期：2026-09-29。已阅读方法与实验部分、仓库发布状态；未实际安装运行，未逐文件审计实现。

## 输入输出与方法分解

输入仍围绕含位姿的单目 RGB 连续观测，模型还使用从图像获得的几何先验；输出为高斯记忆解码的三维语义占用。

1. **Geometry-guided Refinement Module（GRM）：** 根据估计法向，将位置更新分解为法向与切向分量；平坦区域限制偏离平面的更新，复杂区域放宽限制。
2. **自适应强度：** 结合曲率和深度信息决定约束权重。
3. **Semantic-aware Uncertainty Sampler（SUS）：** 根据语义不确定性选择重叠区域中需要更新的高斯，减少重复更新。
4. 保留基础框架的局部更新、全局记忆和 Gaussian-to-voxel 输出。[正文 §3](https://arxiv.org/html/2504.09540v1)

## 关键概念解释

设单位法向为 `n`，一个普通位移 `Δm` 可分解为 `(Δm·n)n` 与剩余的切向分量。这是基础向量投影，不是本论文独有。这里的设计意义在于把“表面大致是平面”的先验用于限制网络更新，降低高斯在法向方向无意义漂移。

约束强度不是越大越好：桌沿、椅背和曲面附近若被错误视为平面，约束会损伤细节。因此学习重点应放在什么时候启用、用什么置信度，而不只是记住增加了一个正则项。

## 实验该怎么看

应分别看 GRM、SUS 及联合方案的消融，区分几何一致性和更新效率的贡献。论文的“没有新增可训练参数”表述不能推出没有额外推理成本，因为产生法向、深度和采样决策本身需要计算。报告端到端时间时应把这些前端算进去。[论文](https://arxiv.org/html/2504.09540v1)、[官方仓库](https://github.com/PKUHaoWang/EmbodiedOcc2)

## 局限与人形迁移分析

**作者明确的限制：** 原文结论/局限讨论以静态世界为假设，动态场景属于后续工作。[正文 §5](https://arxiv.org/html/2504.09540v1) 下述移动家具测试因此是超出原设定的迁移压力测试。

**本调研分析：** 这条路线对室内支撑面和大平面有吸引力，但法向误差会直接影响更新方向；人形运动模糊可能降低这些先验质量。语义置信度高也可能是稳定的错误，因此“低不确定性就少更新”需要检查物体移走和类别发生误判时的纠错能力。

你可以设计两组对照：固定相机看静态墙面，检查稳定性；移动一个高置信度家具，检查遗忘与纠错速度。它们分别奖励记忆保持和及时修正。仅用一种静态平均指标难以覆盖这两个目标。

## 阅读与复现检查点

- 先读 [EmbodiedOcc](../embodiedocc/README.md)，确认增量部分。
- 法向的坐标系、归一化和可见性 mask 是否与高斯一致？
- 法向/深度前端用什么权重，是否引入不同训练数据？
- 记录被选中更新的高斯比例、模型耗时和总耗时。
- 对平面、边缘、细物体分别评价，不把大墙面优势直接解释成全身避碰优势。
