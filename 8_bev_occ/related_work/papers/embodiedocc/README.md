# EmbodiedOcc：用显式高斯记忆逐步理解室内场景

## 一分钟总结

它把问题从“单张图像预测当前场景”推进到“随着相机探索，持续更新一个三维语义记忆”。对人形感知最值得学的是局部观察与全局状态如何衔接、回看时如何复用历史。它使用带位姿的 RGB 输入；不是自己解决定位的完整 SLAM 系统。

## 元数据与证据

- 标题：**EmbodiedOcc: Embodied 3D Occupancy Prediction for Vision-based Online Scene Understanding**。
- Yuqi Wu 等；arXiv 2024，ICCV 2025（[官方仓库](https://github.com/YkiWu/EmbodiedOcc) 标明）。
- [论文记录](https://arxiv.org/abs/2412.04380)、[已读 HTML v2](https://arxiv.org/html/2412.04380v2)、[项目页](https://ykiwu.github.io/EmbodiedOcc/)。

## 输入输出和方法分解

输入为 RGB 图像及对应相机几何/位姿；输出为局部或全局三维语义占用。场景以含位置、尺度、旋转、透明度、语义的高斯集合表达。

1. **局部预测：** 图像特征与高斯查询交互，深度感知分支为高斯提供几何提示。
2. **持久记忆：** 全局高斯保存在世界坐标，当前视锥选出的高斯进入局部更新，再写回记忆。
3. **控制更新：** 对已有更新历史与新区域施加不同更新强度，减少重复观测破坏原状态。
4. **生成输出：** Gaussian-to-voxel splatting 将高斯表达转为体素占用；局部训练与在线记忆训练分阶段进行。[正文 §3](https://arxiv.org/html/2412.04380v2)

## 关键概念解释

把它与传统地图比较，有助于理解创新边界：传统地图通常保存传感器累积的几何状态，这里保存可由网络更新的语义高斯。两者都有“地图状态”，但更新依据不同。高斯在数学上有连续空间范围，这不保证解码后的体素表面是精确物理表面；透明度也不能直接解释成校准过的碰撞概率。

世界系与相机系之间变换的正确性很关键。若相机位姿有误，一个历史高斯可能投影到错误像素，随后被错误语义更新。网络的记忆机制无法自动消除这种系统性偏差。

## 实验该怎么看

论文在 Occ-ScanNet 的局部设置与重新组织的 EmbodiedOcc-ScanNet 全局设置评估，并设计回看相关测试。[正文 §4](https://arxiv.org/html/2412.04380v2) 学习时比较局部预测直接拼接与维护记忆，不把二者差异全部归因于“更多帧”。重点看重访区域是否保持一致、局部/全局评价范围是否不同。

## 局限与人形迁移分析

**事实边界：** 核心实验是室内占用基准，不直接证明真实人形动态导航、抓取或落脚成功。

**本调研分析：** 这是连接 BEV/OCC 与机器人建图的优先阅读对象。人形需要补充：姿态和关节驱动的相机变换、场景范围未知时的记忆扩展、动态目标清理、自体过滤、长时间遗忘策略。尤其要测试“转身后再回来”与“物体已搬走再回来”，前者奖励稳定记忆，后者要求及时更新，不能用同一种保守策略解决所有情况。

## 阅读与复现检查点

- 手画从世界记忆选取视锥高斯、变换、更新、写回的全链路。
- 检查 metric depth 前端的训练与推理依赖，单目输入不等于无需深度先验。
- 固定随机种子、位姿和观察顺序比较有记忆/无记忆。
- 对位姿扰动、帧顺序、重复帧做消融；分别报几何与语义错误。
