# OneOcc：全景单相机足式占据与步态扰动

## 元数据与证据

- **原题**：OneOcc: Semantic Occupancy Prediction for Legged Robots with a Single Panoramic Camera。
- **作者**：Hao Shi、Ze Wang、Shangwei Guo、Mengfei Duan、Song Wang、Teng Chen、Kailun Yang、Lin Wang、Kaiwei Wang。
- **发表**：CVPR 2026录用（arXiv作者元数据已注明）；`arXiv:2511.03571`，2025首发，当前v2为2026-03-15。
- **来源**：[论文条目](https://arxiv.org/abs/2511.03571)、[HTML v2](https://arxiv.org/html/2511.03571v2)、[官方仓库](https://github.com/MasterHow/OneOcc)。
- **证据阅读级别**：HTML方法、实验和附录部分、当前摘要及仓库；未运行、未下载PDF/source。核验日期：2026-09-29。
- **开放状态**：仓库仍以说明和图片为主，训练/推理、权重和数据指南在待发布清单；不当成已可直接训练。
- **定位 / 优先级**：P1；足式桥接论文。QuadOcc为真实四足，Human360Occ为CARLA人类视角与模拟步态，均不等于真实人形全身任务验证。

## 一分钟总结

OneOcc研究如何让单个全景相机的360度观测转成语义体素，并处理全景投影和步态引起的扰动。它补齐了六相机+LiDAR、四组双目之外的传感器路线。论文关注的是环境占据，不能据此推断单相机已满足精细落脚和抓取。[当前摘要](https://arxiv.org/abs/2511.03571)

## 输入、输出与数据

输入为标定全景图像，输出周围语义体素。QuadOcc包含24K四足采集帧、6个非空语义类，主要网格为64×64×8、0.4 m体素。Human360Occ用于仿真中的城市内/跨城市测试。[官方README](https://github.com/MasterHow/OneOcc) 真实采集和仿真泛化必须分开报告，不能相加后称为人形数据规模。

## 方法详解

四个组成分别是：DP-ER联合环形图与等距柱状展开；BGV联合笛卡尔与柱坐标体素；AMoE-3D做分层多尺度融合；GDC学习特征采样的位移补偿。[HTML方法](https://arxiv.org/html/2511.03571v2)

从几何角度解释，全景图横轴近似对应方位角，柱坐标表示更自然地维护角度连续性；笛卡尔坐标更容易对接空间碰撞。两种表示之间的转换如果量化粗糙，仍可能在近场边界产生误差。GDC是学习型补偿，不能等价为完整六自由度状态估计，也不能自动替代传感器标定和时间同步。这些是对方法边界的分析。

## 实验应该怎样读

当前表格报告QuadOcc mIoU 20.56；夜间结果13.50低于MonoScene的14.20。至少需要按光照、语义和距离分别读，不能将全天平均优势理解成所有条件最优。[HTML实验](https://arxiv.org/html/2511.03571v2) 论文v2对相较LiDAR的表述已更审慎，综述宜采用当前版本，不照搬旧README中的宽泛优越性措辞。

公平比较还要检查不同模型的输入模态、深度是否真值、体素边界和类别映射。论文附录不同实现的坐标/标签约定存在需进一步核对之处；在代码未释放时，不应自行声称这些适配已完全等价。这里列的是复现审查重点，不是本次实际发现模型运行错误。

## 局限与人形迁移分析

0.4 m体素可以研究场景布局，但不能未经验证用于厘米级足边和手部接触；这是由任务尺寸决定的工程判断。对人形，可保留全景语义分支做周围理解，再以近场深度和细高程补足足底/手部几何。网络看见完整水平环视，也不保证上方、下方和自遮挡区域都有证据。

步态扰动很相关，但四足底盘和人形头部的运动频谱、相机高度、颈部转动不同。应通过真实人形急转、上下楼和低头序列验证，而非只使用模拟周期抖动。如果研究GDC，可与已知姿态重投影、显式IMU补偿和不补偿三者对比，以确认学到的是运动补偿还是数据集偏置。

## 阅读与复现检查点

- 先读v2方法和附录，核对模型在QuadOcc/H3O采用的投影变体。
- 可视化环形图展开接缝，确认360度边界连续。
- 检查标签0/255、free/unknown、xyz轴和网格原点。
- 分别评估姿态扰动、照明和距离；增加近场障碍漏检指标。
- 复现准备先做投影与标定回放；等官方训练实现后再锁定代码版本。
- 对照[Humanoid-OmniOcc](../humanoid_omniocc/README.md)评估全景单目与环视双目的深度约束和算力代价。
