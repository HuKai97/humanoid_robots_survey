# BEVFormer：把图像与历史记忆汇入 BEV

## 论文与证据

- **标题**：BEVFormer: Learning Bird's-Eye-View Representation from Multi-Camera Images via Spatiotemporal Transformers。
- **作者 / 年份**：Zhiqi Li 等；ECCV 2022，arXiv 首发 2022。
- **主来源**：[arXiv 记录](https://arxiv.org/abs/2203.17270)、[正文 HTML，v2](https://arxiv.org/html/2203.17270v2)。
- **官方代码**：[fundamentalvision/BEVFormer](https://github.com/fundamentalvision/BEVFormer)，论文记录直接链接，已阅读仓库说明；注意网上有同名 fork。本次未下载源码、PDF、数据或权重，未执行复现。
- **阅读证据级别**：摘要、HTML §3.1–3.4 与实验段落、官方仓库 README；针对性初读，非逐页全文精读。核验日期：2026-09-29。

## 一分钟总结

BEVFormer 在每个 BEV 格子放一个可学习 query，让它向当前多相机图像查询信息，并向上一时刻 BEV 查询历史信息。关键是空间采样与时间记忆共同构造一个可供多个任务使用的表示。对传统机器人背景，最值得学的是“已知位姿负责粗对齐，学习模块负责内容关联”这一分工。[论文摘要](https://arxiv.org/abs/2203.17270)

## 任务、输入和输出

输入是当前多相机图像、标定与运动信息，加上历史 BEV 状态；输出是统一 BEV 特征，后接三维检测或地图分割头。历史状态是网络内部记忆，不能当作永久地图；原论文也不是三维稠密占据预测器。[官方仓库](https://github.com/fundamentalvision/BEVFormer)

## 方法拆解

1. **网格 query**：为 BEV 每个位置定义查询向量，并加入位置编码。
2. **空间交叉注意力**：在该格的不同高度建立三维参考点，通过标定投影到可见相机；在附近少量位置采样图像特征。
3. **时间自注意力**：先按自运动对齐历史 BEV，再学习从历史与当前 query 汇聚信息。
4. **共享表示**：重复编码后得到当前 BEV，检测与分割任务头从中解码。[正文 §3](https://arxiv.org/html/2203.17270v2)

理解 query 时不要把它等同于物体。这里的 query 首先代表空间位置，某格可能包含路面、行人线索或者暂时无直接观测。deformable attention 的直观含义是“围绕几何投影位置查少量可学习邻域”，并非遍历所有像素寻找对应。历史对齐只补偿机器人自身运动，移动物体还需要跨时刻关联；这两类运动不能混在一个刚体变换里解决。

## 实验应看什么

摘要强调三维检测、速度估计及低可见目标的收益，仓库给出 tiny、small、base 等不同资源配置。学习时优先比较是否使用历史信息、同一 backbone 和图像尺寸下的变化，再看单一最终分数。公开仓库的初版模型与论文最强配置并非同一条结果；复现目标必须具体到配置和评测划分。[摘要](https://arxiv.org/abs/2203.17270)、[模型表](https://github.com/fundamentalvision/BEVFormer)

## 局限与对人形机器人的迁移价值（分析）

BEV 历史记忆很适合缓解转头、短暂遮挡与相机视场有限，但这依赖可靠的时间戳和运动补偿。人形行走时机身有上下摆动及俯仰、横滚；如果先把空间压成平面再用平面变换对齐，不同高度结构可能无法同时对齐。因此迁移时要先明确 BEV 的参考平面，并检验是否应在完整三维空间补偿后再聚合。

高度参考点让 query 能读取不同高度线索，并不意味着最终输出具有显式高度分辨率。将它用于楼梯、桌下通行或手臂避碰，还需增加三维解码与相应监督。另一风险是长期缓存旧障碍：障碍被搬走后，强时间先验可能比当前观测更保守，也可能在观测突然恶化时产生错误延续。需要对新出现、消失和跨越视野边缘的障碍分别测更新延迟。

## 阅读与复现检查点

- 画出一个 BEV query、多个高度参考点与相机成像位置的对应关系；检查相机后方点、出图点的有效掩码。
- 使用静态场景与纯机器人运动检查历史对齐；再加入移动目标，区分配准误差与目标运动。
- 核验序列边界何时清空缓存、训练是否随机打断历史、在线推理是否只用过去帧。
- 分别记录单帧计算延迟、历史状态显存、端到端时间戳延迟；不能由论文 GPU 速度推断机载速度。
