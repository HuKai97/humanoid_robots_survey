# OccWorld：从当前三维占用走向未来状态预测

## 一分钟总结

OccWorld 把三维占用编码成离散 token，再根据历史预测未来场景和自车运动。它说明 OCC 可以成为预测和决策研究的状态表示，不只是感知输出。对人形学习者应放在后期：首先要有可靠的当前状态，然后才讨论未来预测。

## 元数据与证据

- 标题：**OccWorld: Learning a 3D Occupancy World Model for Autonomous Driving**。
- Wenzhao Zheng 等；arXiv 2023，ECCV 2024（[官方仓库](https://github.com/wzzheng/OccWorld) 标明）。
- [原始记录](https://arxiv.org/abs/2311.16038)、[已读 HTML](https://arxiv.org/html/2311.16038)。
- 核验日期：2026-09-29。已读任务、tokenizer 与预测框架，并查官方训练/评价入口；没有运行代码或核验本地延迟。

## 输入输出与方法分解

核心世界模型接收历史三维语义占用及自车状态，预测下一时刻的占用与自车运动，之后可以自回归展开。

1. 给占用类别嵌入，将高度信息组织到 BEV 通道。
2. 用 VQ-VAE 学习紧凑的离散场景 token，并训练重建。
3. 在离散表示上做时空建模，预测未来场景与运动。
4. 解码回体素空间用于几何、语义和规划相关评价。[正文 §3](https://arxiv.org/html/2311.16038)

## 关键概念解释

VQ-VAE 的 codebook 可以理解为可学习的局部模式词典。它减小预测问题规模，但压缩过程会损失细节。因此应先测“真值占用 → token → 重建占用”，再测未来预测；否则不清楚椅腿等结构是感知漏了、压缩丢了还是预测错了。

自回归是把自己的预测再送回模型继续预测。预测步数增加时，误差会累积。单步效果好不代表长时间滚动预测稳定，更不等于模拟具备真实接触物理。

## 实验该怎么看

官方项目展示不同占用来源与相应训练/评价方式。[官方仓库](https://github.com/wzzheng/OccWorld) 阅读时逐项区分：输入是真值 occupancy、传感器生成标签还是模型预测；是否使用额外运动监督；规划指标的碰撞计算采用哪种标签与协议。不同输入信息量的结果不能只按模型名排序。

## 局限与人形迁移分析

**事实边界：** 本文对象是自动驾驶。当前证据不能推出对人形关节运动、足地接触或双手操作建模有效。

**本调研分析：** 占用 token 能帮助你思考空间状态压缩与长期预测，但人形任务需要更丰富的动作/状态条件。身体移动、头部转动、手臂操作可能引起不同场景变化，不能仅靠一个平面轨迹概括。对接触任务，还应考虑物体运动与机器人动作的因果关系，而非只学视频中的统计相关。

## 阅读与复现检查点

- 分开测 tokenizer 重建、单步预测、多步 rollout 和下游任务。
- 用当前状态直接保持不变、依据位姿变换等简单基线作参照。
- 所有预测输入限定为当前及历史，明确训练时 teacher forcing 与测试滚动差异。
- 总体 mIoU 之外，检查动态参与者、边界与远期误差。
