# FIERY：从当前 BEV 走向未来动态实例

## 论文与证据

- **正式标题**：FIERY: Future Instance Prediction in Bird's-Eye View from Surround Monocular Cameras。
- **作者 / 年份**：Anthony Hu、Zak Murez 等；ICCV 2021（官方仓库标 Oral）。
- **主来源**：[arXiv 记录](https://arxiv.org/abs/2104.10490)、[正文 HTML](https://arxiv.org/html/2104.10490)、[作者官方仓库](https://github.com/wayveai/fiery)。

- **阅读证据级别**：摘要、HTML §3 模型关键段、评价指标与消融段、官方配置表；针对性初读，未下载 PDF/权重/数据。核验日期：2026-09-29。

## 一分钟总结

FIERY 用过去的环视图像估计 BEV 状态，再预测多个时刻的实例形状与运动，并通过潜变量描述未来的多种可能。它将“看见什么”推进到“接下来哪里会被动态对象占用”，但预测的是 BEV 动态实例，不应称为全空间三维占据预测。[论文摘要](https://arxiv.org/abs/2104.10490)

## 任务、输入和输出

输入为一段多相机图像、标定及过去自运动；输出当前及未来的 BEV 实例分割、运动信息，可形成轨迹。方法无需 HD 地图作为输入。官方基线配置记录历史时间窗、未来时间窗、网格范围与分辨率，比较成绩必须同时固定这些参数。[摘要](https://arxiv.org/abs/2104.10490)、[官方配置表](https://github.com/wayveai/fiery)

## 方法拆解

1. 每个时刻用 LSS 风格视锥展开构造 BEV 特征。
2. 根据已知过去自运动，把历史 BEV 对齐到当前参考系，再编码时空状态。
3. 训练时以观测未来构造条件分布；推理时仅从当前状态的分布采样潜变量。
4. 递归预测未来状态，解码语义、实例中心、中心偏移与实例运动。[正文 §3](https://arxiv.org/html/2104.10490)

中心偏移可以理解为“本格属于哪个实例中心”；流则提供跨时刻对应。二者用途不同，不能将一个位置向中心的向量当作速度。多模态未来也不是多种传感器模态，而是未来有多种可能，例如同一行人可能停下或继续走；用平均轨迹可能落在实际上不会发生的位置。

## 实验看点

论文使用 nuScenes 与 Lyft，除了逐格 IoU，还评价跨时间实例一致性及概率预测。官方仓库分别列出不同空间范围与未来时长的配置，说明了为什么不能只摘取单个最高分。HTML 消融重点包括历史上下文、自运动对齐、未来流和概率建模。[正文实验与消融](https://arxiv.org/html/2104.10490)、[仓库](https://github.com/wayveai/fiery)

从学习角度应先复现“静态保持”和“匀速外推”两个朴素对照，弄清模型在哪些交互场景赢得收益，再加入潜变量。未来预测结果的好看程度不能替代概率覆盖与误报代价评价。

## 局限与对人形机器人的迁移价值（分析）

在人机共处场景，机器人仅依据当前占据避障可能在下一步与行人冲突；FIERY 提供把动态预测接入 BEV 的思想。对人形机器人，未来空间需求不只是机身中心轨迹，还包括摆动腿、展开的手臂和所搬物体的扫掠范围，因此应将预测对象与全身规划器的占据时间窗对齐。

道路车辆数据的运动规律不能直接迁移到室内人群、伸手交接物体或狭窄空间侧身避让。额外还要检验强烈头部运动导致的假运动，以及新进入视野的对象缺少历史时如何处理。二维实例足迹对人体上肢、桌面物体等高度结构不足，可以作为动态粗预测层，与局部三维几何层组合，而不是取代全部几何感知。

训练使用未来标签是监督学习允许的，在线推理使用未来图像或未来位姿则会造成信息泄漏。迁移和复现时尤其应检查数据加载器如何切历史、当前与未来，不能只检查网络前向函数。

## 阅读与复现检查点

- 画清历史特征、当前参考系与未来标签的坐标关系；检验位姿变换方向。
- 区分语义 IoU、实例识别、跨时间 ID 一致性和概率预测指标，保持相同空间范围和时域。
- 将机器人静止、机器人运动、对象运动分开构造小测试片段，定位假运动来源。
- 概率预测比较不同采样数时记录计算量；规划使用预测前评估不确定性是否经过校准。
