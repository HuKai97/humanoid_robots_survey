# Lift-Splat-Shoot：从相机几何进入 BEV

## 论文与证据

- **标题**：Lift, Splat, Shoot: Encoding Images From Arbitrary Camera Rigs by Implicitly Unprojecting to 3D。
- **作者 / 年份**：Jonah Philion、Sanja Fidler；ECCV 2020。
- **主来源**：[作者项目页](https://research.nvidia.com/labs/toronto-ai/lift-splat-shoot/)、[arXiv 记录](https://arxiv.org/abs/2008.05711)、[正文 HTML](https://arxiv.org/html/2008.05711)。
- **官方代码**：[nv-tlabs/lift-splat-shoot](https://github.com/nv-tlabs/lift-splat-shoot)，由作者项目页直接链接，已核验仓库 README；未下载源码、权重、数据或 PDF，未运行。
- **阅读证据级别**：项目页、摘要、HTML 方法关键段及仓库说明；属于有针对性的初读解析，不声称逐页精读。核验日期：2026-09-29。

## 一分钟总结

LSS 把每个图像位置的语义特征沿多个候选深度展开，再用标定把这些特征汇总到共同 BEV 网格。它把传统“反投影—坐标变换—栅格累积”变成可训练的特征变换，是从传统轮式机器人感知进入视觉 BEV 最适合先读的一篇。论文还展示 BEV 成本图上的轨迹选择。核心价值是统一几何表达，不应把输出直接解释为经过概率标定的自由空间地图。[项目页](https://research.nvidia.com/labs/toronto-ai/lift-splat-shoot/)

## 任务、输入和输出

输入为多相机图像及内外参；学习目标包括车辆、车道或可行驶区域的 BEV 分割，另有规划演示。基础方法不要求训练或测试时提供深度传感器。输出位于选定参考系的二维栅格，每格是特征或任务预测；它不是每个三维体素的占据概率。[正文 §3](https://arxiv.org/html/2008.05711)

## 方法拆解

1. **Lift**：图像编码器给出上下文向量和离散深度权重，二者组合为相机视锥内特征。
2. **Splat**：按已知相机几何将候选三维位置变到公共参考系，对同一 BEV 单元内的特征进行聚合，再交给 BEV 网络。
3. **Shoot**：在预测成本图上评估固定候选轨迹，以示范轨迹为监督；这是论文的规划连接方式。[正文 §3](https://arxiv.org/html/2008.05711)

给传统感知工程师的解释：点云栅格化是“某个量测落在哪格”，LSS 是“这个图像特征可能属于哪些深度，并向相应格贡献多少”。深度分布由下游任务牵引，权重有用不等于距离数值可靠。你熟悉的相机模型仍然决定投影位置，神经网络主要学习特征内容和分配权重；几何标定不会因为端到端训练而变得可有可无。

## 实验看点、局限与边界

项目页展示 nuScenes 的 BEV 分割，并考察相机缺失、外参变化与跨相机平台迁移。官方仓库提供数据投影可视化入口，也明确给出论文结果与公开权重结果的差异，适合学习复现实验如何核对配置。[项目页](https://research.nvidia.com/labs/toronto-ai/lift-splat-shoot/)、[仓库说明](https://github.com/nv-tlabs/lift-splat-shoot)

阅读时优先问：相机减少时是已有重叠观测在补偿，还是网络按道路先验补全？后一种能力对分割可能有用，却不能自动成为足部落点的几何证据。论文的道路数据和分割目标也没有证明对楼梯、桌板下方空间、透明障碍或近距离细杆的安全性。

## 对人形机器人的迁移价值（分析，非论文结论）

建议复用的是相机到公共空间的几何接口，先在人形机器人局部重力对齐坐标系中建立小范围 BEV。头部相机相对身体会随关节变化：每帧外参应来自时间同步的关节位姿与机身状态估计。机器人低头、转头、蹲下后仍用固定车载外参，错误会被网络看成环境移动。

输出应按用途拆开：水平导航可使用 BEV 语义或成本；足步与手臂避碰需要保留高度、未知空间及可观测性。一个可行入门实验是用已知 RGB-D 点云作为几何参考，在同一局部网格比较 LSS 与直接点云栅格化，观察台阶边沿和头部俯仰变化时两者的系统性偏差。

## 阅读与复现检查点

- 先手算一个像素在两个深度假设下变到机器人坐标系的位置，确认单位、轴向与矩阵方向。
- 画出图像特征、深度维、视锥特征、BEV 特征的张量形状；估计分辨率翻倍的内存代价。
- 查图像裁剪缩放后内参如何更新，验证点云叠图；官方 README 的 `lidar_check` 是阅读入口，不是本次已执行步骤。
- 将“无观测”“未占据”“被遮挡”分别设计标记，不把分割背景类直接当作机器人可穿越空间。
