# Occ3D：先理解标签与可见性，再比较 OCC 网络

## 一分钟总结

**定位：必须精读的数据和评测基础。** Occ3D 的重要性不只是一套基准，而是把“稠密占据真值怎么来、哪些位置可评价”作为核心问题。它通过点云聚合、遮挡推理和图像引导修正构建 Waymo/nuScenes 占据标签，并提供 CTF-Occ 基线。对要自己采集人形数据的工程师，这篇常比再读一个更复杂的网络更有价值。[NeurIPS 原始页](https://papers.neurips.cc/paper_files/paper/2023/hash/cabfaeecaae7d6540ee797a66f0130b0-Abstract-Datasets_and_Benchmarks.html)

- **官方入口**：[项目页](https://tsinghua-mars-lab.github.io/Occ3D/)、[数据与代码仓库](https://github.com/Tsinghua-MARS-Lab/Occ3D)。已核验 README 对数据、mask 和基线的说明；未下载数据和论文，未运行基线。

## 任务与输入输出

给定当前或历史环视图像及相机参数，输出指定三维空间的占据与语义。必须区分 **occupied、free、unobserved**；它们是观测状态，不能只靠语义类别编号理解。论文对可见性敏感的评测有明确设计，与把所有遮挡区都作为 SSC 目标的协议并不相同。[论文任务定义与可见性](https://arxiv.org/html/2304.14365#S3)

## 方法：标签生成流程

1. **增密**：静态背景按全局位姿聚合；动态对象需要按对象坐标对齐，再放回目标时刻。对未标注点传递语义，并以表面重建缓解孔洞。
2. **可见性**：从 LiDAR 和相机位置做射线遍历；射线穿过且无表面的位置支持 free，击中表面支持 occupied，无证据的位置保留 unobserved。
3. **图像引导修正**：用图像语义检查三维标签投影，缓解位姿噪声导致的物体边缘变厚。
4. 用三维到二维语义一致性衡量标签质量；CTF-Occ 则通过逐级细化体素查询得到预测。[论文 §3–5](https://arxiv.org/html/2304.14365)

## 关键概念解释

**可见性 mask** 规定哪些位置参与监督或评价；改变 mask 就改变了任务难度。**标签增密** 是离线使用更多观测构建监督，不代表模型在线推理时能读取未来帧。**General Object** 表示预设类别之外的一般物体，不等价于开放词汇识别；几何上发现障碍与为任意自然语言词汇赋义是不同能力。

官方标签存储包含语义和可见性信息；实际复现要读取当前版本字段解释，尤其不要把数组里默认的空类当成“传感器已经证实为空”。同为 nuScenes 的 Occ3D、SurroundOcc 等标签不是可互换文件。[官方数据说明](https://github.com/Tsinghua-MARS-Lab/Occ3D)

## 实验应看什么

先看标签生成每一步对投影一致性的影响，再看网络排名。自建数据时建议检查：静态背景是否重影、动态物体是否拉成长条、细杆是否被增密算法抹掉、地面是否过度平滑。定量对比必须写全数据版本、体素范围、分辨率、类别映射、camera/LiDAR mask 及训练 mask 与测试 mask 是否一致。

还应对照 [SparseOcc](../sparseocc/README.md) 的 RayIoU 分析：只在某种可见区域测 mIoU 可能无法充分暴露厚表面等问题。不同论文协议的分数不能排成一张直接可比榜单。

## 局限与人形迁移分析（本调研推断）

车载类别和空间分辨率不天然适合足底台阶、桌腿、扶手及低矮悬空障碍。人形自建标签的首要工作应是确定身体附近需要回答的问题：哪里可落脚、哪里有碰撞风险、哪里尚未观察。语义 occupancy 自身不会给出摩擦系数、承重能力和步态可达性。

建议把其数据流水线迁移思想用于短程 RGB-D/双目序列，加入头部与关节运动的精确时间戳、机器人自身几何剔除和局部位姿质量检查。对未知区域保留状态；不要为了得到漂亮的稠密标签就无条件补洞。训练集与验证集按场景或轨迹拆分，避免相邻帧泄漏。

## 阅读与复现检查点

- 先制作标签字典，分别描述 empty/free、unknown/unobserved、ignore、各语义类。
- 用同一帧画 LiDAR mask 与 camera mask，并解释二者差异。
- 把离线真值构建输入与在线模型输入分别列出，显式审计未来信息是否进入模型。
- 人工检查少量有代表性的原始传感器/标签投影，再批量生成训练数据。
- 第一版评价同时保留几何召回、误占据、语义 mIoU、距离分桶和身体高度分桶；这些附加指标是人形迁移建议。
