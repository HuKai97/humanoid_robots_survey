## 一分钟总结

BEVDet 用图像编码器、LSS 风格视角转换、BEV 编码器与检测头搭出清晰范式，并强调数据增强和后处理怎样与 BEV 几何匹配。它适合夹在 LSS 与 BEVDepth 之间阅读：前者解释如何得到 BEV，BEVDet 解释如何把这个表示训练成有效检测系统。[论文摘要](https://arxiv.org/abs/2112.11790)

## 任务、输入和输出

输入多相机图像与几何参数，输出三维目标框及相关属性。论文研究 nuScenes 三维检测，模型的 BEV 中间表示不自动等于 occupancy。人形工作若关注不规则障碍或脚边地形，需要另外定义输出与监督。[正文 §3](https://arxiv.org/html/2112.11790)

## 方法拆解

1. 图像骨干和 neck 提取多尺度特征，视角转换将其移入 BEV。
2. BEV 编码器加工公共空间特征，使用 CenterPoint 第一阶段风格的检测头。
3. 分开处理图像域增强与 BEV 域增强，确保几何和标签变换一致。
4. Scale-NMS 根据类别调整用于抑制重复框的尺寸关系，改善小足迹对象的后处理。[正文 §3](https://arxiv.org/html/2112.11790)

最值得理解的概念是两个增强空间。若对图像裁剪或旋转后，几何转换中正确撤销了这个变化，最终物理场景位置并没有随之变化；因此图像域的数据多样性不能完全替代 BEV 空间的多样性。反过来，如果主动旋转 BEV 特征，则标签也必须一致旋转，方向和速度向量也要被正确变换。

Scale-NMS 是重复预测清理规则，不是把实际障碍物尺寸永久放大。人形部署中的安全膨胀属于规划/碰撞检查接口，应与检测 NMS 清楚区分，否则容易把感知后处理阈值误认为身体安全裕量。

## 实验看点

原文围绕图像增强、BEV 增强、BEV 编码器、分辨率与 NMS 做消融。学习时应关注训练是否提前过拟合，以及不同域增强的组合，而不是只看最终 NDS。当前官方仓库已增加 BEVDet4D 等后续方法；复现原论文时需锁定具体分支、提交与配置。[正文 §4](https://arxiv.org/html/2112.11790)、[系列仓库](https://github.com/HuangJunJie2017/BEVDet)

## 局限与对人形机器人的迁移价值（分析）

这里最可迁移的是实验工程：把视角变换、空间编码、任务输出分清，再为每一层验证数据与增强。人形相机在关节链末端，图像增强处理与真实相机运动是两回事；前者是训练变换，后者应通过每帧标定和位姿进入物理几何，二者混淆会破坏标签对齐。

在室内任务上，不能原封不动照搬道路对象类别及 NMS 类别尺寸先验。椅腿、线缆、开放柜门等对行走与手臂都重要，但很难用道路检测类别完整覆盖。可以把 BEVDet 当作学习多相机几何的基线，后续用占据表达未分类障碍；“没有输出检测框”绝不能等价于“可安全穿过”。

如果只做第一项小实验，建议固定所有几何和骨干，在同一人形采集数据上比较无增强、仅图像增强、仅空间增强及两者组合，并按真实头部视角变化分组评价。该实验是未来计划，本次未执行。

## 阅读与复现检查点

- 对一个增强前后的三维点验证重投影一致性，检查 crop/resize/flip 的矩阵顺序。
- 查旋转后的朝向与速度标签是否同步更新，避免只旋转框中心。
- 分别计图像分辨率和 BEV 网格分辨率的计算开销，两者影响不同。
- 官方系列仓库中的加速算子与后续时序方法需独立登记，不与原论文结果混用。
