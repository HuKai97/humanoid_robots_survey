# 分阶段学习路线

建议按 8–10 周业余/工作结合节奏理解；这是安排建议，不是对用户截止时间的假设。每阶段以可交付成果作为完成条件。当前没有下载或执行这些实验。

| 阶段 | 建议用时 | 核心阅读 | 要完成的成果 |
|---|---|---|---|
| 0：任务和几何 | 1周 | 领域地图、术语、OctoMap、Voxblox | 用一页纸画坐标链，解释 free/unknown、BEV/SSC/ESDF 区别 |
| 1：视觉到 BEV | 1–2周 | LSS、BEVDet、BEVDepth、BEVFormer、Simple-BEV | 手写小规模投影/反投影和 voxel pooling；可视化误差传播 |
| 2：三维占用 | 1–2周 | SSCNet、MonoScene、TPVFormer、VoxFormer、SurroundOcc | 跑通一个已有 checkpoint 的推理与官方评测，先不重训 |
| 3：数据与评测 | 1周 | Occ3D、OpenOccupancy、EmbodiedScan | 写清两个基准的 mask、类表、空间范围、时序可用信息 |
| 4：室内在线感知 | 1–2周 | EmbodiedOcc、SliceOcc、EmbodiedOcc++、RoboOcc | 对比独立帧拼接与带记忆输出，做位姿扰动和回看分析 |
| 5：人形迁移 | 1周 | Humanoid Occupancy、Humanoid-OmniOcc、OneOcc | 对照你的候选传感器画近场盲区，确定局部地图坐标和范围 |
| 6：任务分支 | 1–2周 | 高程建图/ViPlanner；VLMaps/ConceptGraphs；SparseOcc/GaussianFormer；FIERY/OccWorld | 选一个分支做受控实验，记录失败样例并提出可检验问题 |

所有论文入口见 [PAPER_INDEX.md](PAPER_INDEX.md)。阶段可以重叠；如果只需要快速建立概念，先读每篇“一分钟总结”，之后按需求读详解。

## 你可以复用的能力与需要补齐的能力

| 已有轮式经验 | 直接复用 | 需要扩展 |
|---|---|---|
| 传感器标定和时间同步 | 多模态融合前置条件 | 可动相机运动链、IMU和关节同步、自体遮挡 |
| 点云与地图 | 空间离散化、地图更新、可视化 | voxel/TPV/Gaussian 特征与学习式解码 |
| SLAM和里程计 | 多帧对齐和全局一致性 | 感知网络对位姿误差的鲁棒性、回看记忆 |
| costmap和规划接口 | 地图消费者需求 | 多高度碰撞、足底支撑、摆腿空间、操作距离 |
| 模型部署 | 算子、延迟、资源管理 | 三维稀疏算子、时序缓存、深度前端总成本 |

## 推荐的三个起始 baseline

1. **几何参照：深度/点云 → 局部占用或 TSDF/ESDF。** 有深度时优先建立它，帮助分辨是几何数据问题还是网络问题。候选 OctoMap、Voxblox、nvblox 的选择依据是平台与接口，而非简单比较论文年份。
2. **学习参照：MonoScene 或室内 EmbodiedScan baseline。** 前者有利于理解单目补全，后者更贴近室内多模态。先固定一个数据集与一个输入设定，不一次更换网络、数据和传感器。
3. **在线参照：EmbodiedOcc。** 在单帧与评测跑通后学习显式记忆；与无记忆拼接、位姿真值和扰动位姿对照。不要从复杂世界模型直接开始。

## 传感器尚未确定时的分支选择

| 候选输入 | 优先补课 | 先验证的风险 |
|---|---|---|
| RGB-D | TSDF/ESDF、深度融合、RGB语义 | 有效测距、反光/透明物、深度空洞与近场盲区 |
| 双目 | 标定、视差/深度置信度、多视角 | 纹理不足、遮挡、曝光差异、基线与近场范围 |
| 多目 RGB | LSS、BEVFormer、单目度量深度 | 尺度、外参、域变化、头部运动与历史错位 |
| RGB + LiDAR | BEVFusion、人形重力对齐、动态点云 | 自体过滤、扫描畸变、安装盲区、同步 |

这些是要验证的维度，不是购买建议。平台选型之后再定体素大小、更新频率、显存预算、训练规模和发布格式。

## 怎样算真正读懂一篇

不看论文，能在白板上画出输入到输出；能说出训练时额外使用了什么；能找到官方评测的 mask 和类别映射；能解释一个失败案例；能列出哪一个假设在人形上最可能失效。只记住模型名称和 mIoU 不算完成。

## 怎样形成研究问题

在相同评测下复现至少一个几何方法与一个学习方法。固定十个困难片段，记录细障碍、反光、转身、重访、动态人和台阶的错误，再选一个有重复证据的问题。把改动写成能被消融推翻的命题，例如“在固定计算预算下，加入关节驱动的动态外参能否降低头部转动期间的时序重影”，不要预先宣称创新或有效。
