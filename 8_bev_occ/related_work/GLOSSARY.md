# 术语与最小数学基础

本页为教学解释；符号是统一教学约定，不冒充各篇论文的原符号。方法来源见 [论文索引](PAPER_INDEX.md)。

| 术语 | 含义 | 常见混淆 |
|---|---|---|
| BEV, Bird's-Eye View | 以俯视空间索引组织的图像、特征或输出 | 不等于二值占用，不保证含精细三维几何 |
| Occupancy mapping | 由观测更新空间占用状态或信念 | 不等于一定补全未观察物体 |
| Occupancy prediction | 从输入推断空间占用，可结合学习先验 | 不等于输出全是已观测事实 |
| Semantic occupancy | 占用和语义类别的联合表达 | 类别数是否含 free 要查协议 |
| SSC | Semantic Scene Completion，补全场景几何和语义 | 点云语义分割只标已有点，任务不同 |
| Free / occupied / unknown | 自由、占据、未知 | unknown 不是可通行，也不必是训练中的显式类别 |
| Visibility mask / ignore mask | 可见性范围 / 不参加损失或评分的区域 | 标签存在不意味着当时可观察 |
| Voxel | 规则三维空间单元 | 分辨率单位通常是米，别把体素边长写成体积 |
| TSDF | 截断的有符号距离场，通常通过沿视线的测量融合 | 数值并不普遍等于最近障碍的欧氏距离 |
| ESDF | 到表面/障碍的欧氏有符号距离表达 | 由 TSDF 转换也要规定未知区域怎么处理 |
| Elevation map | 通常按 xy 格子存高度及相关统计量 | 单层高程不足以表达桌面和桌下同时存在 |
| Traversability | 给定机器人和任务条件下的可通行性 | 是地形、机器人能力和运动状态的关系 |
| Affordance | 场景支持的行为，如可抓取、可坐、可支撑 | 不能只凭语义类别决定 |
| Lift / splat / voxel pooling | 将图像特征提升到三维候选位置并聚合 | 深度分布提升不等于已知真实深度 |
| Deformable attention | 用有限可学习采样点做特征交互 | 可减少采样成本，但总体性能仍受表示规模影响 |
| TPV | 三个正交平面表示三维信息 | 与完整三维体素逐位置独立特征不同 |
| Semantic Gaussian | 带几何和语义属性的三维高斯基元 | 透明度不是自动校准的占用概率 |
| Ego-motion / pose | 机器人/相机自身运动与位姿 | ego 坐标未必重力对齐，也未必固定高度 |
| Temporal fusion / memory | 融合历史观测或维护状态 | 多帧输入不自动等于长期在线建图 |
| Occupancy flow / forecasting | 占用运动信息 / 未来占用预测 | 两帧占用差异也可能只是相机视角变化 |
| Closed-set / open-vocabulary | 固定类别集合 / 用语言查询较开放的概念 | 开放词汇模型仍会漏检，也需几何支持 |
| IoU / mIoU | 交并比 / 按类别平均交并比 | binary、semantic、point、voxel、ray 指标不混用 |
| Oracle | 使用额外真值信息的参照 | 必须标明额外信息，不能冒充可部署模型 |

## 1. 投影与反投影

令 `T_AB` 将 B 系坐标变到 A 系，齐次点满足 `p_A = T_AB p_B`。针孔相机中，像素齐次坐标 `u~=(u,v,1)` 和相机 z 深度 `d` 给出 `p_C = d K^-1 u~`。这里的 `d` 不是沿射线的欧氏距离，使用不同深度定义时要换算。

将三维点写成四维齐次点 `p~_C=[p_C^T,1]^T` 后，从相机到世界：`p~_W = T_WB(t) T_BC(t) p~_C`。若相机固定在可动头部，`T_BC(t)` 应由关节链和标定计算；若 B 取躯干坐标、相机固定于躯干，则 `T_BC` 为常量，变化的是世界系相机位姿 `T_WC=T_WB(t)T_BC`。若 B 取骨盆等其他基座，还需计入腰部运动链。先统一时间戳，再讨论时序网络。

## 2. 占用概率与 log-odds

对体素占用概率 `p`，定义 `l=log(p/(1-p))`。在简化条件独立假设下，递推可写成 `l_t=l_(t-1)+l_sensor-l_prior`，实际系统通常还做上下限截断。这解释为什么多次一致观测能增强信念，也解释为何相关观测或错误位姿会反复强化错误。

学习式 softmax 输出是模型分类分数。要用于工程决策，应测校准和不同分布下的可靠性；不能仅因取值在 0 到 1 就把它当作传感器后验。

## 3. 三维分辨率为什么昂贵

教学例子：范围 `10m × 10m × 3m`，体素边长 `0.1m`，共有 `100×100×30=300,000` 个体素。若每格 64 个 float32 特征，仅这一层约 `76.8 MB`（十进制），还未计反向梯度、优化器、其他层和缓存。边长减半，体素数变为 8 倍。这不是某论文显存测量。

因此近场高分辨率、远场粗分辨率、稀疏体素、高斯或多平面各有研究价值，但比较时需固定空间范围和有效输出精度。

## 4. 指标的解释

`IoU_c = TP_c / (TP_c+FP_c+FN_c)`；`mIoU` 是指定类别的平均。报告时必须附上类别集合、free 是否计入、ignore/visibility mask、体素大小和标签版本。只报 overall accuracy 容易被大量空体素主导。

面向人形任务还应分开统计：实际障碍被误判成自由的比例、近场细障碍召回、支撑面误差、时间延迟与地图残影。定义见 [测评协议](../experiment/evaluation.md)。
