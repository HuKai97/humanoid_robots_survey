# 从轮式感知到人形 OCC 的复现路线

**状态：计划骨架，尚未安装模型、下载数据或运行实验。** 当前只保存调研与设计材料。硬件、相机配置和可用数据待确定，因此以下顺序是学习与诊断路线，不是已经证明的最优选型。先阅读 [评价草案](../experiment/evaluation.md)，每次尝试使用 [报告模板](report_template.md) 登记。

## 阶段 0：传统几何基线

从你熟悉的深度/点云、位姿变换、射线占据或距离场开始，建立局部三维地图。先确保相机轴、重力方向、单位、时间戳、关节外参和自体过滤正确；输出明确区分 occupied、free、unknown。它提供可解释的几何参照，但若没有语义支路，不参加语义 mIoU 排名。

第一项验收是固定序列回放：输入表面与地图投影能对齐，动态物移走后清除规则明确，重新观察未知区能够更新。不要先追求整屋漂亮模型；先保留脚边障碍、桌下空隙和头顶障碍，再逐步扩展范围。[Occ3D](../related_work/papers/occ3d/README.md) 可帮助理解射线证据与标签可见性。

## 阶段 1：LSS 小练习

用已有 [LSS 解析](../related_work/papers/lift_splat_shoot/README.md) 理解图像特征、深度分布、三维提升和 BEV 聚合。练习重点是标定与张量含义：把已知三维点投到图像，再返回预期网格；检查裁剪缩放后的内参和有效视图。用简单平面、箱体和不同高度障碍验证几何链。

LSS 主要帮助学习二维到三维/BEV 的联系；仅完成 BEV 输出不等于复现完整语义 OCC，也不能直接与三维 occupancy 模型比 mIoU。验收产物是坐标示意、投影可视化和输入输出说明，不预设分数提升。

## 阶段 2：清晰的学习基线

若先学习单目补全，可从 [MonoScene](../related_work/papers/monoscene/README.md) 入手，分别可视化图像投影证据与被补全区域；若任务和数据已经是室内 RGB-D/多视图，更适合从 [EmbodiedScan](../related_work/papers/embodiedscan/README.md) 的任务与基线入手。二者是不同条件下的入口，不强迫依次完整训练。

先跑官方单样本，再核对标签与 evaluator，最后才扩大训练。旧依赖、预训练来源、深度监督和输入视图数逐项登记。与几何基线比较时回答两个问题：增加了哪些有用语义/补全，新增了哪些错误判自由或误占据？不能用输入模态不同的分数证明结构更强。

## 阶段 3：在线记忆

在单帧链路可解释后，研究 [EmbodiedOcc](../related_work/papers/embodiedocc/README.md) 的局部更新、世界坐标记忆与重访。固定观察顺序、位姿与初始状态，对比单帧输出简单融合和学习式记忆；分别测静态一致性与动态更新，加入位姿扰动。

验收是能解释高斯或体素从哪里取出、如何更新、何时遗忘，并复现同一失败片段。已知位姿下记忆表现好，不表示同时解决了定位漂移、回环和动态建图。进一步方法选择以瓶颈为准：计算受限看稀疏/高斯，监督不足看 [SelfOcc](../related_work/papers/selfocc/README.md)。

## 阶段 4：直接人形验证

最后进入 [Humanoid Occupancy](../related_work/papers/humanoid_occupancy/README.md) 与 [Humanoid-OmniOcc](../related_work/papers/humanoid_omniocc/README.md)，先核验公开代码、传感器组合、动作场景和真值质量。把头部六自由度运动、自体遮挡、近场细结构及足/手/头的空间需求列为迁移维度；不要因为标题含 Humanoid 就省去数据与协议审计。

工程验证先离线回放，再仿真下游；实机结果单独登记。足底支撑、抓取接触和全身碰撞需要附加指标，当前 OCC 输出不直接代表动作可执行。不同平台的硬件和时序差异必须反映到端到端延迟中。

## 每次执行的最小交付

按 `日期_任务_方法_vNN_seedNN_runNN` 建立独立记录，保存报告、最终配置、环境清单、命令、代码版本、数据清单和日志；预测样例关联固定失败片段 ID。体积较大的数据与权重仅记录来源、版本、校验值和路径，不重复复制。

先冻结验证方案，再看测试结果；失败照样进入 [结果登记册](../experiment/results.md)。不要为每个模型换一组最好看的示例，也不要只保存最好种子。复现有三种独立结论：环境能运行、原协议可对照、目标人形场景有收益；满足前一种不自动满足后一种。
