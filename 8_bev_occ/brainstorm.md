# 待验证问题与讨论记录

## 2026-09-29：初次调研

用户希望从传统轮式感知进入人形BEV/OCC，兼顾行走与操作，平台未定。本轮尚未复现baseline；以下仅为待核验问题，不是已证实创新。

| 问题 | 阅读动机 | 未来最小对照 |
|---|---|---|
| 重力对齐与动态外参各贡献多少？ | 躯干/头部运动改变几何关联 | 固定模型比较真实/简化坐标链，按姿态分组 |
| 近场精度怎样分配？ | 细障碍与身体碰撞需要局部细节 | 固定计算预算比较不同分辨率分配 |
| 记忆怎样兼顾重访与动态遗忘？ | 累积信息也可能积累误差 | 静态回看、移动家具、位姿扰动分别测试 |
| 几何证据与学习补全怎样组合？ | 已观测和推断可靠性不同 | 几何单独、学习单独、组合，分观测域评价 |
| 语义是否改善控制任务？ | 分类提升不自动提高落脚/通行 | 固定规划器，有无语义比较任务成功 |
| 长期地图怎样保留unknown和free？ | 不能把未看到当自由 | 检查射线证据、更新规则与地图老化 |

先做 [复现计划](复现/README.md)，积累固定失败片段，再选择一个能被消融推翻的命题。后续讨论倒序追加，被否定的想法保留原因。
