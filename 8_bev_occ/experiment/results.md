# 实验结果登记册

**当前没有已执行实验，也没有性能结果。** 空白表示未测，不表示零、通过或失败。协议仍在 [evaluation.md](evaluation.md) 中修订；硬件与数据未定之前，本文件只登记计划和以后真实产生的证据。

## 登记原则

每次执行都生成唯一 Run ID，即使安装失败、训练中断、显存不足或指标回退也登记。推荐 `YYYYMMDD_任务_方法_vNN_seedNN_runNN`；日期使用实际执行日期。配置、代码 commit、数据清单哈希和协议版本一起保存，禁止覆盖旧结果后沿用旧 ID。只有修改说明和重新运行可产生新版结果。

下表状态初始均为“未运行”。暂不设最优方法，也不填预计提升。真正运行后链接原始日志、预测样本和复现报告；主表摘要必须可追溯到相同 ID 的证据。

## 固定失败片段与失败登记
