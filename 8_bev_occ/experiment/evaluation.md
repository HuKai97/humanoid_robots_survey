# 人形 BEV/OCC 评价协议草案

**状态：未冻结、未执行。** 硬件、传感器、数据和下游控制接口尚未确定。本文件提出首轮协议；数值阈值须在训练或查看测试结果前确定，不能把空表或计划当成已验证结论。每次正式评价须绑定本协议版本。

## 1. 先冻结任务与有效域

区分当前帧预测、遮挡补全、在线地图与未来预测，分别建表。明确输入模态、历史帧数、位姿来源、训练额外监督、体素范围/大小、类别字典、坐标系、输出频率。记录已观测与推断体素的来源，free、occupied、unknown、ignore 使用独立定义。

定义有效评价域 `V` 为预先约定空间范围内、真值可判定且非 ignore 的体素；由真值及固定协议构造，不能由模型预测决定。GT unknown 不并入 free，也不参与常规准确率分母，另报其占比与预测分布。可见区、遮挡区及新暴露区分别报告；具体 mask 随数据版本固定。[Occ3D](../related_work/papers/occ3d/README.md)、[SparseOcc](../related_work/papers/sparseocc/README.md)

## 2. 几何、语义与危险漏检

在 `V` 上将所有占据类别合并：`occupancy IoU = TP_occ / (TP_occ + FP_occ + FN_occ)`。建议主表中预测 unknown 对 GT occupied 计作未检出，同时另报弃权比例；不能丢掉困难预测再报高分。语义逐类 `IoU_c = TP_c / (TP_c + FP_c + FN_c)`，`mIoU` 对预先固定的占据语义类取平均；empty 是否参与须明确，本草案建议另报。测试中无真值类的处理规则也须提前固定。

严格区分“危险地说这里空了”与“模型不知道”：

`错误判自由率 = N(GT occupied 且 pred free 且位置∈V) / N(GT occupied 且位置∈V)`。

分母为零时记 `N/A`，不能记零。另报 `N(GT occupied 且 pred unknown)/N(GT occupied)`、有效域整体 unknown 比例，以及在不同预测覆盖率下的误差。对 GT free 误报 occupied 单列误占据率，避免以堵死所有空间换取低漏检。

在预定义机器人扫掠空间或避碰相关区域与 `V` 的交集中重复计算错误判自由率，称为危险区域漏检；该区域由机器人形状和固定动作候选定义，不能事后圈出有利区域。区分传感器未观测、类别误判、几何漏检与标签缺失。

## 3. 人形必须增加的切片评价

近场距离段、足/膝/躯干/头高度段及最小结构尺寸分桶，边界值待冻结。固定台阶边缘、门槛、椅腿、扶手、桌下空隙、悬空障碍案例，报告召回、误占据与表面距离误差。透明/反光物单列，不因真值困难默默删除。落脚面还需几何平整度与可达性评价；语义 floor 不等于可承重。[MonoScene](../related_work/papers/monoscene/README.md)、[SurroundOcc](../related_work/papers/surroundocc/README.md)

时序按静态重访、动态物体移走、自体遮挡恢复分别测一致性、残影持续时间、新障碍检出时间和地图更新延迟。位姿扰动分别覆盖平移、滚转/俯仰/偏航、时间偏移及关节外参误差，固定扰动分布与随机种子；同时保留无扰动参照。[EmbodiedOcc](../related_work/papers/embodiedocc/README.md)

## 4. 数据、速度与下游

按场景或采集轨迹划分 train/val/test，禁止相邻帧跨集合泄漏；同房间不同走向的划分规则须明示。在线推理只访问当前及历史；离线真值可用完整序列，但未来信息不能进入输入。开发调参只看 train/val，冻结后再开 test。

报告端到端 p50/p95 延迟：从同步输入可用到下游可读取更新地图，包含预处理、深度前端、网络、坐标融合、体素/ESDF 转换、传输和队列；另报传感器采集到结果的时龄。记录硬件、精度、批量、预热、丢帧与超时；不得只计主干耗时。

下游先离线回放和仿真，按任务报告碰撞/最小间隙、规划成功率、重规划频率、绕行代价或落脚候选有效率。实机闭环单列，不由离线 mIoU 代替。首次正式跑分前勾选：配置冻结、数据隔离、因果输入审计、标签检查、失败片段集、计时边界一致。
