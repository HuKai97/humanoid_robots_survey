# 复现计划：先得到可信的失败样例

状态：计划，未运行、未安装依赖、未下载模型。先做一个基线，再决定是否进入第二条路线；不要求同时复现本库全部论文。

## 路线 A：理解世界模型如何控制

优先 TD-MPC2；希望深入想象策略学习时选 DreamerV3。选一个小任务、一个版本、一个明确输入模态。成功条件是能重跑训练/评估、获得完整日志、解释模型输入输出及动作时间索引，而不是立即追平论文所有数字。

记录环境交互步数（区分仿真/真机，模型内想象步数另记）、训练更新次数、模型大小、训练时长和推理延迟。先做单种子冒烟运行验证数据流；正式比较再按 [评测协议](../experiment/evaluation.md) 使用全部预定种子。不能把单次最高回报作为复现结论。

## 路线 B：从感知表示进入预测

优先 DINO-WM 的思想或可获取官方小任务，再引入 PointWorld 的三维动作条件思路。初始阶段冻结视觉/点云编码器，只训练小型预测器，并与无动作、当前状态保持不变、简单线性/MLP 动力学比较。此时应称教学或缩小规模基线；只有对齐作者协议后才能称原论文复现。

可控扰动选择一种：深度缺失、相机姿态误差或时间延迟。先证实基线在该因素上有稳定问题，再加入几何补偿、融合或不确定性模块。在替换预测器的实验中，最终保持同一规划器评估闭环收益；预测表征辅助策略的路线则固定策略架构、训练算法与预算进行相应对照。

## 路线 C：人形专项验证

阅读 DWL/WMR/CAP/DWMP 等卡片，逐项确认训练代码、环境和权重。若论文代码尚未发布，先使用已有稳定策略采集日志，或把同类模块接入可运行的人形环境；不能将自行实现称作者官方复现。

第一项任务只选择已定义地形上的行走/跨越，避免同时加入语言、双臂操作和复杂导航。记录跌倒、碰撞、落脚误差、接触状态及视觉失效条件。仿真结果写明为仿真，真实机器人验证另设阶段。

## 每个方法的复现报告应包含

| 项目 | 填写要求 |
|---|---|
| 对应版本 | 论文版本、代码 commit、依赖/仿真器版本、配置 |
| 数据与输入 | 轨迹划分、模态、预处理、时间戳、动作定义 |
| 预算 | 设备、环境步数、训练步数、墙钟时间、规划预算 |
| 结果 | 全部种子、均值与离散程度、成功率分母、失败样例 |
| 对齐程度 | 与论文一致项、偏离项、数字不可直接比较的原因 |
| 诊断 | 哪一步失败、是否已排除泄漏/动作错位/控制器问题 |
| 下一步 | 只改变什么，预期机制，什么结果将推翻猜测 |
