# 调研方法、证据等级与 workflow 适配

## 范围与截止

本轮检索日期与材料截止：2026-09-29。覆盖经典模型式控制、机器人视频/动作模型、三维与自监督表示、直接人形与腿足相关工作，并实际检索 2025–2026 的新论文。属于面向入门和选题的精选调研，不是宣称无遗漏的系统综述或完整排行榜。

项目、目标和术语已可从用户请求确定：人形机器人世界模型；从传统感知背景入门并找到交叉研究方向；使用本领域标准术语。会议、deadline、硬件与感知细分方向未知，明确记为未指定，未因此阻塞调研。已询问可选背景信息，未得到补充时按公开数据/仿真起步编写。

## 使用的 workflow

阅读了 [SKILL.md](https://github.com/skJack/research-workflow/blob/main/SKILL.md)、[初始化脚本](https://github.com/skJack/research-workflow/blob/main/scripts/init-project.sh) 以及项目纲要、交接和评测模板。保留其“一份文档一种职责”的结构，建立 `AGENTS.md`、`handoff.md`、`brainstorm.md`、`related_work/`、`复现/`、`experiment/`、`DataSet/` 与 `dataset.md`。

适配点：用户明确不下载论文，因此未执行 `fetch-paper.sh`，也不建立假装已下载的 PDF/源码目录。文献改为 `related_work/papers/<年份>_<短名>.md`；每篇自含来源与解析。原 workflow 的“先复现再形成假设”在本轮体现为：先给复现计划，研究方向仅记为候选/待验证，不写成已经发现的新贡献。评测协议因任务未定而标为草案，实际实验前再冻结。

仓库结构按公开 workflow 思路编写，未安装全局技能、未克隆代码、未运行外部脚本。文件夹使用原 workflow 的 `related_work` 命名，即用户所说的 related work 文件夹。

## 检索策略和纳入规则

四条并行主题：基础世界模型与模型式 RL；动作条件视频与机器人策略；特征/三维/占据和传统感知；人形/腿足的预测与控制。代表性检索词包括 `World Models PlaNet Dreamer TD-MPC2`、`robot action conditioned world model UniSim IRASim DreamZero`、`DINO-WM V-JEPA 2 PointWorld OccWorld`、`humanoid world model perceptive locomotion contact 2025 2026`。

优先纳入能解释一种关键机制、提供直接机器人/人形证据、适合可操作对照，或代表近期路线变化的工作。感知/策略对照单独标识。通用视频模型与自动驾驶工作只保留对当前问题有具体迁移价值的代表，未按热度堆满条目。

搜索用于发现线索；论文题名、时间、方法和实验结论依论文官方页、arXiv HTML、会议/期刊页、作者项目及官方代码 README。未采用媒体转载或搜索聚合页作为核心事实证据。一次网页打开失败不等于项目不存在；缺失内容降低阅读等级而不靠猜测补齐。

## 阅读证据如何解释

| 标记/表述 | 真实含义 | 可支持什么 |
|---|---|---|
| HTML 方法/实验节选 | 已在线阅读相应正文段落 | 方法流程、该段列明的实验设置；不等于全附录精读 |
| 摘要 + 官方项目/README | 已核对标题、定位、公开说明 | 核心目标、粗粒度机制、可见资源；不支持未读表格精确数值 |
| 前沿线索 | 只核验摘要/项目的存在与定位 | 后续阅读优先级；不声称完整分析 |
| 分析推断 / 候选实验 | 本调研据方法与用户背景提出 | 解释可迁移性和实验设计；不是原作者结论 |

部分感知卡使用 B+ 表示已读 HTML 方法/实验节选并核对官方项目，B 表示摘要与官方项目/README；这是阅读证据等级，不是论文质量评分。

每篇卡按“元数据 → 30 秒总结 → 详细方法 → 证据/局限 → 与感知/人形的关系 → 复现建议 → 来源”组织，个别卡片把来源放在开头或行内。英文缩写、公式是为解释服务的教学概括；未将未读原文复述成逐式精读。

## 资源与性能核验边界

有代码链接、有训练代码、有权重、有完整数据、已在本机运行，是五种不同状态。论文卡尽量写清公开入口与缺口；全部“复现建议”均未执行。项目可能在查询日后更新，未来开始复现必须锁定版本。

不做跨不同任务和硬件的成功率排名。不引用找不到对应上下文的参数规模、倍数和时延。少量原文数字必须有明确平台和统计范围，不能拿模型动作块刷新率代替机器人伺服周期。摘要与仓库若出现版本差异，保留差异说明或不复述该数字。

## 来源清单与持续维护

`_sources/` 中的 JSON 是这次已纳入工作的元数据与实际用过的来源入口，`paper_index.json` 是统一索引；不是完整网页镜像或全部搜索结果日志。论文卡的行内引用用于对应具体事实。新发现先进入前沿追踪，再核验方法和实验后升为独立卡。

供扩展阅读的综述：[World Model for Robot Learning: A Comprehensive Survey](https://arxiv.org/abs/2605.00080)，arXiv 首次提交 2026-04-30；本轮仅核验其摘要与范围，不将其中转述当作被引用原论文的一手核验。它适合未来补漏，不能代替逐篇回到原始来源。
