# 从传统机器人感知进入世界模型：交叉点与可执行研究题目

> 调研核验日期：2026-09-29。以下“研究题目”是根据已读文献提出的**待验证假设**，不是已经成立的新颖性结论。先复现、定位瓶颈、补检索近邻工作，再立题。本次仅完成文献与实验设计，没有下载论文、数据、模型或运行实验。

## 先把你已有的能力放到新问题里

你不需要把原有感知经验清零。世界模型需要将“当前看见什么”组织成可预测的状态，再回答“执行某个动作后会怎样”。标定、时序同步、里程计、点云处理、跟踪、地图更新、遮挡处理和不确定性估计，都可能决定预测是否可信。真正需要补的是动作条件动力学、部分可观测状态、规划器如何利用预测，以及闭环评估。

| 原来的感知工作 | 在世界模型中的对应问题 | 超过普通感知改进的验收条件 |
|---|---|---|
| 相机/IMU/机器人外参标定 | 视觉变化属于自运动还是环境动力学 | 同一动作在新视角下仍能正确预测后果，规划更好 |
| 深度与点云重建 | 状态表示和三维监督是否可靠 | 运动点与接触区预测改善，而非只提高静态重建 |
| 目标检测、实例分割、跟踪 | 交互对象身份和可见性是否持续 | 遮挡后的多步预测与动作选择更可靠 |
| SLAM、局部地图 | 记忆、尺度、参考系以及可通行区域 | 在自运动和地图过时情况下仍能降低任务失败 |
| 多传感器融合 | 视觉看不到的速度、接触和摩擦信息 | 加入信息后能区分视觉相似但物理不同的未来 |
| 鲁棒估计、协方差传播 | 不确定预测如何影响规划 | 风险经过校准，失败降低且任务完成率不塌陷 |

三类工作应分开理解：[ConceptGraphs](papers/2023_conceptgraphs.md) 主要构建语义地图；[DP3](papers/2024_3d_diffusion_policy.md) 直接输出动作；[DINO-WM](papers/2024_dino_wm.md)、[V-JEPA 2-AC](papers/2025_v_jepa_2.md)、[PointWorld](papers/2026_pointworld.md) 学习动作后的状态变化。[OccWorld](papers/2023_occworld.md) 是占据与自车运动联合预测的跨域参考，其驾驶结果不能作为人形证据。

## 我最建议的起步方向

**先做“相机自运动与时间错位会怎样破坏世界模型规划”，再考虑加入几何补偿。** 这是一个可小规模运行的误差归因问题，适合已有感知背景的人，也能避免一开始陷入大型视频模型训练。

第一阶段以 DINO-WM 官方单任务复现为入口，学会离线轨迹、动作对齐、特征预测和 MPC。选择依赖较轻的任务，记录原始成功率和规划时延。第二阶段转到有可控相机和真值状态的小型三维模拟推物环境，保持机器人任务不变，单独增加相机转动、平移和观测延迟。**二维图像平移只能用于快速接口检查，不能称为三维头部自运动实验。**

初步资源估计：一台 Linux 主机、约 24 GB 显存、32–64 GB 内存、50–200 GB 可用空间，可作为冻结视觉编码器、小预测头与少量模拟数据的起点；一次小设置可能需要数小时到数天。以上是规划估计，**不是测量值或官方复现承诺**，受分辨率、特征缓存、轨迹数量、模型大小、规划样本数影响。先用几十条轨迹检查数据管线，再扩大；不应直接启动 PointWorld 或 V-JEPA 的完整预训练。

最小交付物应是：固定版本环境说明、训练/测试拆分、一个可重复的原基线、四张误差曲线（位姿噪声/时延/遮挡/规划预算）、失败视频索引和结论。如果原模型已经足够鲁棒，或简单增加历史就解决问题，也是一项值得保留的否定结果。

## 题目 1：自运动补偿是否提高动作条件预测的可迁移性

**问题与假设。** 人形头部和躯干运动时，视觉 patch 的变化可能主要来自相机。假设统一到机器人基座或局部稳定参考系后，模型能用更少交互数据学到物体受动作影响的变化。

**已有工作与可能增量。** DINO-WM 使用空间特征预测；V-JEPA 2 讨论相机位置敏感；PointWorld 已使用显式三维和标定。因此“加入三维坐标”本身不是新贡献。可能的增量是**在有误差、随时间变化的相机位姿下，验证几何补偿何时有益、何时有害，并将位姿置信度纳入状态预测**。背景与接口见上述论文卡及其原始来源。

**baseline / 数据。** 先复现 DINO-WM 单任务，再用 MuJoCo/MetaWorld 风格的单臂推物任务采集自己的短轨迹；使用相同动作与场景，渲染固定相机、移动相机两类观测。基线包括原图像特征、增加历史的原模型、几何补偿、真值位姿补偿。真实验证可从已有 RGB-D 操作数据小子集开始，但不可假定其中已有可靠头戴 IMU。

**消融。** 只改图像不改动作坐标；图像与动作一起改；真实/估计/扰动位姿；静止场景与动态物体；同计算量历史窗口；同参数量预测头。训练/测试按场景和相机运动轨迹划分，不能随机拆相邻帧。

**指标。** 多步物体位姿误差、运动区域点流误差、候选动作成本排序相关性、闭环目标成功率、端到端时延。对应人形因素是头部视角、IMU 与视觉融合、基座运动和手臂遮挡。

**失败条件。** 只降低特征误差却不改善动作选择；使用真实估计位姿后收益消失；加长历史的简单基线已达到相同效果。出现这些结果就收缩主张，不直接进入复杂真机全身实验。

## 题目 2：把标定误差传播到规划风险，而不只拟合一个方差头

**问题与假设。** 外参偏差会让很多点同时产生相关误差。假设显式区分深度噪声、位姿误差与动力学未知，能减少规划器利用模型错误挑选动作的情况。

**已有工作与可能增量。** PointWorld 已经包含运动点加权、数据不确定性头和鲁棒损失；因此这些不能再作为“首次”贡献。可测试的增量是：上游几何相关不确定性如何传播到目标点距离、碰撞代价和动作风险，并在分布变化后重新校准。[PointWorld 方法与局限](https://arxiv.org/html/2601.03782v1)

**baseline / 数据。** 采用 PointWorld 的小型公开模型做离线审计；若资源不足，在同一模拟点云任务训练小模型。对比原模型、普通深度噪声增强、独立逐点方差、简单双模型 ensemble、显式位姿扰动传播。使用原始干净数据与多等级人工几何扰动；动作和物体真值用于评估，不暴露给部署输入。

**消融。** 只做训练加权/只改规划风险/二者都做；独立噪声与整帧相关噪声；不同校准集；静态与运动点分开；相同候选数和相同延迟预算。不能用测试集调拒绝阈值。

**指标。** 区间覆盖率和区间宽度、风险—覆盖曲线、被选动作真实代价、失败率、成功率和保守停止次数。对人形尤其关注近身碰撞与落脚空间的不确定性，但初期仍只做操作或局部运动规划。

**失败条件。** 总是拒绝动作带来低碰撞但几乎不完成任务；校准仅在同分布成立；ensemble 在同预算下已达到同样效果。任何一种都会限制方法价值。

## 题目 3：遮挡记忆与几何补全怎样帮助接触后的预测

**问题与假设。** 手臂遮住物体后，单帧点云可能丢失决定接触响应的表面。假设保留时间一致的对象记忆，并对不可见表面保留多种可能，比每帧独立补全更有利于预测。

**已有工作与可能增量。** PointWorld 已研究部分可观测输入；2026 的 3DPWM 已明确研究先补全点云再学动力学。因此“点云补全 + 世界模型”不是未被占据的方向。候选增量应落在**补全不确定性、历史对象身份、接触事件三者的配合，以及由此产生的动作差异**。[3DPWM 官方摘要](https://arxiv.org/abs/2607.00148)

**baseline / 数据。** 模拟有刚体真值的桌面推物，按物体形状和遮挡模式留出测试集。对比单帧点云、普通多帧融合、确定性补全、恒速对象跟踪、加入动作的记忆模型；几何完整真值是性能上界。ConceptGraphs 风格对象关联可以提供接口，但不宜把其静态地图直接当真实动态状态。

**消融。** 真值/估计对象 ID；真实历史/打乱历史；预测多个补全假设/只有均值；遮挡发生在接触前/接触后；固定相机/随头部移动相机。

**指标。** 遮挡后对象位姿误差、ID 切换、接触后运动预测、目标成功率、再观察次数；补全 Chamfer 距离只作为辅助，避免好看的背面补全掩盖错误接触。

**失败条件。** 完整几何上界没有改进；收益完全来自更多可见帧；补全提高几何均分却引入错误接触。人形特殊性是双臂自遮挡、头部转向后的再发现与长期对象身份。

## 题目 4：视觉—本体—接触融合能否辨别“看起来相同”的物理状态

**问题与假设。** 同样的物体姿态可以处于静止、滑动或即将失稳的状态。假设本体速度、IMU 和接触信号能补齐视觉状态的不可辨识部分，改善短时关键事件预测。

**已有工作与可能增量。** 本体状态条件化和多模态世界模型并不新；不能仅凭加入一个传感器立题。要检验的增量是**在异步、缺测和噪声条件下，哪些传感器在接触切换阶段真的改变动作排序**。

**baseline / 数据。** 先在仿真采集具有不同摩擦、负载、接触初态的交互。对比视觉、视觉+本体、视觉+接触、全部输入、历史更长的视觉模型，并加入解析/常规系统辨识的低维预测模型。人形后续数据需要关节位置/速度、IMU、接触或力代理与图像同步记录，不能用普通机器人视频假装已有这些量。

**消融。** 传感器噪声、随机掉线、时钟偏移；训练用真值接触而测试用估计接触；摩擦和物体质量留出；参数量匹配。既测平均误差，也单独测接触发生前后的小时间窗。

**指标。** 接触事件 F1、滑移/失稳提前量、多步速度误差、完成率、峰值接触力（若可测）、额外传感器时延。人形对应足地切换、手物接触、基座扰动和快速本体反馈。

**失败条件。** 所有收益都来自特权真值标签；传感器稍微错时就不如视觉；简单滤波和物理模型已解决问题。初步操作验证不能替代双足平衡实验。

## 题目 5：世界模型是否值得为“再看一眼”付出动作成本

**问题与假设。** 人形可以转头、移动上身或手臂减少遮挡。假设预测信息增益可以帮助选择再观测动作，在少量额外时间内降低后续操作失败。

**已有工作与可能增量。** 主动感知、POMDP 和信息增益规划已有成熟研究。候选增量应是**使用同一个动作条件模型预测任务进展与可观测性，并检验这是否优于传统几何信息增益**；新颖性必须补查主动世界模型规划文献。

**baseline / 数据。** 模拟遮挡下寻找并推动目标。比较固定视角、规则转头、覆盖率驱动的 next-best-view、随机再观察、模型驱动的再观察。所有方法允许同样的总动作数和观测预算。数据应包含真实改变视角后的新观测，不把同一张图裁剪成新视角。

**消融。** 只预测任务目标/只预测可见性/联合；真值几何/估计几何；计入和不计入转头时间；完美记忆/有限记忆。转头动作应改变相机坐标，移动身体动作还会引入接触和平衡成本。

**指标。** 按总用时计的任务成功率、错误接触数、观测次数、遮挡消除率、额外运动距离。单纯提高地图完整度不足以证明任务获益。

**失败条件。** 简单规则转头同样有效；获得的信息没有改变后续动作；模型忽略再观察动作的风险或时延。仿真若采用瞬时相机传送，不能支持实体人形主动感知结论。

## 题目 6：用延迟与风险感知的短时预测连接高层规划和低层控制

**问题与假设。** 模型看到的是过去的图像，动作执行时世界已变化。假设把实际时延与动作实现误差放入短时预测，可以改善移动人形的执行稳定性，而无需把大型视觉模型塞进高频力矩环。

**已有工作与可能增量。** 状态外推、延迟补偿控制和残差动力学都是已有方法。可测试的增量应是**世界模型的学习预测在接触切换、视觉缺测和变化负载下，是否比线性外推/物理预测提供额外价值**。

**baseline / 数据。** 模拟统一控制任务，记录实际图像时间戳、动作发出与实现时间。对比忽略延迟、恒速外推、带延迟的经典状态估计、学习残差预测、端到端预测；动作接口与低层控制器保持不变。先做固定基座，再加入可控基座扰动；双足作为单独验证阶段。

**消融。** 固定/变化/突发时延；名义动作/实测动作；长预测窗口/短预测窗口；高层慢速更新/低层快速更新；模型推理时间必须计入总延迟。

**指标。** 轨迹跟踪误差、控制截止时间错过比例、任务成功率、接触失配、基座姿态波动；真正双足阶段才报告跌倒率和足底打滑。

**失败条件。** 补偿收益低于它新增的计算延迟；只在固定延迟上有效；传统滤波和模型预测控制在同预算下已足够。不能用离线预测误差代替真实执行验证。

## 什么才算你的世界模型论文站得住

至少需要回答四个问题：预测对象是什么；动作如何改变预测；预测怎样进入决策；改进是否在相同数据、相同感知、相同计算预算下改善闭环结果。建议实验报告固定列出训练数据量、额外标注、传感器、目标信息、推理预算、模拟/真实、固定基座/移动/双足，并把模型失败和感知失败分开。

一个实用阶段门是：**原方法能复现 → 扰动下存在稳定瓶颈 → 简单基线不能完全解决 → 假设有可测收益 → 再补近邻检索与人形验证**。你最可能较快建立优势的环节是坐标、时间、几何质量与不确定性，而这些优势最终应通过动作和任务结果体现。
