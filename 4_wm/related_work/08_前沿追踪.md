# 2026 前沿追踪与后续补读

截至 2026-09-29。下面区分已经写详细卡的工作与只核验入口的线索，避免用“最新”暗示完整覆盖。

## 已纳入详细卡

| 工作 | 变化与阅读理由 | 边界 |
|---|---|---|
| [PointWorld](papers/2026_pointworld.md) | 三维点流、机器人动作几何与规划 | 机械臂闭环与双足全身不同；已有不确定性设计须纳入近邻比较 |
| [DreamZero](papers/2026_dreamzero.md) | 联合未来视频与动作的世界动作模型 | 策略接口不等同任意动作可查询的前向模拟器 |
| [Cosmos 3](papers/2025_cosmos.md) | 系列已扩展到多模态、动作条件和策略模式 | 2026能力不能回填到2025初版；按具体checkpoint与任务验证 |
| [CAP](papers/2026_cap.md) | 深度退化下的世界模型表征与本体融合 | 真实实验样本量和完全遮挡失败需同时看 |
| [DWMP](papers/2026_dwmp.md) | 本体动力学与视觉几何分支 | 主要表征辅助策略，不把它写成已验证任意动作反事实模拟 |

## 已核验入口、仍需深入的方法

| 线索 | 已知定位 | 下一轮必须核验 |
|---|---|---|
| [MotionWAM](https://arxiv.org/abs/2606.09215) | 全身运动与视频模型特征；摘要报告真实G1移动操作 | 动作条件、训练/部署接口、实验次数、与等容量视觉策略的对照 |
| [WM-LOCO](https://arxiv.org/abs/2609.02542) | 世界模型增强的人形视觉行走，重点落脚约束 | 增加记忆与动力学训练的贡献能否分离；代码发布与深度退化测试 |
| [V-JEPA 2.1](https://arxiv.org/abs/2603.14482) | 稠密时序特征，后续摘要也有抓取改进报告 | 版本、动作条件适配与具体机器人实验；不继承旧版未验证结论 |
| [3D Point World Models / 3DPWM](https://arxiv.org/abs/2607.00148) | 先补全点云再学习动作条件动力学 | 几何监督、遮挡设置和控制评测；“补全+动力学”已经有直接近邻 |
| [机器人世界模型综述](https://arxiv.org/abs/2605.00080) | 覆盖策略耦合、模拟、生成与评估等路线 | 用作补漏目录，关键事实仍回原论文核对 |

MotionWAM 与 WM-LOCO 的详细来源状态见 [核验备忘](_sources/humanoid_frontier.md)。V-JEPA 2.1 与 3DPWM 的版本说明见 [交叉研究文档](04_感知与世界模型的交叉研究.md)。以上线索不计入28张详解卡的数量。

## 后续追踪方式

围绕最终选题做定向检索，记录检索日期、首次公开时间、所读版本、是否已正式接收、官方代码/权重/数据各自状态。新工作先读问题定义与实验条件，再比较机制和最接近基线；不要按题名含有 world model 就自动收录。

若开始研究感知可靠性，优先追踪 contact-aware prediction、ego-motion compensation、belief-space planning、uncertainty calibration、action-conditioned 3D dynamics 和 humanoid perceptive locomotion 交叉的原始论文。这里列的是检索词，不表示这些方向仍为空白。
