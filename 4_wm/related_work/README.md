面向有传统机器人感知经验、世界模型方向刚起步的研究者。检索截至 **2026-09-29**，按照 [research-workflow](https://github.com/skJack/research-workflow) 组织。

本轮包含 **28 张论文/系列解析卡**，覆盖经典模型式控制、机器人视频与动作模型、三维/特征预测、人形与腿足控制。其中 Cosmos 为多版本系列卡；另有少量仅核验入口的前沿线索。每张卡都先给简短总结，再介绍方法、证据、局限、感知交叉点和复现建议。**没有下载论文 PDF、论文源码、数据或模型，也没有运行实验。**

## 第一轮不必把所有论文都读完

建议顺序：

**[World Models](papers/2018_world_models.md) → [PlaNet](papers/2019_planet.md) → [Dreamer](papers/2020_dreamer.md) → [TD-MPC2](papers/2024_tdmpc2.md) → [DINO-WM](papers/2024_dino_wm.md) → [PointWorld](papers/2026_pointworld.md) → [DWL](papers/2024_dwl.md) → [CAP](papers/2026_cap.md)**。

这个顺序依次回答：模型是什么、怎样预测与规划、怎样学策略、怎样连接几何感知、进入人形后还缺什么。偏视觉生成时补 HWM/UniSim/DreamZero；偏状态估计与控制时提前读 PETS/MoSim/DreamWaQ。

## 给你背景的首选起点

先复现一个小规模动作条件预测基线，再研究**相机自运动、标定误差或观测延迟**如何改变预测与规划。在保持数据和控制预算一致时，比较历史记忆、传统几何补偿和学习式补偿。该方向能利用已有感知经验，且可以先在公开仿真中做误差归因；是否值得立题取决于基线是否确实存在尚未被简单方法解决的问题。

注意两种边界：传统感知算法已有大量预测和滤波工作，不是天然“比世界模型低级”；机械臂、四足、轮式人形、仿真人形和真实双足的结果也不能互相替代。文中所有研究题目均是待验证假设，未声称已经具备新颖性或实验收益。
