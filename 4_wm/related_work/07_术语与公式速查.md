# 世界模型术语与公式速查

以下公式是跨论文的教学抽象，不是任何单篇论文的逐式复刻。具体实现以论文卡链接的原文为准。

## 最少需要理解的数学

**状态估计：**`b_t = Update(b_{t-1}, a_{t-1}, o_t)`。`b_t` 表示结合历史后的状态信念；传统概率滤波可用分布表达，神经模型常用向量近似。

**动作条件预测：**`p_theta(z_{t+1} | z_t, a_t)`。`z_t` 是学到的状态表示，可含历史。没有历史或 Markov 假设时，这种写法只是简化。

**多步滚动：**从同一初始化状态出发，反复使用预测结果作为下一步输入。预测第十步时不能偷用真实第九步观测；那是 teacher forcing 条件下的测试，不是十步开环预测。

**MPC：**`a*_{t:t+H-1} = argmax_{a_{t:t+H-1}} E[sum_{k=0}^{H-1} gamma^k r_hat_{t+k} + gamma^H V_hat(z_{t+H})]`。优化一段动作序列，仅执行第一步或短片段，获得新观测后重规划；有的方法没有终端项，也有方法使用动作价值 `Q(z,a)` 作终端估计，不能把本教学公式直接当作 TD-MPC2 原式。

**联合训练目标示例：**`L = L_prediction + lambda_geom L_geometry + lambda_contact L_contact`。这是可选研究设计，权重、标签来源与辅助任务公平性必须在实验前写清，不是把目标简单相加就有创新。

## 核心词汇

| 术语 | 中文解释 | 最容易误解的地方 |
|---|---|---|
| observation / state | 可见观测 / 决定演化的状态 | 一张图像通常不是完整状态 |
| proprioception / exteroception | 本体感知 / 外部环境感知 | 图像很丰富，不代表能替代关节和 IMU |
| POMDP / belief state | 部分可观测决策过程 / 状态信念 | 存历史不等于精确贝叶斯推断 |
| world model | 用于描述/预测世界的模型 | 学界用法宽泛，需说明动作、预测对象与用途 |
| latent dynamics | 潜空间动力学 | latent 不自动对应物理坐标 |
| RSSM | 循环状态空间模型 | 确定性记忆与随机状态承担不同角色 |
| prior / posterior | 预测先验 / 结合观测的后验 | 向未来滚动时没有未来真实观测可用于校正 |
| model-based RL | 使用环境模型的强化学习 | 模型可能只用于训练，不必部署时搜索 |
| model-free RL | 不以显式环境预测模型做该决策学习 | 仍可能有很强的感知与记忆网络 |
| actor / critic | 产生动作的策略 / 估计价值的网络 | critic 预测收益，不是预测图像 |
| replay buffer | 历史交互缓存 | 训练可随机采样转移/片段；评测拆分需避免相邻帧及同轨迹泄漏 |
| imagination rollout | 模型内的预测轨迹 | 预测不是新的真实证据 |
| open-loop / closed-loop | 开环 / 闭环 | 同一模型两种条件下误差差很多 |
| MPC / CEM | 模型预测控制 / 一种采样优化法 | MPC 是控制框架，CEM 是可选优化器 |
| inverse dynamics | 根据前后状态推断动作 | 存在多解，生成的视频不一定可执行 |
| action-conditioned | 显式以动作作为条件 | 接收动作不意味着网络确实利用动作 |
| occupancy / scene flow | 空间占据 / 三维运动场 | 占据准确不自动等价于接触力正确 |
| affordance | 环境/物体允许的交互可能性 | 可抓/可踩是任务与身体相关概念 |
| contact mode | 接触模式，例如双支撑/单支撑 | 切换可能让动力学不平滑 |
| ego-motion | 机器人/相机自运动 | 与物体运动混淆会污染动态预测 |
| epistemic / aleatoric | 认知不确定性 / 随机不确定性 | 模型集成与输出方差不是万能分离器 |
| calibration | 置信度与实际错误频率的一致性 | 方差大不等于已经校准 |
| sim-to-real | 仿真到真实迁移 | 仿真多样性不保证真实覆盖 |
| embodiment | 机器人身体、传感器与动作接口 | 机械臂、轮式人形和双足不能混报 |
| VLA / WAM | 视觉语言动作模型 / 世界动作模型 | 以实际输出与训练目标判断，不只看名称 |
| JEPA | 联合嵌入预测架构 | 视觉表征预训练不自动得到动作条件控制器 |
| privileged information | 训练可见而部署不可见的特权信息 | 必须防止流入评测时的策略输入 |

概念与方法来源可从 [PlaNet](papers/2019_planet.md)、[Dreamer](papers/2020_dreamer.md)、[TD-MPC2](papers/2024_tdmpc2.md)、[PETS](papers/2018_pets.md) 和 [比较表](03_论文比较表.md) 继续查阅。
