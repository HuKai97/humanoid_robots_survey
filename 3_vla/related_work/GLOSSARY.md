# 阅读术语表

以下为教学性释义；具体论文定义优先于此表。方法来源可从 [论文索引](PAPER_INDEX.md) 查询。

| 术语 | 中文与直觉 | 阅读时要问 |
|---|---|---|
| Embodiment | 机器人形态，包括身体、传感器、执行器和接口 | 换机器人后哪些输入输出改变？ |
| VLM | 视觉语言模型，理解图像与文字 | 是否只输出文本，还是接入动作头？ |
| VLA | 视觉语言动作策略/模型 | 输出是什么动作，谁实际执行？ |
| Policy | 策略，从观察/历史到动作的映射或分布 | 有无历史、状态和任务条件？ |
| Observation | 可获得的观察 | 训练与部署能看到的量是否一致？ |
| Proprioception | 本体感知，如关节位置、速度、身体姿态 | 维度、单位、坐标系是什么？ |
| Episode / trajectory | 一次完整尝试及其随时间记录 | 成功/失败、起止和重置如何定义？ |
| Rollout | 让策略连续与环境交互 | 是否真正闭环，还是离线预测动作？ |
| BC | 行为克隆，用示范监督动作 | 示范偏差与部署分布偏移如何处理？ |
| IL | 模仿学习，利用专家行为学习的总称 | 是否包含交互收集新示范？ |
| RL | 强化学习，通过交互与奖励学习策略 | 奖励是否借助部署时不可用的信息？ |
| Offline RL | 从已有交互数据学习策略价值与决策 | 和只拟合专家动作的 BC 有何区别？ |
| Action chunking | 一次预测多步动作 | 预测长度、执行长度、更新周期各是多少？ |
| Temporal ensembling | 合并多次预测中对同一时刻的动作 | 平滑是否增加延迟？ |
| Diffusion policy | 条件扩散生成动作 | 去噪次数与动作质量、延迟怎样权衡？ |
| Flow matching | 通过学习向量场生成目标分布 | 使用什么路径、时间约定和动作空间？ |
| Action tokenization | 把动作编码成离散序列 | 信息损失、序列长度和解码方式是什么？ |
| Fine-tuning / LoRA | 微调 / 一种低秩参数高效微调方法 | 更新哪些参数，是否仍需大激活显存？ |
| Co-training | 混合任务或数据共同训练 | 各数据权重和监督目标是什么？ |
| Retargeting | 运动重定向，把人的姿态映射到机器人 | 骨长、关节极限、接触如何约束？ |
| IK | 逆运动学，从末端目标求关节配置 | 解是否唯一，是否保证动态稳定？ |
| Whole-body control | 全身控制，协调身体多个部分和接触 | 哪些自由度被控制，谁负责平衡？ |
| Loco-manipulation | 移动与操作的协调 | 同时进行还是先走后抓？ |
| Sim-to-real | 从仿真训练/验证迁移到现实 | 改了相机、动力学还是环境？ |
| Real-to-sim evaluation | 把真实数据训练的策略放到仿真评估 | 仿真排名能否代表真实排名？ |
| Domain randomization | 随机化视觉或物理条件以增强鲁棒性 | 随机化维度与测试分布如何对应？ |
| OOD | 分布外测试 | 究竟是新物体、场景、任务、语言还是形态？ |
| Zero-shot | 对明确目标条件没有额外训练的评估 | 对任务、环境还是机器人零样本？ |
| Privileged information | 训练时额外可用、部署时没有的信息 | 如何通过蒸馏或估计消除依赖？ |
| Success rate | 达到预定义任务条件的比例 | 分母、重试、人工干预与超时怎样计入？ |
| WAM | 世界动作模型，联系未来世界观察与动作生成 | 是预测视频、输出动作还是二者联合？ |

常见误解：开源代码不等于公开全部训练数据；模型参数少不等于完整系统延迟低；视频动作流畅不等于任务成功率高；跨机器人训练不等于对任意新机器人免适配。
