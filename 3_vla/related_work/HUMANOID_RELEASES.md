# 人形 VLA 企业发布观察：Helix 系列

核验日期：2026-09-29。本文依据 Figure 官方技术发布，**与论文解析分开维护**：企业自报结果不等于独立复现或统一公开基准。本轮未核验到这些版本可直接下载、训练并复现的公开权重/数据/完整代码。

## 先看结论

Helix 提供一条值得学习的系统演进路线：2025 年的上半身语言操作，2026 年加入全身控制层，再追踪跨环境泛化。但应按发布版本分别讨论，不能把 Helix 02、2.5 的能力写回最早版本。

## 2025-02-20：Helix

官方将其描述为感知、语言理解与上半身连续控制结合的 VLA，并展示物品操作与双机器人协作。其公开定位是 **full-upper-body control**，不能直接据此推断该版本已统一负责双足平衡与行走。[Figure 原始发布](https://www.figure.ai/news/helix)

学习重点：为什么语义推理和快速动作生成要分层？上半身关节维度、相机观测和语言条件如何对齐？本轮不把网页中的“首个”“任意物体”等宣传表述当作覆盖全领域的事实。

## 2026-01-27：Helix 02

官方加入 System 0 全身控制层，System 2 处理语义目标，System 1 产生全身关节目标，System 0 执行平衡和身体协调；发布中分别给出 S1 200 Hz、S0 1 kHz 的工作频率，并展示包含行走和操作的厨房长序列任务。以上为厂商报告。[Figure Helix 02](https://www.figure.ai/news/helix-02)

**本调研解释**：这与学术系统的“VLA 输出参考动作，低层执行动态控制”有可比较之处，但内部模型、数据与接口未必相同。不能因为都使用层级，就把任何 HOVER/HOMIE 控制器等同于其 S0。

## 2026-09-17：Helix 2.5

最新官方报告以 Index 人类行为数据预训练，再适配整理房间、折毛巾和铺床三个行为，在 30 个未见家庭评测。官方给出的对照是固定任务数据等条件，预训练将完整任务成功率由 9% 提升到 56%。这里的零样本针对测试环境和物体；任务仍通过其他环境采集的数据适配，且每个行为使用自己的固定检查点。[Figure Helix 2.5](https://www.figure.ai/news/helix-2-5-zero-shot-30-home-generalization)

**本调研分析**：这个结果可作为“人类数据是否帮助环境泛化”的线索，但不能与 OpenHLM/HAF 的平均任务进度直接比较。也不能把三个行为来源于同一基础模型，改写为无需任务适配的单一通用策略。

## 如何在自己的调研中使用

1. 系统结构讨论可与 [HumanPlus](papers/2024_humanplus/README.md)、[HOVER](papers/2024_hover/README.md)、[OpenHLM](papers/2026_openhlm/README.md) 对照。
2. 泛化评测应明确未见维度：场景、物体、任务、语言表述或机器人构型，它们不相互替代。
3. 复现计划优先选有明确代码、数据和控制接口的学术基线；Helix 系列先作为产业路线观察。
4. 后续有论文、公开评测、模型或数据发布时，另开记录，不覆盖此处已注明版本的证据。
