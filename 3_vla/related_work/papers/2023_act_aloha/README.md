# ACT / ALOHA：低成本双臂模仿学习与动作分块

## 先读总结

1. ALOHA 用主从双臂遥操作收集示范，ACT 根据图像与关节状态学习控制。[S1][S2]
2. ACT 一次预测多步关节目标，降低逐帧决策带来的误差累积。[S2]
3. CVAE 建模示范中的不同风格；temporal ensembling 聚合同一未来时刻的重叠预测。[S2][S3]
4. 它是理解双臂协调、动作块和数据质量的入门基线；双臂成功不意味着已解决双足移动与平衡。

## 问题是什么

精细双手任务不仅要“手到附近”，还要求两侧配合和接触时机准确。人类示范可能在相同画面下出现停顿、不同速度或不同后续操作。逐帧监督既容易累积偏差，也难从单帧判断动作进度。

## 方法：动作块 + 潜变量 + 重叠融合

项目给出的输入包括多视角 RGB 图像、关节位置和风格变量 `z`，输出未来一段关节位置目标。[S2]

训练时，CVAE 编码器读取真实动作序列及关节状态，推断潜变量；策略解码器结合图像、状态和潜变量重建动作块。损失包含动作重建项和约束潜变量分布的 KL 项。测试时不再读取真实未来动作，移除 CVAE 编码器，并使用先验均值作为 `z`。[S2][S3]

执行时可不断重新预测；当多个历史动作块都覆盖当前时刻，temporal ensembling 对**同一时刻**的预测做加权融合。它不是把相邻时刻动作简单平均，否则可能引入时间偏移。[S3]

**解释性推导**：动作分块提供局部运动计划；频繁重新观察保留反馈；融合减少预测之间的跳变。这三件事一起决定行为，不能把“块越长越好”当成结论。

## 数据与监督

主要监督来自 ALOHA 遥操作示范。项目展示四路相机和双臂关节控制；公开代码同时提供 Transfer Cube、Bimanual Insertion 仿真环境与示范采集、训练、评估入口。[S2][S4] 这类系统的数据通常与具体相机、关节范围、控制频率绑定，换身体需要重新检查接口。

## 实验证据与局限

作者在多项真机精细任务上展示学习能力；摘要中“少量示范达到较高成功率”是针对所列任务条件，不能推广到所有双臂任务。[S1] HTML 消融研究动作块、CVAE 与重叠融合，并指出过长动作块削弱反应能力；细小低对比目标也会导致失败。[S3]

局限分析：原版没有自然语言任务选择；双臂关节动作紧贴平台；位置控制成功不等于显式力反馈。迁移到人形时，还需处理上肢动作对身体重心、支撑足与可达范围的影响。

## 联系与复现检查

与 [Diffusion Policy](../2023_diffusion_policy/README.md) 比较动作序列分布的表达。学习现代 VLA 时，应检查是否采用了 action chunking，以及是否仍使用 ACT 式融合。

可行练习：先按官方仿真流程学习一项任务，冻结数据划分和 seed，再单独比较 chunk 长度或是否启用 temporal aggregation。不要同时修改网络、数据和控制频率。阅读时回答：测试时为什么没有未来动作？CVAE 的训练潜变量与推理潜变量有何差别？动作是关节目标还是末端增量？本轮没有训练或下载示范。
