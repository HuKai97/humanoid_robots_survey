# RoboCasa365：从单个演示走向系统化评测

## 先读总结

- 这是 2026 年 RoboCasa 的扩展工作，应与 2024 原版分开记录。
- 论文覆盖 365 个日常任务、2,500 个厨房环境，并提供人工及合成示范。[S1]
- 它面向多任务学习、基础策略训练与终身学习等不同设置，不能把这些设置的分数混合排名。[S1]
- 有助于研究移动操作和长任务，但不是全身人形能力的独立充分证据。

## 元数据与阅读范围

完整标题：RoboCasa365: A Large-Scale Simulation Framework for Training and Benchmarking Generalist Robots。Soroush Nasiriany、Sepehr Nasiriany、Abhiram Maddukuri、Yuke Zhu，2026。官方项目标注 ICLR 2026。核验论文摘要和 HTML 的介绍/框架、官网与仓库入口；未逐表复核全部实验。[S1][S2] 检索：2026-09-29。

## 为什么需要它

只测试少量任务，容易让模型改进看起来很大，但换一批任务结论可能不同。这篇扩展工作的价值在于让任务多样性、场景变化与数据规模成为可以系统研究的变量，而不是只展示几个漂亮视频。

## 详细框架

平台沿用厨房交互环境，扩大布局和外观组合，并把日常任务组织成基础技能与组合活动。训练数据同时包括人类示范和自动生成示范。策略接收指定的视觉、语言与机器人状态，在环境中闭环执行；其具体动作接口仍取决于所选机器人和控制器。[S1][S2]

可以从三个维度理解实验设计：更多任务是否帮助新任务；更多轨迹是否提高熟悉任务表现；更多环境变化是否改善陌生厨房表现。这是本笔记对研究变量的教学性整理，不是断言每种扩展都单调有效。

预训练、联合训练和终身学习回答的科学问题不同。一个模型如果训练时见过测试任务，只是换初始物体位置，不能与任务完全未见过的设置同称“零样本”。

## 实验证据与阅读边界

论文分析任务覆盖、数据规模与环境变化对泛化的影响。[S1] 本轮不转录完整结果表，也没有在本地核验作者基线，因此不声明任何方法是这个平台的最新最优。

它给出了可研究大范围日常操作的环境，不意味着现实家庭的所有接触、传感噪声和失败恢复都已模拟充分。对人形项目，仍应检查双足动力学、身体支撑和高低层接口实际是否进入评测。

## 复现选择与局限

它适合在掌握一个较小benchmark后使用。环境和资产规模本身会增加工程负担；应从固定小任务子集完成链路验证，再运行完整正式协议。小子集结果只能标作调试结果，不能替代完整benchmark的结论。

建议记录任务/环境ID、训练与测试场景重叠、数据来源比例、每种来源的失败筛选规则，以及动作执行的重规划周期。比较原版与365时先辨认目标问题是否一致。
