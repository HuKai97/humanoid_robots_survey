# LIBERO：先学会怎样评价策略

## 先读总结

- LIBERO 最初面向终身机器人学习和知识迁移，不是专门为某个 VLA 设计的排行榜。[S1]
- 它用不同任务套件区分空间、对象、目标与综合知识变化，并提供示范与基线。[S1][S2]
- 必须区分 LIBERO-100、LIBERO-90 和 LIBERO-10；后来 VLA 常用的评测组合不自动等于原始论文完整协议。
- 它适合学习闭环仿真评测，但得分不能单独证明人形机器人全身能力。

## 元数据与阅读范围

完整标题：LIBERO: Benchmarking Knowledge Transfer for Lifelong Robot Learning。Bo Liu、Yifeng Zhu 等，2023，NeurIPS Datasets and Benchmarks。核验 arXiv 摘要、官方项目及代码 README；未运行环境、未逐表精读原文。检索：2026-09-29。

## 研究问题

机器人既需要知道对象和空间关系，也需要知道动作程序。例如“拿左边的杯子”和“把杯子放到盘中”改变的知识维度不一样。若只报告所有任务平均成功率，很难知道方法学会了什么，也难以判断新任务训练是否损害旧任务。

## 详细设计与输入输出

LIBERO 提供程序化构造操作任务的流程，用语言描述目标，策略在仿真中接收视觉和机器人状态，输出动作直到成功或终止。benchmark 本身不规定必须使用一个大型 VLM；它评估的是策略在给定任务和训练流程下的行为。[S1][S2]

官方四类套件共 130 个任务：Spatial、Object、Goal 分别控制不同变化，LIBERO-100 是较综合的任务集合，进一步区分预训练用的 LIBERO-90 与下游终身学习用的 LIBERO-10。这个结构是设计受控比较的依据，不只是数据文件名。[S2]

原始问题还包含任务顺序、前向迁移、后向影响等。若只在若干任务上联合训练后报告最终成功率，就主要是在回答多任务策略性能，而不能自然宣称解决了持续学习。[S1]

## 实验结论与边界

作者比较架构、预训练及终身学习方法，报告不同迁移类型下并没有一个编码器始终最好等发现。[S1] 本笔记不搬运单个分数作为“标准成绩”；复现应对齐论文/仓库版本、数据划分和训练设定。

机械臂桌面仿真不覆盖双足动态稳定、真实接触误差或整屋移动。即使同叫 LIBERO，初始化、失败处理、图像裁剪与评估次数不同，分数也可能不可直接比较。

## 对人形 VLA 的意义

先在可控任务中建立语言变化、动作适配、闭环成功率和统计意识，再迁移到更复杂的人形环境。把 LIBERO 成绩称为“通用人形能力”会跨过尚未验证的环节。

## 适合初学者的检查清单

学习建议：选择一个官方支持的 baseline，列出观测字典、动作向量、最大步数和 success 条件。固定初始状态，观察相同场景更换目标语言是否改变动作。保存全部失败与超时，先复现执行链路，再比较模型结构。当前尚未安装或评估。
