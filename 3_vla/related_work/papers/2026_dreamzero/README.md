# DreamZero：以联合预测视频和动作研究新动作泛化

## 论文与阅读状态

- **作者/机构**：Seonghyeon Ye、Yunhao Ge、Kaiyuan Zheng 等；NVIDIA 等。
- **首次提交**：2026-02-17；[arXiv](https://arxiv.org/abs/2602.15922)。
- **原文**：[HTML v1](https://arxiv.org/html/2602.15922v1)；[官方项目](https://dreamzero0.github.io/)；[官方代码](https://github.com/dreamzero0/dreamzero)。
- **核验日期**：2026-09-29。阅读深度：HTML 架构与实时执行部分、官方评测和仓库说明；未逐页精读、未复现。按 WAM（World Action Model）相邻分支收录，不改称传统 VLM 基座 VLA。

## 先读总结

1. 同时预测“未来画面怎样变化”和“机器人怎样行动”。
2. 新对象、新场景与新动作是不同泛化问题。
3. zero-shot 须说明任务、环境和机器人是否见过。
4. 大视频基座使它更适合进阶阅读，非最轻量入门基线。

## 详细介绍

### 问题解释

模型可能认识鞋带，却仍只会训练中常见的拿放。这提示语义知识与运动经验之间还有缺口。视频提供物体变化线索，但从像素预测到动作仍要学习机器人接口，仅生成正确视频不能让机器人行动。

### 具体 pipeline

视觉历史经 VAE、语言经文本编码器、本体状态经状态编码器进入自回归 DiT，以 flow matching 联合去噪未来视频和动作，再经不同解码器输出。闭环执行后用真实观测更新缓存，减轻递归预测画面的偏差。作者同时处理视频动作对齐、历史缓存与异步执行。[原文 §3](https://arxiv.org/html/2602.15922v1#S3)

### 实验与贡献范围

官方项目区分 AgiBot、DROID 未见任务/环境及新形态 YAM 适配；少量 YAM 数据后再测迁移，不能解释成完全没有目标机器人数据。项目还展示未见动作的任务进度。[官方评测设置](https://dreamzero0.github.io/)

相对 π0/SmolVLA，视频未来成为输出监督，不只是输入；相对先生成视频再接逆动力学，本文联合学习。笔记判断：要同时验证未来预测质量和闭环成功率，视频像真与动作有效不是等价指标。

### 复现状态与局限

官方代码提供 DROID、AgiBot checkpoint 和训练入口，当前公开推理采用多 GPU 服务。论文实时系统数值与公开仓库当前配置不必一致，不能把论文最佳速度当作默认下载表现。[官方代码](https://github.com/dreamzero0/dreamzero)

核心证据覆盖操作与跨形态迁移，尚不足以证明双足全身平衡。遮挡、接触和执行偏差仍可能影响预测；真实观测更新缓存不构成永不积累误差的保证。别的论文 LIBERO 成功率不能直接与本文 task progress 对比。

## 精读问题与复现门槛

先学动作块和 flow matching，再看视频潜变量与缓存。精读问题：训练是否以真实历史为条件？执行后怎样替换缓存？新形态适配和未见任务 zero-shot 分别在哪个阶段？

先设计公平协议，固定机器人、数据、任务与允许使用的目标域示范，再比较视觉语言和视频基座。无大规模计算资源时可以先分析公开设置，不必从完整预训练开始。本轮未下载权重、数据或论文，也未验证作者性能数值。
