## 先看总结

1. 这里的 “physical humanoid” 指物理模拟中的人形角色，**不等于真实硬件机器人**。
2. 先训练拥有场景真值的 RL 教师，再蒸馏成看第一视角图像和语言的学生。
3. 同时研究导航、物体接触与重排；它不是只会输出文本计划的模型。
4. 是理解特权信息、教师学生训练与主动视觉的清晰案例。

依据[HTML 环境与方法](https://arxiv.org/html/2406.19972v1)；最后一点为学习建议。

## 初学者背景：为什么需要教师

设想要求一个人形把椅子移到桌边。直接从图像学习要同时解决物体识别、走路、接触和目标判断，监督十分困难。仿真可以先提供物体位置、几何和目标坐标训练会做事的教师，再让仅有实际可用观测的学生学习教师行为。这样训练使用了特权信息，但部署学生不必直接读取这些场景真值。

教师通过目标条件 RL 和对抗动作先验学习；学生接收第一视角 RGB、语言、本体感知和上一动作，使用图像编码器与冻结语言编码器，借助 DAgger 模仿教师。动作是 28 个 PD 控制目标；主动渲染部分额外调整颈部监督，让视线更有利于观察目标。[HTML §3 与附录 E](https://arxiv.org/html/2406.19972v1)

## 数据、实验与边界

HITR 在不同室内布局中定义物体初始/目标状态和语言指令。实验使用 Isaac Gym 中的物理人形，其手部以球形结构近似；这种接触形式适合研究较大物体重排，但不能直接代表真实多指手的精密操作。[HTML §4–5](https://arxiv.org/html/2406.19972v1)

官方实现给出教师搬运预训练、教师重排训练、学生蒸馏三个子过程，以及 HITR/HSSD 资源和权重入口。示例使用 Python 3.8、Isaac Gym，并提供多 GPU 启动命令；这些是复现入口，不是本地测试结果，也不保证当前机器能直接运行。[官方 README](https://github.com/AllenXuuu/HumanVLA)

## 对人形 VLA 的意义

**本调研解释**：HumanVLA 已具备视觉、语言到连续动作的闭环，因此可以归入广义 VLA；但它与预训练大 VLM 加动作专家的现代基础模型路线不同。关键贡献在于让复杂物理交互从真值状态控制转向视觉语言条件控制，不能用参数规模或“基础模型”标签替代这一区分。

迁移到硬件还需解决机器人形态、接触、动作范围、视觉真实感与传感噪声。正文把输入设计成现实可取得，并不能替代 sim-to-real 试验。对学生的分析也必须独立于教师：教师在知道物体真值时成功，不保证学生在遮挡时同样成功。

## 联系、阅读问题与候选复现

与 [HumanPlus](../2024_humanplus/README.md) 比较数据来源：前者主要在仿真中生成教师标签，后者通过真实遥操作采任务数据；与 [HOVER](../2024_hover/README.md) 比较蒸馏目标，HOVER 不负责语言语义。

建议逐项列出教师和学生输入，标记训练时可用、测试时可用的信息。再问：学生犯错后查询教师为何比只训练离线示范更有帮助？主动视线控制改变的是视觉观测还是任务目标？

复现门槛中高，但无需先购买人形硬件。候选起点是播放公开学生权重，再检查独立测试任务、渲染和数据资源许可。不要直接把仿真结论写成人形真机结论。本轮只有调研，未下载权重、资产或启动训练。
