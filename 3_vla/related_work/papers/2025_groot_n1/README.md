## 先读总结

1. N1 的主要真机证据是语言条件人形双臂操作。
2. System 2 是视觉语言模块，System 1 是动作模块，不等于显式思维链。
3. 关键还包括真实、模拟、生成视频与人类视频怎样共同训练。
4. 当前仓库已转向 N1.7；复现 N1 必须固定历史代码与对应权重。

## 详细介绍

### 从零理解问题

不同机器人关节数不同，人类视频甚至没有机器人关节标签。把数据直接拼起来，不会自动产生共同动作空间。GR00T N1 同时面对模型接口与异构数据两类问题。

### 输入输出与训练

图像、语言进入 Eagle-2 VLM；本体状态和带噪动作由具身相关编码器处理，DiT 通过交叉注意力读取视觉语言特征，以 flow matching 生成动作块，再由具身相关解码器输出。无真实动作的视频使用潜在动作标签训练。作者混合遥操作、模拟与生成轨迹，并在多形态模拟及 Fourier GR-1 双臂任务上验证。[原文 §2–3](https://arxiv.org/html/2503.14734v1#S2)

**教学理解**：潜在动作是解释前后画面变化的压缩变量，不天然等于电机命令。新形态仍要确定内部表示怎样解码为实际动作。

### 贡献与证据边界

相对单平台模仿学习，它系统化利用多来源数据；相对 π0，模块连接与具身编码不同。官方研究页确实以通用人形为目标，但目标须与实验分开记录。[官方研究入口](https://research.nvidia.com/labs/lpr/publication/gr00tn1_2025/)

本笔记的判断：生成视频合理不等于接触物理正确，潜在动作相近不证明精确跨形态可执行。数据消融、目标机器人任务成绩和闭环评测，比只看视频规模更能说明价值。

### 人形关联与版本陷阱

N1 的 GR-1 上肢双手操作与本主题直接相关；不能据此声称统一学会步态、落脚和全身平衡。截至核验日，官方主分支描述 N1.7 并链接 N1.5、N1.6；主干、动作接口和全身控制集成都已变化。[官方版本说明](https://github.com/NVIDIA/Isaac-GR00T)

后续系统把 VLA 与全身控制器连接的证据应独立讨论，见 [近期状态](../../RECENT_RELEASES.md)，不能倒填到 N1 原论文。

## 精读问题与复现门槛

画三条数据通路：有机器人动作、只有人类视频、模拟数据。分别回答标签从哪里来、编码器是否共享、目标平台还要采什么数据。再看消融：提升来自数据增加、种类变化还是动作模块？

初学者先看历史模型卡和输入输出样例，确认 observation/action 字段、单位、归一化及 embodiment tag，再在模拟任务评测。不能把 N1.7 安装需求当成 N1 精确复现条件。真机还需底层控制、手部标定和数据同步。本轮未下载模型或实验。
