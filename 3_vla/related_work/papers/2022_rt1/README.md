# RT-1：从多任务示范到统一机器人策略

## 元数据与阅读状态

- **作者 / 年份**：Anthony Brohan 等，2022（arXiv 首发）。

## 先读总结

1. 核心问题是：大量不同任务的机器人示范能否训练一个共享策略，而不是每个任务单独训练？[S1]
2. 输入图像历史和文字指令，直接预测离散化动作；重点是可扩展的机器人行为建模。[S2]
3. RT-1 使用预训练视觉与语言组件，但并非把一个互联网 VLM 直接微调成动作生成器；后者是 RT-2 的核心路线。[S2]
4. 对初学者最值得掌握的是条件输入、动作表示、数据多样性与闭环控制四者的关系。

## 问题是什么

“拿杯子”和“关抽屉”看起来不同，但都需要辨认目标、定位接触位置、连续修正动作。直观上，共享视觉和动作知识应当比完全独立学习更高效。难点在于机器人数据昂贵，而且一个模型既要容纳多任务，又要及时输出控制指令。

## 方法：输入、输出与流程

项目方法给出的链路是：**图像短历史 + 指令 → FiLM 条件化 EfficientNet → TokenLearner → Transformer → 动作 token → 控制器**。[S2]

- 语言嵌入通过 FiLM 调制视觉特征，可以理解为让“关抽屉”与“拿杯子”关注画面不同部分。
- TokenLearner 把密集图像特征压成少量 token，降低后续注意力计算量。
- 输出包含末端平移、旋转、夹爪，以及底盘运动和模式切换；动作维度离散成区间，以分类形式学习。模型使用交叉熵监督。[S3]
- 执行后重新观察，再预测下一步；项目报告策略指令频率为 3 Hz。这是该系统策略层的频率，不代表所有电机伺服循环仅运行在 3 Hz。[S2；后半句为概念澄清]

**解释性推导**：离散化让动作学习可以复用序列模型，但分箱分辨率会约束精细动作表达。与“语言里写出动作名称”不同，token 必须被解码成有单位、坐标系和范围的控制量。

## 数据与监督

官方博客报告由 13 台机器人在 17 个月收集约 13 万段示范，涵盖 700 多个任务，包含抓放、抽屉操作等；每段轨迹配文字任务描述。训练是模仿示范动作，不是依靠在线试错自动发现全部技能。[S3]

## 实验证据、边界与局限

论文摘要支持“扩大机器人数据及其多样性可以提高模型泛化”的结论；项目比较已见任务、新指令、干扰物和背景变化，并探索混入其他机器人及仿真数据。[S1][S2] 这些结果并不等于任意新机器人无需适配即可工作，也不等于已获得双足平衡或足地接触控制。

局限分析：示范覆盖不足的物理交互仍然困难；离散动作、较低策略频率和相对固定的身体接口，都使其不能直接替代高速全身控制器。长任务演示若结合 SayCan，应把上层规划与 RT-1 单步技能能力分开理解。
