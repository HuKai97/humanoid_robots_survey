## 详细介绍

### 零基础问题解释

如果训练时总在同一张桌子放杯子，模型可能记住背景与位置，而非学会找杯子。家庭变化还包括橱柜、光线、杂物和执行顺序。“新物体”与“新家庭”测试的是不同泛化轴，不能混在一个笼统分数里。

### 输入输出和原论文配方

图像、本体状态与总任务输入模型；高层输出文字子任务，低层据此生成动作块。原论文 v1 先用 FAST 离散动作，与语义、网页等任务共同预训练；后训练加入 flow matching 动作专家，同时保留文字预测。数据含移动操作、多环境固定机械臂、实验室跨形态数据及高层监督；作者用未见家庭整理任务和数据消融研究泛化。[原文 IV–V](https://arxiv.org/html/2504.16054v1#S4)

**教学理解**：高层可以说“先拿起盘子”，低层负责下一段运动；这是接口示例。统一模型能承担两种输出，不表示两者以同样频率运行，也不代表无限任务记忆。

### 版本和证据边界

当前 openpi 将开源 π0.5 描述为使用 knowledge insulation 的版本，并注明 π0.5 训练和推理目前只支持 flow matching 头。[官方版本说明](https://github.com/Physical-Intelligence/openpi)

Knowledge Insulation 是另一篇 2025-05-29 提交的论文，研究新动作模块对预训练知识与训练速度的影响；不能倒填到 4 月原论文中。[后续论文摘要](https://arxiv.org/abs/2505.23705)

本笔记的判断：完整家庭泛化复现仍需核对原始数据、任务划分和高层接口，公开 checkpoint 微调只是部分路径。开放世界是实验目标与证据范围的描述，不是所有家庭、所有任务均能成功的保证。

### 与其他工作和人形的关系

π0 奠定连续 VLA，FAST 改动作 token，π0.5 更强调异构监督与环境泛化。其主要证据属于移动操作；轮式底盘与双足人形平衡约束不同。值得迁移的问题是子任务能否帮助上肢操作、失败恢复和切换，而非直接宣称解决了全身行走。
