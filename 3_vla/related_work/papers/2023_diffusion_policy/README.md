# Diffusion Policy：用去噪生成连续动作序列

## 元数据与阅读状态

- **完整标题**：Diffusion Policy: Visuomotor Policy Learning via Action Diffusion
- **作者 / 年份**：Cheng Chi 等，2023 首发；本轮同时核对 arXiv v4 HTML，注意后续修订与首发版本差别。
- **定位**：P0；生成式模仿学习基础，原始方法是视觉运动策略，**不能因使用 diffusion 就自动称为 VLA，也不是人形全身策略**。

## 先读总结

1. 输出对象是未来动作序列；扩散过程发生在动作空间，不是给机器人生成一张图。[S1]
2. 根据观察反复去噪，把随机动作候选变成示范分布中的合理动作。[S2]
3. 预测较长序列、执行其中较短一段，然后重新观察，形成滚动控制。[S2]
4. 推荐作为理解连续动作头的 P0 基础；没有机器人也能先用官方 Push-T 仿真学习数据、训练和评估链路。[S3]

## 问题是什么

**教学例子**：推物体时，示范可能选择从左绕过障碍，也可能从右绕过。若只用平方误差输出单一平均动作，可能得到朝障碍中间走的结果。学习动作分布的目标，是保留不同合理解，而不是只拟合它们的均值。

## 方法与监督

链路是：**历史观察编码 → 带噪动作块与噪声步数 → 条件去噪网络 → 连续动作块 → 执行前若干步**。训练时从示范取动作块，随机加噪，用观察作为条件学习预测噪声；推理时从随机噪声逐步生成动作。图像只作为条件编码，不需要在每轮去噪时重新生成未来图像。[S2]

这里有三个长度：观察历史 `To`、预测动作长度 `Tp`、本轮实际执行长度 `Ta`；`Ta` 与 `Tp` 不必相等。官方仓库把对应配置称为 `n_obs_steps`、`horizon`、`n_action_steps`。[S3] 这些不是同一个“序列长度”。

**解释性推导**：固定算力下，执行长一点可摊薄推理成本，但新扰动发生后要等更久才能反馈；执行短一点反应快，却增加推理负担。比较两种模型时，如果执行长度不同，成功率差异未必全由网络结构造成。

## 数据与实验实际说明什么

原论文是从示范进行 behavior cloning，涵盖多个操作基准、不同动作维数与仿真/真机设置；摘要报告 4 个基准的 12 项任务。[S1] 它证明在相应任务条件下，生成式动作分布与序列预测具有价值；没有证明仅训练一个 diffusion policy 就具有开放词汇语义理解，也没有建立全身平衡保证。

作者指出示范不足仍会影响效果，多步采样增加计算和延迟。[S2] 其他局限分析：动作归一化错误会整体改变控制幅度；训练损失下降也不自动等于闭环成功率上升；轨迹级划分比相邻帧随机划分更符合实际泛化评估。

## 联系、阅读问题与复现检查

与 [ACT](../2023_act_aloha/README.md) 比较“都输出动作块，但如何生成动作分布”；与 [Octo](../2024_octo/README.md) 比较“扩散头如何接上通用多模态骨干”。

可行复现顺序是官方 state-based Push-T 示例 → image-based 示例 → 修改一个变量。先核对动作单位、归一化、三个 horizon、训练/评估 seed、checkpoint 选择方式；同时记录离线损失与闭环分数。官方提供配置、日志和 checkpoint 入口，但本轮没有下载或运行。[S3]

阅读问题：网络去掉的是谁的噪声？模型是否预测未来状态？多模态动作分布如何通过采样表现出来？什么情况下增加动作执行长度反而失败？
