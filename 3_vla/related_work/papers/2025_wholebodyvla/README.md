## 先看总结

1. 不只有“移动之后再操作”，模型要让移动为抓取和放置服务。
2. 利用没有机器人动作标签的第一视角视频，先学习潜在动作监督。
3. 高层输出手臂动作与运动命令，后者由专门的 RL 运动策略执行。
4. 有 AgiBot X2 实机实验；“全身”不代表 VLA 直接输出全部腿关节或电机力矩。

依据[摘要](https://arxiv.org/abs/2512.11047)与[项目流程](https://wholebodyvla.github.io/)。

## 背景：为什么用潜在动作

人类视频容易获得，但没有机器人关节标签。潜在动作模型从前后图像差异提取离散代码，让模型先学习“发生了什么动作”，再用机器人数据把代码对应到执行命令。初学者可以把它理解为中间表示学习，而不是从人类视频直接复制电机信号。

WholeBodyVLA 先用操作及与操作相关的移动视频训练潜在动作模型，再让 VLM 从图像和语言预测这些代码，最后借助机器人遥操作数据学习执行映射。部署输入为第一视角观察和指令；潜在动作被解码成双臂关节动作及移动命令，LMO 控制器负责精确移动、转向与下蹲。[HTML 方法与附录](https://arxiv.org/html/2512.11047v2)

项目将高层解码与低层执行分为不同频率，强调低层在扰动下可靠跟踪。这里必须区分学习到的潜在代码与实际动作：前者用于跨数据来源共享监督，后者才具有机型和单位约束。[项目](https://wholebodyvla.github.io/)

## 实验与可复现范围

作者报告 AgiBot X2 上的搬放、装载和推车类任务，以及部件消融和泛化测试。这为其指定任务中的闭环移动操作提供证据。不同论文使用的示范量、控制器与评价定义不同，本调研不把其整体改善数字与其他系统直接排序。[论文摘要](https://arxiv.org/abs/2512.11047)

## 局限与研究联系

**本调研分析**：无动作标签视频并非无需机器人数据。语言和潜在动作的预训练，可以减少数据缺口，但最终仍要解决身体差异和控制接口。图像之间的变化还混合了相机移动、物体移动与身体动作，判断潜在代码是否真正服务任务，需要下游闭环验证。

对照 [HOMIE](../2025_homie/README.md)，可看到上肢命令与低层运动控制的共同分工；对照 [OpenHLM](../2026_openhlm/README.md)，要问是否把腿部关节也暴露给高层。这里的“全身协调”应按可输出命令及实验来理解，不能仅凭名称。

## 阅读问题与候选复现

建议把三类数据分开写清：无动作标签视频、带语言的视频、机器人遥操作。分别标记它们监督哪个损失。继续追问：若只替换低层控制器，潜在动作解码还能沿用吗？作者的移动精度收益来自高层模型还是低层 LMO？消融有没有固定两者之一？

完整原样复现目前存在代码可得性障碍。可先做方法学习或在已开源基线上验证“视频潜在动作是否改善任务”的缩小实验，但那属于新实验，不能称已复现 WholeBodyVLA。本轮未下载数据或模型。
