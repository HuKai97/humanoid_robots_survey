# SIMPLE：面向人形移动操作的仿真学习与评测

## 先读总结

- SIMPLE（2026）面向人形 loco-manipulation；不要与2024年的 SIMPLER 混淆。
- 用 MuJoCo 处理物理与控制，Isaac Sim 提供视觉渲染，并整合数据收集与策略评测。[S1][S2]
- 作者报告包含 60 项任务、50 个室内场景，并展示相似设置下的有限真机迁移。[S1]
- 这是值得跟踪的新平台，其广泛有效性仍需要更多独立复现。

## 研究问题

桌面机械臂benchmark不检验走路、弯腰、平衡和操作的耦合。人形真机评测昂贵且难重复。如果要比较高层 VLA，需要一个能同时处理视觉输入、全身动作和接触约束的实验平台，并检验仿真表现与真实表现的关系。[S1]

## 详细方法和系统闭环

SIMPLE 将物理模拟与渲染分离：MuJoCo推进动力学与控制，Isaac Sim同步状态生成视觉观察。这样各引擎承担不同职责，而不是让两套动力学同时决定同一个身体。数据可先在物理环境采集，再回放生成多样化视觉条件。[S2]

示范有两条路线：运动规划和脚本协调形成自动轨迹；VR遥操作产生人工轨迹。高层任务策略输出身体参考/操作和移动指令，低层追踪控制器承担更快的身体执行。于是比较VLA时必须固定或明确改变低层控制器，否则性能差别未必来自高层模型。[S2][S3]

项目在不同随机化条件下评估策略，并分析示范数量、来源和视觉变化。统一接口减少接入负担，但不等于不同模型的预训练数据、微调预算和推理延迟已经天然公平。

## 实验支持范围与局限

作者报告仿真与现实表现的关联，并展示用仿真数据训练的策略在相似真实任务中迁移。官方页面的真机展示限于选定抓放/交接设置；因此它支持具体条件下的可行性，不能推出“任何场景、任何人形都可零样本部署”。[S1][S2]

当前仓库持续加入控制器和模型支持，主分支与初始论文不一定完全一致。[S3] 本笔记没有运行这些集成，不将“有适配文件”视为完整独立复现证据。

## 与其他工作的关系

接在 HOVER/HOMIE 等低层控制学习之后，可理解为什么VLA需要身体接口；与 SIMPLER 对照，可比较“仿真是否保留真实结论”的验证方式。与 RoboCasa365 对照，要先确认机器人动力学和任务范围，再讨论谁适合自己的研究问题。

## 初学者复现检查

先运行一个任务并跟踪图像、物理状态和动作时间戳，检查跨引擎同步。再固定高低层版本、环境资产、动作归一化和随机化级别。报告任务成功之外，还记录跌倒、碰撞和干预。安装两套引擎、渲染与模型推理都有资源要求，因此它适合作为进阶项目，而不是零基础第一天的训练目标。
