# 复现入口与报告规范

**当前状态：仅完成文献调研，没有安装环境、下载权重、训练、评估或真机实验。**

## 推荐起点

第一阶段选择一个官方支持的仿真策略—环境组合：例如 OpenVLA-OFT 与其 LIBERO 评估流程，或 Octo 与 SimplerEnv 官方支持流程。选择后先核验具体代码版本和检查点，不将所有 VLA 默认视为兼容所有仿真环境。入口见 [论文索引](../related_work/PAPER_INDEX.md)。

| 路线 | 学到什么 | 前置条件 | 本轮状态 |
|---|---|---|---|
| ACT / Diffusion Policy 小任务 | 数据、动作块、闭环评估 | 可运行的官方任务、依赖、算力 | 计划 |
| OpenVLA-OFT + LIBERO | VLA输入预处理、动作适配、任务评估 | 匹配的代码、检查点、benchmark版本 | 计划 |
| Octo + SimplerEnv | 真实数据策略在仿真中的评测 | 官方支持接口、动作归一化与相机配置 | 计划 |
| WholeBodyVLA / SIMPLE | 人形高层与低层控制连接 | 控制与仿真基础、足够算力 | 进阶计划 |

## 最小复现顺序

1. 冻结仓库 commit、环境/资产版本、检查点和配置；读取该版本安装文档。
2. 运行一个环境重置和官方示例，检查图像、状态、动作形状与单位。
3. 固定任务、seed、episode起点和成功判定；先回放或单步验证适配器。
4. 跑 baseline，保存原始每回合结果、视频/关键帧、延迟和失败原因。
5. 完成 [预定评测](../experiment/evaluation.md)，写报告，再考虑改模型。

## 每个实际报告必须写

- 方法、原论文、代码 commit、checkpoint标识、运行命令、依赖、硬件。
- 复现目标：哪张表、哪个任务/条件；与原设定不同之处。
- 数据及划分、动作接口、指标分母、随机种子和原始结果路径。
- 结果：原文作者报告值和本地测量值分列，不混写。
- 失败案例、偏差解释、未验证事项和下一步。

没有测量就写“未运行”，没有对齐条件就写“功能验证/部分复现”，不要写“已复现论文”。
