## 1. 先登记条件，再比较结果

## 3. 必报指标

### 几何解释与经典指标

对模型点集 M，真值 `(R,t)`、预测 `(R̂,t̂)`：

```text
ADD   = mean_x∈M || R̂x + t̂ − (Rx + t) ||₂
ADD-S = mean_x∈M min_y∈M || R̂x + t̂ − (Ry + t) ||₂
e_t   = ||t̂ − t||₂
e_R   = acos(clamp((trace(R̂ Rᵀ) − 1)/2, −1, 1))
```

`e_R` 对对称对象需在合法等价旋转中取最小值或按官方评测处理；ADD-S 的最近邻策略也不等同于精确枚举所有语义/任务对称性。模型单位决定 ADD 和平移误差单位。ADD(-S) 的单阈值准确率与 AUC 不相同；若报 AUC，必须写积分区间和归一化方式。

### BOP 指标

VSD 比较可见表面，MSSD 比较考虑对称性的最大三维表面偏差，MSPD 比较考虑对称性的最大投影偏差。经典 BOP localization 的 `AR = (AR_VSD + AR_MSSD + AR_MSPD)/3`，其中各 AR 跨官方阈值求平均；不要自己挑某一阈值替代官方平均。更近的 detection 赛道还涉及 AP，应使用对应年份/任务的 evaluator。[BOP 评分说明](https://bop.felk.cvut.cz/media/bop_challenge_2020_results.pdf)、[官方工具](https://github.com/thodan/bop_toolkit)

实际执行时固定 toolkit commit、targets 文件、对称变换、渲染器和容差配置。精确实现以固定版本工具为准，本文件的概念公式不替代 evaluator。

### 类别、跟踪与操作指标

| 层级 | 至少报告 |
|---|---|
| 类别级 | 按对应论文协议的 3D IoU mAP、旋转/平移阈值 mAP（例如 5°/2 cm、5°/5 cm、10°/5 cm）；尺寸误差；写清匹配门限与对称处理 |
| 连续跟踪 | 每帧几何误差、有效跟踪帧比例、失效次数、连续有效时长、重初始化延迟；固定首帧条件 |
| 抖动 | 真静止片段中 SE(3) 变化；动态片段分离真实运动与估计抖动 |
| 性能成本 | 对象准备耗时、初始化耗时、逐帧处理 p50/p95、传感器到输出的延迟、显存、重初始化成本 |
| 机器人任务 | 成功次数/总尝试数、重试次数、失败原因；抓取和放置分开，任务容差预先定义 |

失效帧不能从平均指标里静默删除，无输出计失败。预先声明无 CAD 轨迹允许的首帧坐标规范转换；不能逐帧利用 GT 对齐来掩盖漂移。独立尝试/序列作为统计单位，报告样本数；不把高度相关的视频帧数当成独立试验数。若报告置信区间，说明重复实验或序列级 bootstrap 的方法。

## 4. 最小对照组

- **Baseline：** 固定配置的原方法。
- **Oracle mask：** 仅用于量化分割带来的差距，与真实自动前端分栏。
- **Oracle 初始化：** 仅用于隔离跟踪性能，不混成端到端成功率。
- **消融：** 每次只改变一个设计，例如去掉精修/时序约束/重定位。若提出新模块，应提供预算匹配的简单替代或合理随机对照；不为凑表格设置无意义随机姿态。
- **几何检查：** 正确输入/GT 位姿能否投影回图像；该项用于验证坐标和评测实现，不作为算法成绩。

## 5. 预先冻结失败案例与分层

在验证集选定 8 段并记录 ID：无遮挡、轻遮挡、重遮挡、对称物体、弱纹理、深度失效、相机快速运动、出画后返回。不存在的类型写缺失，不能临时挑最好看的例子。

必出：模型/轴叠加图、原始 mask、深度有效率、按对象/距离/遮挡的误差表、时序误差和状态曲线、延迟分布、固定失败案例。图名必须能追溯到原帧和实验版本。
