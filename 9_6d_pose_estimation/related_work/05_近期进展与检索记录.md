# 近期进展、检索范围与证据边界

检索日：2026-09-29。以学习谱系和人形机器人操作相关性选代表工作，覆盖 2018–2025 的经典与近期论文，并抽查 2026 动向。**这不是对截至该日全部论文的穷尽综述，不宣称包含最新全部 SOTA。**

## 已纳入逐篇解析的近期工作

- [Any6D（CVPR 2025）](papers/2025_any6d/README.md)：降低对象准备的参考视图数量，值得关注尺度和生成几何的误差。
- [6DOPE-GS（ICCV 2025）](papers/2025_6dope_gs/README.md)：关注在线重建/跟踪的计算成本与对象表示。
- [HOT3D（CVPR 2025）](papers/2025_hot3d/README.md)：将第一视角、多视角和手物交互纳入评测。

上述选择的意义是补齐输入条件与应用维度，不是用年份替代质量判断。

## 检索过程

1. 读取用户指定的 [research-workflow](https://github.com/skJack/research-workflow) 的 README、SKILL、初始化脚本和模板。
2. 从经典方法、类别级、新物体、跟踪和基准五类检索代表工作，再沿作者项目/论文引用补充。
3. 优先 CVF、arXiv、会议主页、作者项目、作者 GitHub 和 BOP 官方站；第三方结果只用于发现线索，不作为方法论证依据。
4. 对易混淆的输入、对象先验、论文版本、mask 来源和代码发布情况二次核验。

检索词示例：`FoundationPose unified 6D pose tracking official`、`category level object pose NOCS GenPose CAPTRA`、`6D pose unseen objects ICCV 2025`、`Any6D model-free official`、`HOT3D hand object tracking`、`BOP evaluation VSD MSSD MSPD`、`6D pose estimation 2026 prior free`。这是检索轨迹说明，不是形式化系统综述的可复现数据库检索式。

## 证据等级怎么读

| 笔记标记/内容 | 能支持什么 | 不能支持什么 |
|---|---|---|
| 官方题录、摘要 | 题名、年份、任务与主要主张 | 全部算法细节、完整实验条件 |
| 方法 HTML + 项目 | 主流程、关键表示、主要假设 | 未阅读表格的确切数值与全部消融结论 |
| 官方 README | 当时公开的接口、依赖、缺失模块说明 | 在本机成功安装、实时性、论文完全复现 |
| 我们的解释/工程推断 | 从明确假设推导的学习与设计建议 | 作者实证结论、人形平台已验证成果 |

每篇 `metadata.json` 的 `evidence_status` 记录该篇阅读范围。CASS、CDPN、部分 2022 年参考图像方法以摘要/架构/仓库初读为主；不能把本轮统一称为“全篇逐式精读”。本轮不编造跨论文跑分表，不下载 PDF、LaTeX、数据或模型，不运行 baseline。

## 下轮最值得补齐

先根据实际 RGB/RGB-D、CAD 和任务需求选 2–3 个 baseline，再核对其完整实验表、配置与依赖，做小规模复现。只有观察到稳定失败模式后，才将 [brainstorm](../brainstorm.md) 中的候选问题发展成研究假设。视觉触觉融合、关节/可变形对象、事件相机等方向本轮未系统展开。
