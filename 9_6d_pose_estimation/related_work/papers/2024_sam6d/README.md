# SAM-6D：把新物体分割与 3D 配准接起来

## 先读总结

**SAM-6D 的价值是同时考虑“目标在哪个区域”和“区域里的物体是什么姿态”。** 输入 RGB-D 和目标 CAD，先筛选实例 mask，再建立模型与观测的三维对应。SAM 只承担部分前端工作；整条管线不是无需任何训练的系统。优先级 **P0**。[论文页](https://arxiv.org/abs/2311.15707)

## 身份与证据

Jiehong Lin、Lihua Liu、Dekun Lu、Kui Jia，**SAM-6D: Segment Anything Model Meets Zero-Shot 6D Object Pose Estimation**，CVPR 2024；预印本首发于 2023 年。本次阅读 HTML 方法及部分实验说明、官方自定义数据使用说明，未运行模型。[官方实现](https://github.com/JiehongLin/SAM-6D)

## 输入输出与训练前提

ISM 是实例分割模块，利用现成基础模型生成并筛选候选；PEM 是姿态模块，需要在合成数据上训练。zero-shot 指目标对象未参与任务训练，新对象不必再训练，仍然需要目标 CAD、相机内参和深度。输出包括实例区域及其 `R,t`。[论文 HTML §1、§3](https://arxiv.org/html/2311.15707v2)

## 方法步骤与关键表示

ISM 将候选与对象渲染模板比较，综合语义、外观和几何评分，避免单凭语义相似度认错实例。PEM 将问题表达为部分点云对部分点云匹配：粗阶段建立初始对应，细阶段利用位置关系细化；背景 token 接收无有效对应的点，不强迫遮挡和背景点匹配到模型表面。[论文摘要](https://arxiv.org/abs/2311.15707)

**与传统点云配准的联系：** 在全模型与局部观测之间，不是每个点都有真实伙伴。把所有点一律寻找最近邻，会让桌面、手掌、遮挡边界对位姿产生错误拉力。“允许不匹配”本身就是一个重要建模选择。学会判断可对应区域，往往比仅提高描述子维度更接近问题本质。

粗到细也有具体几何意义：初始位姿把两个点集放到较接近的空间后，位置关系才更适合帮助局部匹配。读取网络图时，可为每一层标注其坐标属于模型还是相机，是否已经过初始变换；这样能避免把特征空间相似和真实几何距离混为一谈。

## 实验与实现可核查性

作者在 BOP 七个核心数据集上分别评估新物体分割与姿态估计；实验支持其完整管线和匹配设计的效果，本笔记没有重新计算排行榜。[论文 HTML §4](https://arxiv.org/html/2311.15707v2) 官方 demo 明确要求 CAD、RGB、depth 和 camera 文件，示例把 CAD 和深度标为毫米，并提供 SAM/FastSAM 选择。输入尺度错误可能让整条几何流程失效。[官方 README](https://github.com/JiehongLin/SAM-6D/blob/main/README.md)

## 局限与人形机器人启示

**我们的推断：** 候选阶段漏掉目标，后端再强也无从估计；候选包含手掌时，部分匹配可缓解，但不保证正确。弱深度、窄长物体、严重遮挡和同形多实例需要独立验证。基础模型的显存与前端推理耗时也应纳入机器人预算。

它很适合帮助你把轮式机器人“点云聚类—配准”经验迁移到学习式目标筛选和局部几何匹配。建议搭建前端可替换实验：固定 PEM，比较人工 mask、现成分割和真实机器人分割；再固定 mask 比较姿态后端。这样可以定位瓶颈，而不会把整个系统的失败都归因于 6D 模型。

## 学习与复现检查点

1. 补齐 RGB-D 反投影、刚体配准、遮挡下部分重叠与外点拒绝。
2. 后续真正复现时先核对米/毫米、深度缩放、内参和 RGB-depth 对齐。
3. 分别记录分割召回、姿态成功率及完整管线延迟；同一时刻多个对象的耗时也要测。
4. 人为腐蚀/膨胀 mask，加入手部遮挡，分析“不对应点”数量与错误位姿的关系。
5. 与 FoundationPose 比较时固定目标 CAD、检测前端、图像和评估协议，不直接混用论文总分。
