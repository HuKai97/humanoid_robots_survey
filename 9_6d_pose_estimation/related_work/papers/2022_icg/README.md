# ICG：面向已知几何的快速传统跟踪基线

## 先读总结

**优先级 P0，尤其适合从传统几何感知转入物体跟踪。** ICG 将图像中的前景/背景区域信息与深度表面约束放入统一优化，逐帧更新已知物体位姿。它不要求纹理模型，但需要物体几何与合理初始化。[论文][paper]

它的学习价值是展示：在先验充分、连续运动的任务里，几何优化仍是应认真比较的基线。是否选择它，首先取决于能否获得模型及初始化，而不只是是否偏好深度网络。

## 任务边界与先验

输入为连续颜色和深度观测、相机标定、物体几何与初始位姿；输出每帧刚体变换。物体可以低纹理，但目标与背景仍需提供可区分的区域信息，深度也应可测。方法属于局部跟踪，不能把它当作无初始化的全局检测器。[论文][paper]

官方 C++ 框架支持多相机、区域/深度模块和多物体组合，有 RealSense/Azure Kinect 可选接口。它不靠神经网络训练获得物体能力，仍需模型准备、视点表示与参数配置。[代码][code]

## 方法拆解

1. 从物体模型预生成不同视点的轮廓/表面稀疏表示。
2. 将当前估计轮廓投影到图像，用跨边界的对应线评估前景与背景变化。
3. 将模型表面点与深度对应，构造点到平面的几何约束。
4. 按不确定性组合信息，并以正则化 Newton 更新局部位姿；遮挡处理减少错误对应。[论文][paper]

**我们的解释：** 你熟悉的 ICP 只提供其中一部分。深度在大平面切向上的约束可能很弱，轮廓可补充边界位置；背景颜色与物体相似时，深度又能提供独立帮助。两种信息共同解释同一个 SE(3) 状态，而不是各算一个姿态再简单平均。

## 证据与局限

论文给出多个跟踪数据集实验，并明确指出局部极值、邻近姿态几何相似、背景可分性及深度质量限制。[论文][paper]

**我们的分析：** 初始化误差与相邻帧运动幅度决定能否落入收敛范围。遮挡消失后的重新检测应独立设计，不能用人工重置掩盖真实丢失。模型尺寸或相机外参有误时，优化仍可能稳定收敛，但所得姿态带系统偏差；稳定不等于准确。对称物体上的某些旋转不可观测，滤波不能创造不存在的信息。

## 人形机器人启示（工程推断，待验证）

若操作标准工具、箱体或零件且有 CAD，ICG 值得作为精跟踪候选，用检测/通用姿态模型完成初始化，再持续局部跟踪。头部或手腕运动较快时，可用机器人运动学提供下一帧初值，并让视觉纠正；要先验证时延和手眼标定，否则初值反而可能被带偏。

建议用“静止物体、机器人动头”的简单实验测静态漂移，随后增加遮挡、物体运动与接触。也应记录每次丢失前的残差、可见比例和迭代状态，建立重定位触发规则；这比单看视频中模型覆盖得好不好更适合闭环工程。

## 学习与复现检查点

- 推导点到平面误差对小位姿增量的雅可比，再理解区域信息如何进入优化。
- 确认 mesh 单位、法线、颜色/深度外参与模型坐标原点。
- 将初始化时间、每帧跟踪时间、重定位时间分开统计。
- 同时比较轨迹误差、连续成功时长和丢失恢复，固定初始化难度。上述验证未执行。
