# DenseFusion（CVPR 2019）

## 速读总结

**RGB-D 入门首读：按对应像素融合外观和几何，再学习迭代修正。** 它讨论的不是“有深度就能解决位姿”，而是不同传感器表示怎样有效合用。[论文](https://arxiv.org/html/1901.04780)

学习优先级：**P0**。对熟悉点云、标定和 ICP 的轮式机器人感知工程师，这篇很适合建立深度学习与几何之间的联系。

## 任务边界、输入输出与先验

输入为对齐的 RGB-D、内参和目标分割，输出已知物体相对相机的 `R,t`。训练使用对象模型点和姿态监督；增加新对象通常需要适配训练。仓库允许替换分割器，并提供位姿网络、精修网络和示例分割器，但不提供真实机器人实验的 ROS 代码。[官方代码](https://github.com/j96w/DenseFusion)

## 方法步骤与关键表示

1. 分割目标；深度反投影为点云，RGB 区域由 CNN 提取特征，点云由 PointNet 类网络编码。
2. 按点与像素对应关系融合局部特征并加入全局上下文；逐点预测位姿与置信度，选取高置信候选。
3. 用当前位姿把点云变到估计物体系，再预测残差并迭代组合；损失比较模型点，对称对象使用最近邻形式。[方法第 3 节](https://arxiv.org/html/1901.04780)

**我们的解释：** 一个点云点和一个 RGB 像素必须描述同一处表面，融合才有明确含义。外参偏差、RGB 与深度不同步，都会把不同表面的特征强行拼在一起。因此，这类网络的输入质量检查应该包括“点投影是否落在对应边缘”，而不仅是图像看起来正常。

残差预测可以类比 ICP 的逐步修正，但修正规律由数据学习。它仍有收敛范围；“迭代”不代表能把任意错误初值救回来。置信度也不能直接解释为经过校准的抓取成功概率，需要独立验证可靠性。

**建议的小练习：** 人为给深度增加固定偏置，再给 RGB 与深度增加像素错位，比较两种扰动的误差形态。前者主要改变测量几何，后者破坏对应关系；分开构造它们，能让“融合失效”的描述变得可检验。

## 实验结论与可信范围

作者报告 YCB-Video、LINEMOD 的效果并展示机器人抓取。[项目页](https://sites.google.com/view/densefusion/) 仓库训练流程先学初始位姿，再启动精修训练；这与把所有模块从第一步同时优化并不相同。[官方 README](https://github.com/j96w/DenseFusion) 本笔记不移植论文速度或成功率到用户硬件。

## 优点、局限与人形机器人启示

**我们的分析：** 局部融合适合检查遮挡下的可见证据；预测和精修又提供了明确的消融边界。局限来自前置分割、有效深度、已知对象和训练分布。透明杯、反光器具、深度空洞不能仅靠“多模态”标签视为已解决。

**工程推断，非论文人形验证：** 可用作头部 RGB-D 看桌面的学习基线。将目标按遮挡率、有效深度比例、距离和运动模糊分层，比较初始结果与精修结果。若精修频繁恶化，需同时记录输入深度与初值误差，才能判断是网络问题还是传感器问题。真正闭环抓取还需要手眼标定、抓取生成、碰撞检测和失败恢复。

- 官方 README 提醒模型距离统一到米；核对原始深度缩放和 CAD 单位。[官方代码](https://github.com/j96w/DenseFusion)
- 分开计时分割、预处理、位姿和精修；记录对象数与输入点数。
- 对多个相同对象检查实例分割接口，避免把一个语义类别的两堆点混成一件物体。
