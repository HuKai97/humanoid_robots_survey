# GDR-Net（CVPR 2021）

## 速读总结

**让几何中间表示指导可学习的位姿回归。** GDR-Net 保留稠密对应和表面区域等信息，再用 Patch-PnP 直接预测姿态，连接了对应点方法与端到端学习。[论文 v1](https://arxiv.org/html/2102.12145v1)

学习优先级：**P0**。读完 CDPN 后重点比较：传统求解器换成学习模块，究竟保留了哪些几何信息？

## 基本信息与版本警告

## 任务边界、输入输出与先验

输入为 RGB 的目标区域、内参及裁剪信息；输出已知对象的相机系姿态。CAD 用来生成对象坐标、表面区域等监督，训练需要目标对象知识。因此“单目”描述输入模态，并不表示无对象模型或无需训练。[方法 §3](https://arxiv.org/html/2102.12145v1)

## 方法步骤与关键表示

1. 网络预测对象坐标图、可见掩码和表面区域注意力。
2. 将二维位置与三维坐标组织为对应图，送入卷积式 Patch-PnP。
3. 回归连续六维旋转表示与尺度归一化平移；用中间几何监督和解耦姿态损失训练。[方法 §3](https://arxiv.org/html/2102.12145v1)

**我们的解释：** 名称中的 Patch-PnP 不应理解为直接调用传统 PnP 数值算法；它学习从组织好的几何特征到姿态的映射。工程上可以分别可视化坐标图和最终姿态，判断“几何表示已经错了”还是“从表示到姿态的映射出了问题”。

这里的“六维旋转表示”也不是“6D 物体位姿”：它用六个数表示三个旋转自由度，而完整位姿还包括三个平移自由度。将两个预测向量正交化构成旋转基，解决的是网络输出的参数化问题，不会增加现实物体的自由度。

**建议的小练习：** 把同一物体移到图像边缘，比较裁剪图中的朝向与相机坐标系中的朝向，再画出视线方向。这个练习能帮助理解局部观测旋转与最终相机系旋转为何需要转换，避免只凭可视化框看起来正确就结束排查。

## 实验结论与可信范围

作者报告 LM、LM-O、YCB-V 上的结果，并分析几何中间表示和姿态参数化。[v1 论文页](https://arxiv.org/abs/2102.12145v1) 官方仓库另列出 GDRNPP、GPose 等后续成果；它们应单独登记。[官方代码](https://github.com/THU-DA-6D-Pose-Group/GDR-Net) 本笔记未复核每张消融表，不引用排名或速度。

## 优点、局限与人形机器人启示

**我们的分析：** 这篇适合学习如何设计“可解释的中间任务”，避免从最终误差直接猜网络哪里失效。局限是学习模块依赖训练分布；几何监督不自动保证跨对象、跨相机或跨距离泛化。对称表面和大面积遮挡会带来可辨识性问题，不能仅由更强回归头消除。

**工程推断，非论文人形验证：** 适合已知工具或零件的 RGB baseline 研究。可先建立小规模自有 CAD 集，固定检测器与训练数据，再比较位姿网络。如果 RGB-D 传感器在某些材质上失效，RGB 路线可能有价值，但需用相同目标、相同可见性协议验证。相机更换或输入裁剪变化时，应把尺度恢复与内参处理列为首要检查项。
