# BundleSDF：一边跟踪未知物体，一边建立模型

## 先读总结

**优先级 P1。** BundleSDF 从 RGB-D 视频和首帧目标掩码出发，同时估计未知刚体的运动和三维形状。核心是让位姿图、历史关键帧和在线神经物体场互相修正。对已有 SLAM 经验的工程师，它是连接“场景定位建图”与“被操作物体跟踪”的重要桥梁。[作者项目][project]

它适合研究首次遇到的物体与交互过程，但首次建模得到的对象坐标系不自动带有“把手朝向”等任务语义。

## 任务边界与先验

不要求目标 CAD 或该类别专门训练，但对象须为刚体，需可靠深度和首帧分割。通用匹配、视频分割可使用预训练网络，物体神经场则在当前视频中在线学习。“无需目标模型”不等于“完全没有模型与训练”。首帧作为坐标锚点。[论文][paper]

仓库自定义数据格式包含 RGB、深度、掩码和内参。README 说明未因许可原因集成 XMem 的在线封装，若要在线分割需自行补接；这使论文输入设定与开箱运行条件存在实际差距。[代码][code]

## 方法拆解

1. 先通过图像匹配与深度得到当前帧的粗位姿。
2. 保留有信息的历史帧，避免所有观测直接不可逆地融合。
3. 将当前帧与部分历史帧放入位姿图共同优化。
4. 并行学习物体 SDF 和外观，修正历史位姿，再反馈给跟踪线程。[论文][paper]

**我们的解释：** 类似 SLAM 中保留关键帧后重新优化，但状态围绕物体建立。相机可动、物体也可动；能直接得到的是物体相对相机的关系。若还要世界系物体速度，必须提供同步的相机运动。模型被手夹持后，手上的点若漏进 mask，可能被当成物体表面，从而污染后续跟踪和重建。

## 证据与局限

作者展示了交互、遮挡及低纹理场景，论文也明确给出混合困难条件下的失败、透明物体深度失效与刚体限制。[论文][paper]

官方流程区分视频跟踪/重建、后续全局细化与姿态绘制。不能用离线全局细化后的模型质量描述在线任意时刻的模型质量，也不能将论文速度当作人形整机已达到的速度。[代码][code]

**我们的分析：** 刚开始时模型不完整，可见面太少会形成姿态—形状相互补偿。长期遮挡之后，即便重现的几何相似，语义朝向也可能发生等价跳变。延迟、显存占用、关键帧数量增长均需在实际任务时长下测量。

## 人形机器人启示（工程推断，待验证）

适合把“拿起物体后转动观察”作为建模动作：双臂既是执行器，也可提供新的视角。部署前应设计独立的语义坐标标定步骤，把首次任意对象系转换为抓取/工具使用坐标；否则每次重新初始化后，同一抓取变换可能失效。

可将机器人手部几何作为 mask 检查信息，但不能直接假设手物刚性连接一直成立：松动、换手和滑移需要重新估计。实验应分开固定相机转动物体、移动相机静止物体、两者同时运动，定位错误来源。

## 学习与复现检查点

- 先将“世界系—相机系—物体系”画清楚，检查首帧坐标锚点与输出变换方向。
- 对比在线输出和全局细化输出，保存各自时间戳与版本。
- 显式说明 mask 来自人工、离线传播或在线分割，记录失效恢复策略。
- 分别测位姿误差与形状完整度，再测接触任务成功率；本次未执行。
