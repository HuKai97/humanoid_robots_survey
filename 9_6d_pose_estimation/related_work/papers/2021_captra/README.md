# CAPTRA：类别级位姿从单帧扩展到连续交互

## 先读总结

**优先级 P1。** CAPTRA 利用上一帧姿态把当前点云转到近似规范姿态，降低下一次估计难度；同时处理刚体和由刚体部件构成的关节物体。相比逐帧独立检测，它更直接面向连续操作中的物体状态反馈。[论文][paper]

对于人形操作，重点是从“物体整体在哪里”走向“哪些部件正在相对运动”。抽屉和笔记本电脑不能始终由一个 SE(3) 描述，这也是本调研纳入该文的原因。

## 任务边界与先验

输入为点云序列和首帧位姿；关节物体需要逐部件初始化，类别内刚体部件数及定义已知。测试对象可为同类未见实例，不需要其精确 CAD。输出包含各部件旋转、平移与尺寸，常称 9DoF 描述。[论文][paper]

刚体 benchmark 使用从真值扰动得到的初始姿态；真实关节物体演示依赖对象分割。官方介绍明确区分 object mask 与 part mask，不能将前者的可用性当成系统自动获得所有对象输入。[论文][paper]、[代码][code]

## 方法拆解

1. 以上一帧的部件姿态逆变换当前点云，使其接近规范方向。
2. RotationNet 估计残余旋转。
3. CoordinateNet 预测部件归属和规范坐标。
4. 结合旋转与点对应解析恢复平移、尺度，再更新部件姿态。[论文][paper]

**我们的解释：** 规范化相当于用上一状态做条件化，将大范围姿态问题转成局部修正。它减少学习负担，也使系统对错误历史敏感：一旦上帧严重偏离，裁剪区域和规范化都会跟着偏离。这里的类别规范系与 NOCS 一脉相承，但在关节物体上变成每个部件一套坐标。

## 证据与局限

官方仓库公开刚体与关节数据处理、模型训练及测试组织；其真实数据可视化展示了笔记本和机械臂拉抽屉场景。[代码][code]

论文指出真实深度噪声会影响分割和整体跟踪。[论文][paper] **我们的分析：** 逐部件姿态正确不代表关节轴、接触力或运动阻力已知。部件被手完全挡住时，需要区分观测更新与历史预测；若仍输出确定姿态，应标明其信息来源。类别外结构，例如不同抽屉层数，也超出已知部件数的设定。

## 人形机器人启示（工程推断，待验证）

适合学习开抽屉、开盖、翻转屏幕等任务的感知分解：先用对象级检测定位，再跟踪交互部件，最后将部件运动与机器人末端运动对照。可把两者的相对运动用于发现接触滑移，但接触关系需要独立判定，不应由位姿稳定直接推断抓稳。

建议用简单的单抽屉柜开始，明确底座与抽屉的部件系，分开测整体基座运动、抽屉相对运动和相机运动。若给定较准初值能跟踪、自动初始化后却失败，应优先解决初始化接口，而不是直接否定跟踪网络。人形走动与身体遮挡条件必须后续补测。

## 学习与复现检查点

- 先复习 NOCS 和相似变换，再画出各部件坐标与相对关节运动。
- 固定初始化误差分布，对比真实检测初值，报告二者差距。
- 分别记录 object mask、part mask 的来源；对真实关节演示条件完整披露。
- 不只看逐帧平均误差，还看误差累积、部件身份交换、丢失与重新初始化次数；目前均未执行。
