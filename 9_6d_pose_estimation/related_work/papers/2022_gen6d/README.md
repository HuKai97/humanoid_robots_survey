# Gen6D：用带位姿参考图替代 CAD

## 先读总结

**Gen6D 面向“无 CAD，但可以先拍一组参考图”的新物体。** 查询侧仅需 RGB，不要求查询深度和物体 mask；参考图却需要已知位姿。它不是第一次看到一张任意照片就恢复度量 6D 的方法。优先级 **P1**。[论文页](https://arxiv.org/abs/2204.10776)

## 论文身份与阅读深度

Yuan Liu 等，**Gen6D: Generalizable Model-Free 6-DoF Object Pose Estimation from RGB Images**，ECCV 2022。本次核对摘要、作者项目和官方代码说明，形成结构级阅读；未精读完整损失推导，未运行实验。[作者项目](https://liuyuan-pal.github.io/Gen6D/)

## 输入输出和“model-free”的边界

目标先验是一组同物体的带位姿参考图，输出相对这套物体坐标系的 `R,t`。项目展示先用手机采集参考图，再借助 COLMAP 恢复参考相机位姿的用法。因此 model-free 指不依赖高质量 CAD，不意味着不需要对象专属准备。检测、视角选择、精修器是在其他对象上训练的通用网络。[项目说明](https://liuyuan-pal.github.io/Gen6D/)

## 方法步骤与关键表示

管线依次完成目标检测、参考视角选择和姿态精修。视角选择寻找与查询最接近的参考观察；精修不是渲染 CAD，而是利用多参考图建立特征体，调整初始姿态。项目比较特征体精修与可泛化 DeepIM，强调前者对新物体的作用。[作者方法说明](https://liuyuan-pal.github.io/Gen6D/)

**几何理解：** 从一个候选三维位置出发，把它投影到不同参考图，就能取到各视角的特征；正确几何附近应具有更一致的证据。参考图位姿把这些局部特征组织到同一三维空间。它与多视图立体、视觉定位中的投影关联相通，但最终学习的是位姿修正，不必先构造完整可渲染表面。

对轮式机器人感知工程师，最值得研究的是“图像库如何替代物体地图”。用 SfM 建立的对象坐标系通常需要额外与机器人任务坐标对齐。仅有单目重建相对尺度时，平移数值不能直接当成米制抓取位置；必须通过已知尺寸、标定物或其他度量信息建立尺度。这是几何要求，不应由网络名称掩盖。

## 实验依据与可用性

作者在 MOPED、GenMOP 及 LINEMOD 报告结果。官方代码可保存检测、视角选择、精修的中间可视化，适合逐段排查；README 也明确原训练集已不再提供，旧 OneDrive 资源链接失效后有替代入口。因此“使用预训练权重”和“从头重现训练”难度不同。[官方仓库](https://github.com/liuyuan-pal/Gen6D)

本笔记不把作者的基准优势外推为人形机器人动态抓取优势，也不提供未经核对的帧率数字。

## 局限与人形机器人启示

**我们的推断：** 参考视角未覆盖背面、扫描过程中光照变化、COLMAP 重建失败，都会成为上线前的缺口。低纹理表面未必能提供可靠的参考位姿；移动相机引起的模糊又会损害查询特征。没有 CAD 只是换了一种对象入库方式，而非消除了入库成本。

可由人形机器人围绕静止物体主动采图，并记录头部/腕部相机位姿，研究参考覆盖度对姿态精度的影响；但机器人正运动学并非天然足够精确，需要验证时间同步与外参误差。把这作为主动感知课题，比直接加大网络更容易形成可解释实验。

## 学习与复现检查点

1. 先复习 SfM、相机投影、尺度不可观性，再阅读特征体与姿态更新。
2. 在后续复现中分别改变参考视角数量、视角覆盖和参考位姿噪声，避免只测一个精心扫描的物体。
3. 读取官方 `custom_object.md`，先确认数据格式与度量坐标，再安装环境；本次未安装。
4. 记录精修前后误差和重定位失败率，并把旋转对称等价解与真正方向错误分开。
