# 八周学习路线

> 默认每周 6–10 小时，可按项目节奏压缩或延长。当前只完成调研；下表中的运行、数据采集和实验均为后续计划。

## 先读的十个入口

依次读：几何与任务定义 → PoseCNN → DenseFusion → PVNet → NOCS → GDR-Net → MegaPose → FoundationPose → BundleSDF/ICG（按是否有 CAD 选择）→ BOP 与 HOT3D。随后再读 SAM-6D、FoundPose、Any6D 等分支。每篇的优先级指本项目学习价值，不是学术排名。

## 每周产出

| 周 | 学习内容 | 必读/选读 | 可检查的产出 |
|---|---|---|---|
| 1 | SE(3)、投影、PnP、ICP、坐标/尺度、对称性 | 本库知识地图、OpenCV PnP 文档、BOP 笔记 | 手写一次变换链；用合成点投影并检查逆变换 |
| 2 | 已知实例的直接回归、融合和对应 | PoseCNN、DenseFusion、PVNet；选 CDPN/FFB6D | 画三种方法输入到输出；说明错误如何影响位姿 |
| 3 | 类别级规范坐标、尺寸和姿态歧义 | NOCS、FS-Net；选 CASS/DualPoseNet/GenPose | 对杯子/瓶子说明类别规范轴和可观测自由度 |
| 4 | 新物体泛化与 CAD/参考图像条件 | MegaPose、FoundationPose；选 Gen6D/OnePose++ | 为实际项目填写传感器、对象准备和初始化条件表 |
| 5 | 跑通一个主 baseline 并理解数据接口 | FoundationPose（有 RGB-D+CAD）；按条件选其他分支 | 一份实际复现报告，包含配置、输入、中间结果和失败日志 |
| 6 | 加一个有明确对照意义的 baseline | SAM-6D/FoundPose；或 ICG/BundleSDF | 固定数据和前端，报告精度与完整成本，不混条件 |
| 7 | 人形场景接口、遮挡和时序失效 | HOT3D、CAPTRA/BundleSDF；选 6DOPE-GS/Any6D | 误差来源分层；重初始化曲线；静止与运动相机对照 |
| 8 | 形成系统结论与后续研究问题 | 回读最相关 3 篇 | 方案选择记录、失败案例集、一个可证伪假设和消融计划 |

几何小练习不需要下载论文；真正复現时再按需求准备数据/模型。不要在第一周同时安装十个年代不同的代码仓库。

## 每篇论文的三遍读法

**第一遍，约 10 分钟。** 看本库“速读总结”，回答：估计谁？传感器是什么？已知什么？测试对象训练见过吗？依赖 CAD/参考扫描吗？需要初值或 mask 吗？

**第二遍，约 30–60 分钟。** 沿着方法图追踪一个对象：像素怎样变成特征，对应怎样建立，何处得到尺度，位姿怎样求出，对称性在哪处理。优先在线阅读论文方法部分和官方代码入口。

**第三遍，约 1–3 小时。** 只对主 baseline 做：检查数据加载、裁剪后的内参、输出变换、渲染与评测。逐行核对影响结果的协议，而不是只看网络结构。此时再补实验表格和消融的细读记录。

## 每次读完必须能回答

1. 输入/输出各在哪个坐标系，长度单位是什么？
2. 检测与 mask 从哪里来，推理时间是否包含它们？
3. 测试对象的 CAD、参考图像、模型训练数据是否被使用？
4. 尺度从何而来，对称姿态如何处理？
5. 论文的主要改进由哪个消融支持？当前笔记是否真的核对过该表？
6. 若移到头部/腕部相机，最先失效的假设是什么？
7. 哪种失败能靠标定/前端修复，哪种才需要改模型？

## 按你的工作条件缩短路线

| 条件 | 优先路线 | 暂缓事项 |
|---|---|---|
| RGB-D + 精确 CAD + 尽快操作 | 几何 → FoundationPose → ICG/系统评测 | 先从零训练实例网络 |
| RGB + 精确 CAD | 几何/PnP → MegaPose/FoundPose/GigaPose | 把深度依赖方法直接当成 RGB 算法 |
| 无 CAD，可绕物体拍一段视频 | OnePose++/Gen6D；有深度再看 BundleSDF | 不确认尺度就接机器人 |
| 只有单张 RGB-D 参考 | Any6D，再评估生成形状的误差与准备耗时 | 默认生成的隐蔽面几何准确 |
| 固定类别、不同实例、没有精确 CAD | NOCS → FS-Net/GenPose | 将类别内泛化宣称为任意物体泛化 |
| 主要问题是遮挡/抖动/掉跟踪 | ICG/CAPTRA/BundleSDF + 失效恢复评测 | 仅按单帧姿态排行榜选型 |

具体实施见 [复现计划](../复现/README.md)；所有路线选择均为基于输入条件的建议，代码和设备适配仍需实测。
