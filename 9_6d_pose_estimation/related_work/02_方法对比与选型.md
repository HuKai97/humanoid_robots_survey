# 方法对比与选型

先看输入和对象准备条件，再选择方法。下表是阅读与实验选型工具，**不是跨论文性能排行榜**。逐篇笔记包含一手来源、阅读深度、实验条件和具体限制；未在本项目运行任何方法。

## 1. 已知实例与几何学习

| 方法与解析 | 输入/对象条件 | 核心思想 | 先学什么 / 使用限制 |
|---|---|---|---|
| [PoseCNN](papers/2018_posecnn/README.md) | RGB 主干，已知实例；可加深度 ICP | 中心定位与旋转估计 | 解耦平移/旋转、对称性；区分 RGB 与 ICP 配置 |
| [DeepIM](papers/2018_deepim/README.md) | RGB、可渲染对象模型、初始位姿 | 渲染与观测对比、迭代精修 | 精修收敛域；不能替代检测和初始化 |
| [DenseFusion](papers/2019_densefusion/README.md) | RGB-D、对象分割、已知实例 | 逐点融合 RGB/几何与迭代精修 | RGB-D 对齐；对象训练数据需求 |
| [PVNet](papers/2019_pvnet/README.md) | RGB、已知对象关键点/CAD | 像素投票关键点 + PnP | 遮挡关键点与几何求解；需实例训练 |
| [CDPN](papers/2019_cdpn/README.md) | RGB、已知实例 | 稠密物体坐标与解耦姿态 | 对应图、尺度与裁剪；不是任意新物体零样本 |
| [GDR-Net](papers/2021_gdr_net/README.md) | RGB、已知实例及几何监督 | 几何引导的可学习姿态回归 | 稠密几何与直接回归如何结合；不要混成 GDRNPP |
| [FFB6D](papers/2021_ffb6d/README.md) | RGB-D、已知实例 | 多层双向融合、三维关键点 | 2D/3D 特征通信；依赖有效深度 |
| [CosyPose](papers/2020_cosypose/README.md) | RGB、对象模型、单/多视图 | 单视图候选 + 跨视角关联优化 | 对称性与多视图一致性；不同配置分别评测 |

这条路线适合掌握可解释的中间量。固定 SKU、充足合成/真实训练数据与受控工位中仍值得考虑；新加对象的训练和维护成本需计入方案。

## 2. 新物体泛化：精确区分 CAD 和参考观测

| 方法与解析 | 查询观测 | 新对象准备条件 | 关键限制 |
|---|---|---|---|
| [MegaPose](papers/2022_megapose/README.md) | RGB；支持深度相关配置 | 尺寸正确的对象模型、对象检测 | 无需目标对象重训不代表无 CAD；配置要分清 |
| [GigaPose](papers/2024_gigapose/README.md) | RGB | 对象 CAD/模板；其他分支另看论文 | 模板匹配与剩余自由度估计；分割与 refinement 成本 |
| [SAM-6D](papers/2024_sam6d/README.md) | RGB-D | CAD、模板与预训练模型 | 实例分割与姿态模块分开；PEM 不是完全免训练 |
| [FoundPose](papers/2024_foundpose/README.md) | RGB | CAD 渲染模板和对象区域 | 基础特征+几何；公开仓库不含完整 featuremetric refinement |
| [FreeZe](papers/2024_freeze/README.md) | RGB-D | CAD 与预训练 2D/3D 特征 | 免任务训练依然有模型先验；代码与竞赛扩展版区别 |
| [FoundationPose](papers/2024_foundationpose/README.md) | RGB-D | CAD，或对象参考观测/神经场准备 | 新物体姿态网络不用微调；无 CAD 分支有对象拟合成本 |
| [Gen6D](papers/2022_gen6d/README.md) | RGB | 有位姿的参考图像及尺度/对象定义 | 无 CAD 仍有采集/重建；原训练集不可用需考虑 |
| [OnePose](papers/2022_onepose/README.md) | RGB | 对象扫描视频、SfM 表示 | 新物体不重训；弱纹理和参考覆盖是条件 |
| [OnePose++](papers/2022_onepose_plus_plus/README.md) | RGB | 对象参考视频/重建 | 减少关键点检测依赖；未消除参考准备 |
| [Any6D](papers/2025_any6d/README.md) | RGB-D | 单张同对象 RGB-D anchor，生成形状 | 尺度对齐；多组实验用 GT mask；生成背面误差 |

这里的“新物体”取决于预训练与测试划分，不能只根据方法名字判断是否跨类别；“无 CAD”还可能通过重建或生成得到对象模型。建议在对象数量扩大时测量每个新对象从采集到可推理的总准备时间。

## 3. 类别级位姿与尺寸

| 方法与解析 | 主要输入/先验 | 关键表示 | 学习价值 |
|---|---|---|---|
| [NOCS](papers/2019_nocs/README.md) | RGB-D、已训练类别 | 规范对象坐标与几何对齐 | 类别内新实例的坐标统一、尺度与对称性 |
| [CASS](papers/2020_cass/README.md) | RGB-D、类别形状训练数据 | 规范形状空间 | 形状补全如何辅助姿态 |
| [FS-Net](papers/2021_fs_net/README.md) | 深度点云为姿态核心、类别监督 | 形状特征与解耦旋转 | 几何学习和尺寸；检测前端需单列 |
| [DualPoseNet](papers/2021_dualposenet/README.md) | RGB-D、类别监督 | 双姿态分支、一致性 | 显式回归与隐式约束的协同 |
| [GenPose](papers/2023_genpose/README.md) | 对象点云、类别监督 | 姿态分布与采样 | 多解/不确定性；核心输出 R,t，不直接预测尺寸 |
| [AG-Pose](papers/2024_ag_pose/README.md) | RGB-D、类别监督 | 实例自适应关键点与几何感知特征 | 关键点随形状适应；核对原版与扩展版代码 |

这组重点是“学过的类别中的新实例”。规范轴和对称规则是标注定义的一部分。对杯子、瓶子等类别可有价值；不能直接保证处理任意工业零件或任意新类别。

## 4. 跟踪与重建

| 方法与解析 | 必要准备 | 输出/方法定位 | 人形应用时需要验证 |
|---|---|---|---|
| [ICG](papers/2022_icg/README.md) | CAD、初始位姿、RGB-D | 融合区域与深度的局部跟踪 | 遮挡、初值范围、丢失后恢复 |
| [CAPTRA](papers/2021_captra/README.md) | 已训练类别、初始部件位姿、点云 | 类别刚体/关节部件跟踪 | 初值、mask、部件定义；不是通用全局初始化 |
| [BundleSDF](papers/2023_bundlesdf/README.md) | RGB-D 视频、mask/分割流程 | 无 CAD 跟踪 + 神经对象重建 | 公开代码前端差异、异步优化和总成本 |
| [6DOPE-GS](papers/2025_6dope_gs/README.md) | RGB-D 视频、对象指定和 mask | Gaussian 对象表示 + 姿态图 | 首帧人工条件、完整延迟、代码尚未确认公开 |
| [FoundationPose](papers/2024_foundationpose/README.md) | CAD/参考准备及初始注册 | 全局注册与连续跟踪两种模式 | 注册慢/跟踪快应分开记录，重定位策略另定义 |

## 5. 基准阅读

[BOP](papers/2018_bop/README.md) 用来理解输入权限、对称性和评测协议；[HOT3D](papers/2025_hot3d/README.md) 用来理解第一视角多视角手物交互。HouseCat6D、HO3D、YCBInEOAT 等数据选择见 [数据清单](../dataset.md)。

## 6. 给当前项目的默认选择

如果你有 RGB-D 与 CAD，我建议先用 FoundationPose 建立可检查的离线链路，再按瓶颈选择 ICG（跟踪）或 SAM-6D（初始化前端）作对照。若只有 RGB，先看 MegaPose/FoundPose/GigaPose 的数据和计算条件。无 CAD 时，先确认能否获取参考视频、深度或单张参考，再在 OnePose++、Gen6D、BundleSDF、Any6D 之间选择。

这些建议基于上表条件与公开资料，尚未证实在你的硬件上表现最好。最终选择需补齐：相机类型、CAD/参考采集条件、对象类别与材质、计算资源、任务容差和延迟预算。具体执行顺序见 [复现计划](../复现/README.md)。
