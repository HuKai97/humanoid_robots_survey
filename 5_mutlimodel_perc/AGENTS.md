# 人形机器人多模态感知入门调研

本项目帮助零基础学习者建立人形机器人多模态感知的知识地图、重要文献库和可执行学习路线。当前阶段是调研，不声称完成任何论文复现或实验。

## 每次开始先读

1. 本文件。
2. `handoff.md`。
3. 按需读取 `related_work/README.md` 和相关单篇笔记；开始实验前读 `experiment/evaluation.md`。

## 用户要求与范围

- 调研结果保留在当前工作区，中文讲解，论文先总结再详细介绍。
- 文献主目录使用上游 workflow 的标准名称 `related_work/`。
- 不下载论文 PDF 或 LaTeX 源码，不运行上游 `fetch-paper.sh`。
- 投稿会议、截止时间、机器人硬件及计算资源均未指定，不自行假定。
- 采用 https://github.com/skJack/research-workflow 的职责划分，按用户要求调整文献存储方式。

## 2026-09-29 用户最新范围修订（优先）

- 不做SLAM；不把定位建图作为核心阅读、学习、复现或评价目标。已有SLAM笔记仅保留为非核心归档。
- 主模态：RGB、RGB-D、LiDAR、IMU、关节编码器。重点环境/物体/地形感知、视觉/点云与本体融合。
- 用户追加要求：专门调研与强化学习结合的多模态感知。每篇区分RL、模仿学习、教师学生蒸馏、自监督/监督感知；不能把它们混称RL。
- 区分训练特权信息、部署可得传感器、策略直接输入与预处理得到的估计值。
- 触觉、音频、语言不是此次主线；旧笔记可作为拓展材料，不要挤占核心路线。

## 写作与证据

- 优先核验论文官网、arXiv 摘要/HTML、会议或期刊官方页面、作者代码仓库。
- 每篇标明来源、首次公开年份、阅读证据深度和与人形机器人的关系。
- 区分直接人形验证、可迁移方法、基础支撑；区分感知、策略、控制。
- 定量结论必须有可核对出处与实验条件；未读到的细节记为待核验。
- 作者结论、调研者解读、待验证假设分开写。不能把规划的实验写成已完成结果。
- 标准术语包括多模态融合、点云、RGB-D、鸟瞰图、外部感知、本体感知、部分可观测决策过程、强化学习、非对称演员评论家、教师学生蒸馏、仿真到现实。

## 文件职责

- `related_work/`：总览、学习路线、比较矩阵、单篇中文笔记、检索记录和书目信息。
- `复现/`：拟复现路线与日后的真实复现报告。
- `brainstorm.md`：尚未验证的问题和假设；先复现基线再确定创新主张。
- `experiment/evaluation.md`：实验开始前应冻结的数据划分、指标及对照。
- `experiment/results.md`：实验结果仅追加，失败结果也保留。
- `DataSet/` 与 `dataset.md`：数据资源及处理说明；本轮不下载数据。
- `handoff.md`：本次进度与下一步交接。

保留既有工作。实验使用有语义的版本名，禁止只报告最好结果；检查跨场景、物体、序列划分的数据泄漏。
