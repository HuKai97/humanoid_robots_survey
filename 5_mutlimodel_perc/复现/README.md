# 非SLAM复现起点：先证明外部感知与本体信息互补

当前未下载论文、代码、数据或模型，未安装环境、未训练。下面是可执行的后续设计，不是已完成结果。先读[RL专题](../related_work/08_强化学习与多模态感知.md)。

## 1. 首选：本体＋深度的最小模拟任务

**目标：**在受控障碍或简单操作任务中，对比只用本体与加入深度的策略，解释外部感知是否提供提前决策所需的信息。不要首先尝试完整人形跑酷。

可以选择低台阶通过，或固定基座机械臂到达/抓取一个可见物体。尚未确定机器人和算力，因此这里不硬指定动作维数、相机分辨率或并行环境数。具体模型和环境选定后填写配置。

### 输入与网络

- 深度图→小型CNN；或把深度反投影为点云→点云编码器。初版二选一。
- 关节q/dq、可得的IMU相关量、上一动作和命令→MLP。
- 两组特征拼接→策略。先不加大型Transformer；历史/GRU作为之后独立变化。
- 动作使用选定环境原生接口，例如关节位置目标或末端目标，保持所有对照一致。
- 使用环境已有的PPO实现起步。若采用特权Critic，必须保证Actor不接触同一真值；若采用教师学生，另存每个阶段损失和数据。

这是教学baseline设计，不冒充某篇论文的复现。要复现原论文时应优先使用原作者任务、代码与观测协议。

### 训练和验收

1. 检查传感器：深度单位/无效值、点云坐标、q顺序、IMU坐标、时间戳与观测延迟。保存一组可视化和样本张量。
2. 跑通原环境本体策略；记录训练步数、种子、随机化和控制参数。
3. 加外部编码器，保持奖励、控制器、训练环境步数一致；同时记录GPU时间，因为视觉渲染增加成本。
4. 对未见地形或物体测试；预先确定成功条件、超时和人工介入处理。
5. 注入深度遮挡、延迟和乱序观测，画出性能随扰动强度变化。两种策略都在同一测试分布下运行。

推荐先完成三次独立种子作为学习实验的起点；正式研究是否足够，须看方差与资源，不能用三次运行保证统计充分。推理测试次数也要单独报告。

## 3. 如果暂时不训练RL

做RGB-LiDAR或RGB-D几何对齐、点云分割/检测的小实验，以29–32为方法入口。固定模型权重，测试标定扰动、点云缺失和RGB遮挡，观察检测性能和融合特征。可以先用现成小样本或自建合成数据，但合成练习不叫完整论文复现。

车载KITTI/nuScenes可学习融合方法，却不包含你需要的人形关节/IMU闭环数据。不能把这些数据上的检测分数直接当人形效果。
