# 13｜OpenMask3D：检索具体三维物体实例

## 先读总结

OpenMask3D 把开放词汇三维感知推进到实例层面：不仅标出哪些点像“椅子”，还区分场景中的一把把椅子。系统先生成不带固定类别的三维实例掩码，再为每个实例挑选清晰视角、细化图像区域、提取 CLIP 特征并融合；文字查询与实例特征匹配后，返回具体对象。它为“抓取哪一个物体”提供比逐点热图更清楚的接口。要注意，零样本主要涉及语义特征和新概念查询，三维掩码模块本身使用了预训练分割模型；这不是一个完全没有训练数据的系统。[摘要](https://arxiv.org/abs/2306.13631)

## 元信息与证据边界

- 标题：OpenMask3D: Open-Vocabulary 3D Instance Segmentation。
- 作者：Ayça Takmaz、Elisabetta Fedele、Robert W. Sumner、Marc Pollefeys、Federico Tombari、Francis Engelmann。
- 首次公开年份：2023；会议：NeurIPS 2023，摘要和项目页均已核验。
- 类别：三维开放词汇实例分割；人形关联：**可迁移方法**；优先级：P1。
- 证据深度：摘要、项目页、官方仓库，重点阅读论文 HTML 第 3 节方法、第 4 节实验与局限；未逐项精读附录。核验日期：2026-09-29，未下载或复现。

## 为什么纳入这条阅读线

本篇补齐“图像语义 → 三维点 → 三维实例 → 对象关系图”的层次，推荐实际阅读时放在 ConceptGraphs 前。它属于感知工作；动作扩散策略更适合放入感知如何支撑操作的后续路线，不用来代替实例感知基础。

## 问题、输入输出与融合层级

输入是带位姿 RGB-D 图像、相机参数及重建点云；输出是三维对象掩码和对应语义特征，供开放词汇查询。不同视角的图像特征在**实例级**融合，文本再与实例表示对齐。几何负责回答“哪些点属于对象”，视觉语言特征负责提供“对象可能是什么”的语义。[论文 HTML 方法节](https://arxiv.org/html/2306.13631v2#S3)

## 方法怎么理解

1. 利用预训练三维分割模块产生实例掩码，保留形状分组而舍弃原有固定类别预测。
2. 对每个实例选择可见性较好的视角，减少遮挡图像对表示的污染。
3. 用投影点引导 SAM 细化二维掩码，再对不同尺度的物体裁剪提取 CLIP 特征。
4. 跨裁剪、跨视角聚合特征，并与查询编码比较。[论文 HTML](https://arxiv.org/html/2306.13631v2)

**调研者解释：**将所有点的特征直接平均到一个物体上，可能混入背景与相邻物体；先找到对象、再选择好视角，是另一种组织信息的方式。但如果第一步漏掉一个杯子，再强的语言模型也无法从不存在的掩码中找回它。因而实例召回与语义识别应分别分析。

## 实验支持什么，不支持什么

作者在 ScanNet200 和 Replica 上验证实例分割与迁移，并展示属性、材料、用途等自由查询。定量评估主要仍借助既有标签集合，不能等价于穷尽任意自然语言查询。[项目页](https://openmask3d.github.io/)

论文还用真实标注掩码分析了掩码质量的影响，并将其列为瓶颈；这属于诊断条件，不是可部署系统自动得到的输入。作者指出图像特征只看到局部视野，无法自然获得全场景关系。本轮保留这些有直接出处的边界，不摘录跨条件的最优数值。[论文实验与局限](https://arxiv.org/html/2306.13631v2#S4)

## 局限与人形机器人中的位置

**调研者解读：**实例掩码提供目标边界，却不提供抓取姿态、关节角或力控制。多把外观相同的椅子仍需空间关系来消歧；小物体、被遮挡的细长工具、透明表面的几何问题也应单独检验。“可坐”或“可洗”等语义匹配不是承重、可达性和水密性的测量。

对人形机器人，实例级地图可作为“找到目标后递给操作模块”的接口；机器人动作造成物体移动后，需要更新对象位置或重新观测。本文没有直接人形闭环验证，也不应把静态扫描评估称为在线全身机器人系统。

## 初学先修、小练习与阅读问题

先修：CLIP、二维与三维实例分割、相机投影、遮挡判定、AP 与 IoU 的差别。

**未执行的小练习：**画两个相邻杯子的三维点集：先故意合并成一个掩码，再假设每个杯子的语义特征都完全正确，观察最终是否仍能正确选择一个杯子。另为同一对象挑选正面、背面和遮挡视角，说明哪些适合提取特征。未来基线应分别报告掩码质量和文本检索质量，保留失败场景。

阅读问题：三维掩码训练时见过什么？为何需要 SAM？多尺度裁剪增加了上下文还是噪声？闭集标签上的 AP 如何补充开放查询测试？如果把对象特征送进 ConceptGraphs，哪些信息还缺失？
