# 27｜VisualMimic：把第一人称深度连接到全身操作

## 先读总结

VisualMimic把人形视觉操作分成两层：底层跟踪身体关键点，上层根据第一人称深度和本体状态生成关键点目标。两层都借助教师—学生思想，让训练中可用的状态信息逐步变成现实可部署的观测。它在Unitree G1上展示推、踢、抬等全身交互，提供直接的人形视觉—本体融合案例。相比仅看语言模型，它更清楚地暴露了视觉噪声、相机偏移和动作可行性的耦合问题。需要注意，论文的视觉输入是深度，任务策略也不是自动理解任意自然语言的通用模型。[1][2]

## 方法与数据流

**作者工作。** 底层从人体运动学习通用关键点跟踪；上层先使用特权物体状态训练任务策略，再蒸馏为读取深度和本体的视觉策略。深度经CNN编码，与本体特征结合后生成关键点目标。为降低上下层不匹配，作者在底层训练加入目标噪声，并约束上层输出范围；深度随机遮挡与相机角度扰动帮助迁移。[2]

可用一条链理解：`深度+本体 → 高层关键点目标 → 低层跟踪 → 关节动作`。高层并不直接控制全部电机，低层也不独立决定物体任务。融合主要服务动作选择，没有单独输出完整语义场景图。

**调研者解读。** 中间关键点是一个任务与动力学之间的接口。若视觉准确，但输出目标超出低层能力，任务仍会失败；所以感知误差与接口可行性需要分别诊断。目标限制提升可执行性，也可能限制任务动作范围，这需要在具体任务中权衡。

## 证据与局限

论文有仿真中带/不带视觉的比较、设计消融与实机任务，项目页明确区分仿真、真实和sim-to-sim展示。[2][3] 这些支持视觉在所测物体交互中发挥作用，也支持整套分层训练的迁移可行性；不能把所有页面视频均当成真实任务成功率。

**局限。** 策略仍依赖任务奖励与低层运动分布，不等于一条任意目标指令即可组合所有技能。深度能降低部分外观变化影响，但透明反光物体、远距离缺测及相机漂移依然值得检验。原文使用的深度滤波与掩码训练说明传感器管线属于方法的一部分，复现时不能只复制网络结构。

**代码公开范围（2026-09-29核验）。** 官方仓库目前明确发布Sim2Sim流程与检查点，并说明完整代码将在论文录用后公开。因此本库将其记为“部分开源”；完整训练及实机部署代码未确认，不能仅凭仓库链接就认为可以端到端复现。[4]

## 初学者学习任务

先修：深度图、卷积网络、机器人正运动学、关键点跟踪、分层策略、模仿蒸馏。建议与HumanPlus对照：前者依靠现实示教学习任务，VisualMimic更强调仿真任务学习及视觉迁移；不同数据来源不应直接按成功率排名。

**小练习，未复现：** 选择抬箱任务，画出物体可见性、双手接触、躯干姿态、重心变化四条时间线。判断视觉暂时被手遮住时，本体历史能补充什么，不能补充什么。拟设计单帧与多帧深度对照，并同时检查目标关键点误差及实际物体位移，避免把控制器误差归给感知模型。

**待验证假设：** 给高层加入针对接触阶段的时间记忆可能改善自身遮挡，但也可能引入过时观测；应比较历史错位、清空记忆与正常输入，验证收益来自有效信息而非更多参数。

## 当前传感器与RL范围补注

- **训练范式：**低层RL跟踪/蒸馏＋高层特权RL＋视觉学生蒸馏。
- **RL作用：**RL得到动作跟踪器和基于物体状态的任务教师；最终深度高层主要用教师监督。
- **训练观测：**低层人体动作目标；高层教师真实物体状态与本体，视觉学生读深度与本体。
- **部署观测：**预处理第一人称深度、IMU相关姿态/角速度与关节状态等本体；不需要外部物体真值。
- **本轮定位：**核心直接人形视觉—本体全身操作，但不是纯单阶段像素RL。
