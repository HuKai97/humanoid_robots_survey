# 术语表：传感器融合与强化学习

以下是教学释义。具体论文采用哪些量，必须以其训练和部署配置为准。

| 术语 | 通俗解释 | 容易混淆的地方 |
|---|---|---|
| Proprioception，本体感知 | 关于机器人自身身体的观测 | 不等于所有状态都可实测 |
| Exteroception，外部感知 | 关于环境和对象的观测 | 不只包含RGB，也含深度/雷达 |
| RGB-D | 配对的颜色和深度 | 只使用深度的网络不能说融合了RGB |
| Point cloud，点云 | 一组三维点及可选属性 | RGB-D生成的点云不等于LiDAR实测 |
| BEV，鸟瞰表征 | 在地面平面上组织空间特征 | 不一定是普通彩色俯视图；预测深度≠深度相机输入 |
| Elevation map，高程图 | 为平面位置记录地形高度的表示 | 2.5D表示难保留所有悬空/多层几何 |
| Back-projection，反投影 | 用深度和内参把像素变成三维点 | 需要注意米/毫米和无效深度 |
| Intrinsic / extrinsic | 相机内参／传感器之间的空间变换 | 外参变化会破坏跨模态对应 |
| IMU | 测角速度和比力的惯性单元 | 不直接输出可靠全局位置 |
| Projected gravity，投影重力 | 将重力方向表示到机体坐标系 | 通常来自姿态处理，不等于原始加速度计读数 |
| q / dq | 关节角／关节速度 | 速度来源可能是驱动器或差分估计 |
| Forward kinematics，正运动学 | 从关节配置计算连杆或末端几何 | 末端估计与实际接触结果不同 |
| Early / feature / late fusion | 输入级／特征级／决策级融合 | 名称不统一时看实际数据流 |
| Cross-attention，交叉注意力 | 用一种表征查询另一种信息 | 注意力权重不是模态因果贡献证明 |
| Temporal alignment，时间对齐 | 匹配测量发生时刻 | 同帧率不意味着同步 |
| MDP | 状态—动作—转移—奖励的决策模型 | 机器人通常只得到不完整观测 |
| POMDP | 状态部分可观测的决策过程 | 历史信息有用，不代表记忆一定越长越好 |
| Policy / Actor，策略 | 根据观测产生动作的模型 | 不等于单独的感知编码器 |
| Critic，价值函数模型 | 估计长期收益，帮助训练策略 | 通常不必随Actor部署 |
| PPO | 一类近端策略优化算法 | 不规定怎样融合相机和本体 |
| Reward / return | 单步奖励／累计回报 | 奖励变了，回报绝对值常不可直接比较 |
| Privileged information | 训练时可得、部署时不可得的额外状态 | 必须标明进Actor、Critic、奖励还是标签 |
| Asymmetric Actor-Critic | Actor与Critic使用不同信息 | 不等于单独训练教师后蒸馏 |
| Dual critic，双评论家 | 使用两个价值评估模型 | 不自动意味着非对称观测输入 |
| Teacher–student，教师学生 | 一个模型指导另一个模型 | 学生可以用监督损失而非RL |
| Behavior cloning，行为克隆 | 学习示范的观测到动作映射 | 示范来自RL，不使BC本身成为RL |
| DAgger | 迭代收集学生所访状态上的专家监督 | 核心是模仿学习，不凭迭代就叫RL |
| Diffusion policy，扩散策略 | 用去噪生成等方式建模动作分布 | “扩散”是模型形式，不等于RL训练 |
| Domain randomization | 训练时改变外观、物理或传感器参数 | 随机化范围需与部署问题相关 |
| Curriculum，课程学习 | 随训练逐步改变任务难度等条件 | 课程收益应与融合结构收益分开 |
| Sim-to-real | 从仿真迁移到真实机器人 | 仿真成功不能直接称为真实人形验证 |
| Ablation，消融 | 有控制地移除或改变一个因素 | 重新训练与部署时拔掉模态是两类问题 |
| Oracle，上界参考 | 使用更理想信息的诊断对照 | 不属于真实可部署输入 |
| AP / IoU | 检测平均精度／区域交并比 | 与RL回报或任务成功率不是同类量 |

基础入口：[Modern Robotics](https://modernrobotics.northwestern.edu/nu-gm-book-resource/)、[CS285](https://rail.eecs.berkeley.edu/deeprlcourse/)、[PPO原论文](https://arxiv.org/abs/1707.06347)、[非对称Actor-Critic原论文](https://arxiv.org/abs/1710.06542)。本次不要求学习SLAM算法。
