# 检索、证据与workflow适配

## 当前范围

2026-09-29用户明确：不做SLAM，主要看RGB、RGB-D、LiDAR、IMU、关节编码器，并进一步要求调研与RL结合。此范围优先于初版广泛的感知分类。三篇SLAM/里程计移入归档，触觉/音频/语言材料保留为非核心拓展。

不是寻找“同时接满所有传感器”的单一大网络，而是追踪外部信息与本体信息如何互补，感知学习和RL优化各承担什么职责。

## 检索与选文

以可串联学习的代表工作为目标，不按引用量排序，不声称最新全面覆盖或PRISMA式系统综述。核心纳入点云编码、RGB-LiDAR监督融合、感知运动RL、点云本体操作RL，以及必要的单模态/IL对照。

本次新增分支：[RGB-D桥接](search_rgbd.md)、[传感器融合](search_sensorfusion.md)、[感知运动RL](search_perceptive_rl.md)、[操作RL](search_manipulation_rl.md)。早期日志[基础定位](search_foundations.md)、[三维语义](search_semantic.md)、[触觉表征](search_tactile.md)、[人形系统](search_humanoid.md)保留追溯，但旧日志中的选文优先级不代表当前主线。

选择33时核正了候选题名与年份；34和35是两篇不同跑酷工作；32固定为MIT团队的BEVFusion，不与同名工作混用。37/38与39分别展示RL教师蒸馏和直接点云RL，40作为纯IL对照。BeamDojo保留上游定位/高程依赖说明，但本课题不研究该上游算法。

## 来源与证据处理

优先论文arXiv摘要/HTML、官方会议、作者项目和仓库。项目展示不构成独立复现，原文与同篇HTML也不是两份独立实验证据。全文HTML定向阅读不等于逐式推导、逐表审计；各笔记明示范围。

代码只记实际确认的范围：PointPainting未确认原作者完整官方实现，TransFusion仓库对权重有明确限制，VisualMimic只确认部分流程，BeamDojo本轮未确认完整代码。不能把第三方fork叫官方，不能把未确认叫确定未开源。

新增元数据包括learning_paradigm、rl_role、train_observations、deploy_observations。统一分类以[papers.json](papers.json)的scope为准，各metadata文件是分支来源记录。34部分部署接触信息来源未完全核验，保留不确定性，不假设只用用户列出的观测。

交叉核验关注：是否误称直接人形实验、是否把IL/蒸馏当RL、传感器与处理后观测是否混用、是否把代码入口当完整复现。最终检查结果见[validation.md](validation.md)。

## 与research-workflow对应

已阅读用户指定的[SKILL.md](https://github.com/skJack/research-workflow/blob/main/SKILL.md)、[init-project.sh](https://github.com/skJack/research-workflow/blob/main/scripts/init-project.sh)与六个模板。按其职责创建文件，没有全局安装技能或执行远程脚本。

| workflow职责 | 本项目落实 |
|---|---|
| AGENTS.md | 最新非SLAM范围、传感器与RL证据规则 |
| handoff.md | 本轮结果、未完成实验和下一步 |
| related_work/ | 每篇先总结后详解、原文链接与训练部署信息 |
| 复现/ | 有明确观测和对照的待执行方案 |
| brainstorm.md | 先复现再验证的研究问题，未宣称创新 |
| experiment/evaluation.md | 感知/RL指标、特权信息与公平预算设计 |
| experiment/results.md | 空结果表，只追加以后真实实验 |
| DataSet/、dataset.md | 数据/仿真候选，尚未下载 |

用户明确不下载论文，因此没有执行fetch-paper.sh，省略paper.pdf和LaTeX source/。项目名和入门目标由请求确定；投稿、deadline、硬件和算力未设定，不虚构这些信息，也不因此阻断调研。

以后新增论文，先核验原始来源再填笔记与元数据；选定实验后锁定代码、数据、观测、奖励和预算。不能直接把不同平台的成功率拼成排行。
