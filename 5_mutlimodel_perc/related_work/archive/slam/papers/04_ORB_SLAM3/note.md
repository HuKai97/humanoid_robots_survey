# 04｜ORB-SLAM3

> 范围修订：用户明确不做SLAM。本篇仅保留为初版材料归档，不纳入当前核心阅读、复现或评价。
## 先读总结

ORB-SLAM3 是一个完整的视觉／视觉惯性 SLAM 系统，支持多种相机配置和多地图管理。它帮助初学者把“逐帧估计运动”与“长期维护一致地图”区分开：跟踪、局部优化、回环和地图合并是不同职责。用于人形机器人时，它可以承担几何定位基础，但不是开放词汇理解系统，也没有直接解决足地接触。学习重点是理解不同传感器配置的约束和评测条件，而不是只记住论文中的一个精度数字。[S1][S2]

## 论文信息与证据

- 全名：ORB-SLAM3: An Accurate Open-Source Library for Visual, Visual-Inertial and Multi-Map SLAM。
- 作者：Carlos Campos 等；首次公开：2020；期刊版本：IEEE T-RO 2021。
- 输入配置：单目、双目、RGB-D；支持视觉惯性配置。**并非所有运行配置同时使用所有模态。**
- 输出：相机／机体位姿与地图；人形关系：**可迁移方法**；优先级 P1。
- 本轮证据：arXiv 摘要、版本信息及作者仓库 README；没有逐节精读证明与实验表。

## 详细介绍

### 1. SLAM 比里程计多了什么

里程计关注连续运动估计。SLAM 还要长期维护地图，并在认出旧地点时修正累计误差。人形机器人离开房间再回来，或者短时被手臂遮挡后恢复观察，就涉及重定位和地图关联。

这里“多地图”不是多种语义标签，而是能够管理不同阶段建立的局部地图，并在条件合适时关联它们。

### 2. 核心设计

论文使用特征观测和最大后验估计组织视觉惯性约束，包含惯性初始化与多地图机制。[S1] 官方仓库给出 EuRoC 与 TUM-VI 等配置示例，实际运行必须选对传感器模式、相机模型及标定文件。[S2]

教学性流程可写成：提取并匹配图像特征 → 估计当前位姿 → 更新局部地图与关键帧 → 检查回环／重定位 → 必要时优化地图。使用 IMU 时，运动约束进入相关估计过程；选择纯视觉模式时，不能将结果叫作视觉惯性融合。

### 3. 证据如何阅读

论文摘要给出的精度来自特定数据、配置和评测条件。[S1] 初学者应记录序列、单目还是双目、是否有 IMU、是否启用回环、怎样做轨迹对齐。两个方法都叫“厘米级”不代表它们在同一个任务上可以直接比较。

本笔记不复述跨数据集平均精度排名，也不声称在当前机器上达到论文速度。代码公开只是可复现性的一个必要条件。

### 4. 人形迁移的关键困难

快速转头会改变视野，行走可能产生运动模糊，自身手臂和周围行人带来动态遮挡；相机与躯干 IMU 的相对运动也必须建模。几何跟踪是否稳定，要通过真实传感器布置来判断。

稀疏 SLAM 地图不等于可直接用于脚步规划的完整地形模型。知道相机在哪里，也不等于知道每块地面能否承重。后续需要接触、稠密几何或语义模块提供额外信息。

## 初学者怎么学

先学特征点、重投影误差、关键帧和束调整，再读系统架构。可与 03 比较“滑动窗口里程计”和“完整 SLAM 系统”的侧重点。

**小练习（尚未执行）：**在同一公开序列上比较官方支持的纯视觉与视觉惯性模式，记录轨迹误差、丢失次数、初始化时间及计算耗时；不要让两组使用不同帧率。若尚未搭好环境，先列出各模式的输入文件与标定需求。

阅读问题：视觉丢失之后，系统创建新地图还是重定位？回环前后的误差如何分别报告？稀疏地图为何不直接等同于障碍物地图？
