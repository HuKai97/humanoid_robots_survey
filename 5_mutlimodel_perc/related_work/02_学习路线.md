# 非SLAM学习路线：传感器融合 → 感知与强化学习

按每周8–12小时作参考；时间取决于编程、数学和深度学习基础。若这三项也从零开始，先增加基础周。无需先拥有真实人形机器人；本轮只给学习与复现设计，没有安装训练环境。

## 今天先做的三件事

1. 读[领域地图](01_领域地图.md)，能解释外部感知与本体感知。
2. 读[22 野外感知运动](papers/22_Perceptive_Locomotion_Wild/note.md)和[27 VisualMimic](papers/27_VisualMimic/note.md)的总结，标出图像/地形、本体、奖励、动作在哪里。
3. 读[RL专题](08_强化学习与多模态感知.md)的训练范式表，为每个输入写上“传感器实测／处理得到／训练真值”。

今天不必推导SLAM、复现全身控制或训练大模型。完成标准是能画出一个传感器到动作的流程，并标明训练与部署不同之处。

## 10周学习与产物

| 阶段 | 学什么 | 必须留下的产物 |
|---|---|---|
| 第1周 | Python/NumPy、张量与坐标、相机内参、关节q/dq | 一张传感器数据表；深度反投影示例 |
| 第2周 | CNN、点云编码、PointNet++；训练验证划分 | 能解释批量、点数、通道和池化；一个小网络训练记录 |
| 第3周 | PointPainting/TransFusion，按需BEVFusion | 融合位置对照图；坐标与遮挡误差分析 |
| 第4周 | MDP/POMDP、回报、Actor/Critic、PPO基础 | 小任务训练曲线；区分奖励与监督标签 |
| 第5周 | RMA、22、33，训练/部署观测对照 | 逐个输入标来源；画出RL/蒸馏损失流向 |
| 第6周 | 选定最小模拟任务，先本体baseline | 固定配置、种子、任务成功判据和完整运行日志 |
| 第7周 | 加深度或点云，与本体拼接 | 同预算baseline和融合策略；确认未泄漏真值 |
| 第8周 | 缺失、时延、遮挡或错误配对 | 固定扰动强度的性能曲线和失败视频/样例 |
| 第9周 | 36及26/27；操作路线读37–39 | 实机传感器与仿真观测差异清单 |
| 第10周 | 一次复现总结及小型问题研究 | 3–5页报告：方法、对照、失败、证据、下一步 |

第6–8周可按资源延长。先做低维RL任务熟悉工具是学习练习，不称人形复现。没有GPU时先完成点云几何、小规模监督实验和RL概念练习，视觉并行RL训练留待资源明确后。

## 如何选主线

- **想做人形行走/全身感知：** 深度或LiDAR地形 + IMU处理量 + 关节q/dq。以22、33、36、27为主，先固定任务与控制接口。
- **想做感知算法而不重训全身策略：** RGB+点云检测/几何表征，或对固定策略的感知扰动与适配。以41、29–32为主，之后测试任务相关性。
- **想做人形手臂操作感知：** 点云/深度 + 上肢关节状态。以39→37→38→26为主；先在固定机械臂学方法，再讨论人形迁移。

这些是根据方法依赖和学习成本提出的路线，不是平台购买建议。初期不要求RGB、RGB-D、LiDAR、IMU、编码器五者同时上阵；先证明一组外部感知和本体信息存在互补。
