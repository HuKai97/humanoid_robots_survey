# 从这里开始：指定传感器融合与强化学习

**本调研已按你的修订排除SLAM主线。** 聚焦RGB／RGB-D／LiDAR的环境与物体信息，以及IMU／关节编码器提供或推导的本体信息。特别分析感知怎样进入RL策略、如何融合、训练与部署各能看到什么。

## 先回答“有没有与强化学习结合”

有，而且路径不止一种：LocoTransformer、DexPoint是直接感知RL的代表；22野外感知运动、TRANSIC、RialTo等包含RL教师再训练感知学生的流程；BeamDojo提供LiDAR高程与本体用于人形RL的实例。DP3保留为纯模仿学习对照。具体机制和原始证据见[08 强化学习专题](08_强化学习与多模态感知.md)及[论文索引](03_论文索引.md)。

- **17篇核心/必要基线：**21、22、26–39、41。包括点云基础、RGB-LiDAR融合、视觉/地形与本体的RL、点云操作。PointNet++是单点云基础，RMA是本体对照，不能说两者都已融合全部传感器。

这些条目不都在人形上验证，也不都用RL。索引逐篇给出平台和学习范式；直接人形的26–28、36也分别覆盖操作、全身交互或运动，不能互相替代证据。

## 每篇笔记包含什么

`papers/<编号_短名>/note.md`先给中文总结，再解释问题、输入输出、融合结构、训练范式、实验支持范围、局限与小练习，并保留原始链接。核心新增论文和21–28补注明确区分训练特权信息、部署传感器、处理后状态、RL/模仿/蒸馏。

部分材料只读了摘要与官方说明；部分定向读了全文HTML的方法、实验与附录，阅读深度逐篇记录。未核对的数值不编写；未运行的练习不当作结果；有仓库不意味着完整训练、权重和实机流程都公开。

书目见[papers.json](papers.json)和[references.bib](references.bib)。后者是最小导入格式，正式投稿前需补完整官方信息。新增笔记可使用[模板](templates/paper_note_template.md)。

检索截至2026-09-29，涵盖经典与近期代表，不是穷尽综述。没有下载论文PDF、源码、数据或模型，也没有运行实验。结构与交叉检查记录见[validation.md](validation.md)。
