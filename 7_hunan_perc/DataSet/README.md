# DataSet：数据登记与实验入口

本目录按research-workflow保留为数据资源入口。**当前没有下载或保存数据集、论文、模型权重。** 选型、官方来源与模态边界见[根目录dataset.md](../dataset.md)。

建议顺序：先完成一个融合/几何最小实验，再决定是否下载完整数据。公开汽车数据只作为接口与基线练习，人形动态、自遮挡和近场支撑问题需要额外验证。

## 后续目录约定（仅设计，尚未创建）

```text
DataSet/
  README.md
  registry/                 # 数据版本、来源、许可核查、校验和、存储位置
  manifests/                # scene/session、时间戳、相机/IMU/点云字段
  splits/                   # 固定训练/验证/测试场景清单
  calibration/              # 内外参、时差、坐标方向、传感器与关节链版本
  derived/                  # 可再生成的预处理；关联原始数据与脚本版本
  reports/                  # 缺失率、同步、误差分桶和数据年龄审计
```

大体积原始数据可存外部数据盘，本目录登记绝对路径或挂载约定，避免拷入Git。原始文件保持只读；滤波、对齐、补洞、抽帧的输出必须保留来源与处理参数。

## 每套数据最少登记

| 项目 | 必须记录 |
|---|---|
| 来源 | 官方URL、版本、获取日期、具体子集；本次均为未获取 |
| 权利 | 数据条款与代码许可分别记录；下载前再核实 |
| 模态 | 真正可读取的字段；IMU是否完整、时间是否可靠，不只看宣传传感器清单 |
| 几何 | 单位、光学/机体坐标、深度Z或射线距离、内外参、动态关节关系 |
| 标签 | 原始测量或推断补全；类别映射；无效/未知值；真值来源 |
| 划分 | 官方划分，或自采按物理场景与session隔离；不随机拆相邻帧 |
| 验收 | 解析样本、时间戳连续性、有效率和校验和；不以能打开文件代替数据审计 |

自采建议与schema已经写在[dataset.md](../dataset.md)。第一轮应以离线感知验证为目标，记录脚边台阶、悬空障碍和摆臂遮挡；本次未进行采集、标注或训练。
