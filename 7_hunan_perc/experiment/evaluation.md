# 感知测评协议 v0（草案，尚未执行）

本轮只完成调研。以下是后续复现前应固定的协议；数据集、硬件、阈值尚未确定，不得把它当成已冻结的生产验收标准。首次实验前填写具体配置并保存版本，之后不要看结果再挑指标。

## 1. 数据与划分

公开数据使用对应官方划分；自采按物理场景、采集session隔离，不能随机拆相邻帧。同一台阶或房间的多次扫描先归组再划分。分布外测试另列新场景、材质、相机安装角、运动幅度。只使用给定或独立测量的短时位姿，不开发SLAM。

记录输入数据版本、传感器型号与模式、标定版本、坐标系、单位、时间戳语义、有效深度掩码、预处理和真值来源。固定失败案例清单，新增案例另记版本。

## 2. 必报指标（按任务选择并事先固定）

| 模块 | 主指标 | 必要辅助量与分母 |
|---|---|---|
| 对齐与标定 | 独立序列重投影/边缘对齐误差；跨次外参和时差稳定性 | 单位、运动激励、时间抖动、距离与角速度分桶；小残差不是绝对真值 |
| 度量深度 | 有效区域MAE/RMSE、AbsRel | 有效率、深度范围、尺度对齐是否使用；预测深度与传感器原始深度分开 |
| 相对深度 | 明确尺度/偏移对齐的误差或次序指标 | 不和未对齐的公制深度直接排名；真值有缺失时说明掩码 |
| 3D语义/检测 | 官方mIoU/mAP及其协议 | 薄杆、台阶边缘、小目标、未知类召回；报告类别与数量 |
| 地形 | 高度MAE、台阶边缘偏移、支撑区域precision/recall | 当前可见/历史可见/从未可见三类分开；不可支撑误判为支撑的比率 |
| 身体障碍 | 头/躯干/手臂相关障碍漏检率 | 障碍尺寸与距离阈值先定义；几何可通行与接触可承重分开 |
| 时序 | 输出抖动、遮挡后恢复时间、动态残留持续时间 | 不能为降低抖动引入未报告的延迟 |
| 系统 | 从采集到发布的数据年龄p50/p95、吞吐、显存与丢帧率 | 设备、功耗/模式、预热、输入尺寸和队列策略；不能只报网络前向FPS |

支撑判定需先定义脚掌几何、边缘余量、坡度与碰撞规则；仅凭几何不证明摩擦和承载。若没有这些条件，任务名称写“几何候选支撑区域”。标注误差应纳入结果解释。

## 3. 必备对照

相机/深度单模态、LiDAR单模态、简单投影融合、待研究融合；若某任务没有对应模态，只选有意义的基线。使用一致场景、有效范围和计算预算。训练模型对比尽量匹配容量与训练数据。

在保持模型不变的条件下分别注入：常数时间偏移、外参小角度/平移扰动、深度孔洞、点云稀疏、相机遮挡和缺帧。扰动范围根据实际日志确定，不把任意数值宣称为硬件标准。避免一次同时改变多个因素而无法归因。

可用真值姿态或真值深度做诊断上界，但必须标作oracle且部署不可用。随机/打乱模态可测试模型是否真正使用新增传感信息，不能拿它代替正常工程基线。

## 4. 汇报和可视化

报告整体与分桶统计，包括距离、角速度、运动阶段、光照、材质和障碍类别；同时报告样本数。神经网络有随机性时记录种子，按资源计划重复并报告离散度。没有做重复时明确说明，不捏造误差条。

固定输出：投影叠加、深度有效性与误差、局部几何和悬空障碍、当前/历史/推断来源、延迟分布、至少一组固定失败样例。论文数值单独列“原文”，本地数值列“实测”，不可混排。

每次写入 `experiment/<语义版本名>/`，含配置、代码commit、环境、数据split、metrics.json、失败清单和可视化。版本名示例 `geom_baseline`、`fusion_timeoffset`、`terrain_memory_ablation`，不要用 `final_v2`。
