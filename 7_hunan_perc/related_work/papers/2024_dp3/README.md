# 3D Diffusion Policy: Generalizable Visuomotor Policy Learning via Simple 3D Representations

- 首次公开：2024；简称：DP3。作者：Yanjie Ze 等。
- 优先级：P2；定位：扩展阅读，理解深度/点云如何进入操作策略。
- 具身：机械臂及灵巧手等操作系统；非人形专用，非行走感知。
- 核查日期：2026-09-29；状态：调研完成，实验未执行。

## 先读总结

DP3把单视角深度转成稀疏点云，以轻量编码器提取几何特征，再与机器人状态一起作为动作扩散模型的条件。对传统感知工程师，它是连接“可校准的三维测量”与“学习动作分布”的清晰案例：不必先得到完整物体类别和姿态，也可以让几何表征为操作服务。本文适合作为扩展学习，主要证据来自操作任务，不能当作人形全身感知或LiDAR融合系统。重点应放在反投影、坐标系、点云裁剪与采样，而不是只关注扩散网络名称。[论文](https://arxiv.org/abs/2403.03954)｜[项目](https://3d-diffusion-policy.github.io/)

## 研究问题与输入输出

问题是如何在有限演示下学习具有空间泛化能力的操作策略。输入为单视角点云与机器人状态，输出为连续动作序列。论文的主要几何输入不使用颜色，因此不能把DP3描述为RGB、深度、LiDAR三模态融合；单视角点云也不是完整场景模型。[方法第III节](https://arxiv.org/html/2403.03954v4#S3)

## 方法机制：感知前端是重点

作者将深度按内外参反投影，裁剪工作区并下采样，以简单逐点MLP、池化和投影形成紧凑特征。动作网络再以几何特征和机器人状态为条件生成一段动作。演示数据训练感知与动作模块，动作生成属于条件去噪过程。[论文方法](https://arxiv.org/html/2403.03954v4#S3)

机制解释：二维像素距离同时受到深度、焦距与视角影响，而三维坐标把测量放到具有公制意义的空间中。几何编码并不自动带来旋转不变性；相同物体在不同坐标系下仍会形成不同数值。尤其相机安装在人形头部后，必须明确使用相机坐标、机体坐标还是机器人基座坐标，以及外参是否随关节变化。

稀疏化的工程含义是计算量与局部细节之间的取舍：桌面大物体可以保留少量点，但细杆、薄边缘和近接触区域可能在采样后消失。采样方法不会凭空恢复不可见表面。学习者应看每一步处理后还剩什么信息，而不仅看最终动作成功率。

## 训练监督与复现入口

训练来源是成功的专家演示，目标不是语义分割标签，而是条件动作学习。官方仓库提供不同仿真任务和点云处理路径，也区分原始DP3与后续简化配置；它们的速度与训练设置不能直接混用。[官方实现](https://github.com/YanjieZe/3D-Diffusion-Policy)

阅读时可以先画出一个batch中点云、机器人状态、动作窗口的形状，确认归一化和时间偏移。例如使用当前图像预测未来动作时，图像的采集延迟会改变真实条件；这不是增加模型参数就能消除的问题。

## 实验证据与边界

论文在多个仿真操作域与真实操作任务中比较了三维表征、不同编码器及二维基线；作者项目展示空间、视角、外观等变化下的行为。[作者实验展示](https://3d-diffusion-policy.github.io/) 这些结果支持其具体任务设置中的三维条件化价值，不支持“点云总优于RGB”的普遍结论。颜色区分、文字指令、材质判断或透明物体可能要求额外信息。

感知侧还需要考虑训练工作区裁剪是否隐含任务先验、测试时相机是否完成重新标定、相机噪声如何传播到手边位置误差。原文观察到的较稳健动作也不能替代对碰撞风险的专门测量。

## 对人形感知的启发（推断）

可以把DP3作为人形操作分支的几何基线：胸部或腕部深度产生局部点云，与关节状态一起形成下游条件。先做固定躯干、单手任务，再考察躯干运动导致的坐标变化。把操作实验与行走实验分开，有助于找到误差究竟来自视觉、时序还是身体运动。

如果已有LiDAR，需先判断近场点密度、盲区、扫描时间和相机点云是否匹配；两者同为XYZ，并不代表可以无条件替换。建议在接口中保留观测来源、时间戳和可见性，避免把缺失区域误当成真实空闲区域。这是扩展设计，不是DP3原文实现。

## 轮式背景需要补什么

已有投影、标定和点云处理基础可直接复用。新内容包括演示数据组织、动作chunk、条件扩散和闭环执行频率。无需先学完整大语言模型；理解“观测作为条件，输出是多个可能动作的分布”即可进入论文。

## 最小学习实验（设计，未执行）

1. 选一个简单仿真机械臂到达任务，记录深度、内外参、末端状态与演示动作。先离线验证深度反投影后的位置误差。
2. 在相同数据划分下对比深度CNN、XYZ点云编码与RGB编码，使用同一个简单监督动作头，先隔离感知表征贡献。
3. 分别改变目标空间位置、相机视角、背景纹理；保持物体几何不变的外观测试，与改变物体形状的几何测试分开。
4. 扫描点数、外参扰动和深度孔洞强度，输出动作误差及目标定位误差。再选择一个配置接入扩散动作头。

验收应包含固定测试集、运行延迟和失败点云可视化。这个最小实验不声称达到论文操作成功率，也不等同人形迁移验证。

## 自测

1. 从深度图到XYZ，哪些误差来自内参，哪些来自外参和时间？
2. 为什么丢弃颜色可能改善外观泛化，却损失某些任务所需信息？
3. 点云编码器表现更好时，如何排除工作区裁剪和训练数据泄漏的影响？
