# FoundationStereo：单目先验增强的双目匹配

## 先读总结

FoundationStereo直接对应深度相机与双目视觉主线，建议优先阅读。它结合双目几何匹配与预训练单目视觉先验，提高跨场景的视差估计能力，再通过相机标定恢复米制深度。与单目相对深度相比，度量依据来自双目基线和焦距，但结果仍依赖同步、校正与可靠对应。对人形机器人，它适合近场稠密几何和操作区域感知；快速头动、低纹理、手臂遮挡及算力限制需要实测。它是双目算法，不等于某种主动投光硬件，也不是拿两张任意图片就能获得可靠尺度。[论文](https://arxiv.org/abs/2501.09898)

## 定位、输入与输出

首次公开2025，优先级P0。输入经过立体校正的左右图像，输出视差；转换点云需要内参和以米表示的基线。官方明确提示多相机图像应先校正，并提供分辨率、细化次数等推理选项。[官方代码](https://github.com/NVlabs/FoundationStereo)

## 方法流程与核心机制

冻结的Depth Anything V2提供单目先验特征，旁路CNN补充细节，组合左右图像特征建立代价体。空间与视差维度的聚合帮助处理模糊对应，再通过迭代细化得到视差。它使用单目特征作为双目匹配线索，而非把单目输出直接当作米制深度。[作者方法概览](https://nvlabs.github.io/FoundationStereo/)

核心理解是两个信息来源互补：双目对应提供几何约束，视觉先验有助于纹理不足或外观复杂区域。网络先验也可能在证据不足时给出看似合理但有偏的结构，因此仍需检查误差。

## 训练数据与监督

作者构建约百万对合成立体图像，并通过自动筛选减少有歧义的样本；视差真值用于训练。数据多样性和模型模块都参与泛化。零样本指相关测试域未做专门微调，不意味着无需标定或预处理。[全文数据与实验部分](https://arxiv.org/html/2501.09898)

## 实验能证明与不能证明什么

跨域双目基准支持泛化提升，作者项目还展示与常见RGB-D设备及单目模型的点云比较。示例可以帮助观察薄结构与复杂材质，不应直接解释为所有设备、距离和运动条件下全面优于硬件深度。相机基线、分辨率、后处理与采集时间都可能影响比较。[作者项目页](https://nvlabs.github.io/FoundationStereo/)

官方仓库提供加速与分辨率选项，但部署效果需记录硬件、输入尺寸和迭代次数。后续Fast-FoundationStereo是独立工作，不能把其实时性能归给本文。[官方实现与后续入口](https://github.com/NVlabs/FoundationStereo)

## 工程迁移判断：从视差到人形近场几何

以下为原创推导与建议。在标准水平校正且主点已适当处理时，Z=fB/d，其中f为像素焦距、B为基线、d为视差。小视差扰动导致深度误差近似为Z²乘视差误差再除以fB；因此远处相同像素误差会变成更大距离误差。这解释了为何只报告视差平均误差不足以评估抓取距离。

对近场，较大视差、左右遮挡与最小工作距离同样重要。两台头部相机虽随头部一起转动，理想刚性条件下相对外参不变，但时间不同步、滚动快门与结构振动仍会破坏匹配。IMU可以帮助估计快速转动阶段和分析误差；本文网络本身不融合IMU，也不自动补偿所有曝光畸变。

主动双目通常通过投影纹理改善可匹配性，本算法并不要求或替代投影器。红外与RGB也有域差，能否处理某型号相机原始红外图，应单独验证。稀疏LiDAR可用于独立几何核验，但同样要确认同步、外参和遮挡。

## 局限与应补知识

补立体校正、代价体、遮挡一致性、视差符号和缩放规则。缩小图像会同时改变焦距与像素视差；若只改变其中一个，米制结果将系统偏移。左右主点不一致时不能不加处理地套最简公式，应按校正投影矩阵恢复深度。已有轮式几何经验在这里非常有价值，但人形需要更重视近距离、非静态相机和端到端时延。

## 最小学习实验（建议，未执行）

取得可访问原始左右图像的已标定双目设备，采集纹理平面、无纹理平面、细杆、反光物四类场景。先以静止同步图像比较传统SGBM、设备原生深度和FoundationStereo；相同可见区域下报告距离误差、有效点比例、边缘误差及延迟。

再测试头部转动或手持转动，按IMU角速度分组，统计误差与失效。故障注入左右帧时间偏差、轻微垂直错位、图像缩放但漏改内参，观察症状。基准必须使用独立测量，不以某个待比较方法自身输出作真值。最后针对输入分辨率和迭代次数画精度—延迟表，作为是否可部署的证据。
