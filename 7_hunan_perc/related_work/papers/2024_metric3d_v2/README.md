# Metric3D v2：相机内参参与的单目度量几何

## 先读总结

Metric3Dv2针对单目度量深度与表面法向，核心是把不同相机的数据变换到统一的规范相机空间，再恢复原相机下的几何量。它能帮助你理解为什么换一台相机、裁剪图像或改变焦距会影响米制深度，也能说明深度和法向的联合学习价值。它仍然使用学习到的先验，已知焦距并不让任意单张图的尺度变得物理上唯一。对人形感知，它适合研究局部表面、目标距离及深度缺测时的辅助估计；应与真实RGB-D或LiDAR交叉核验，不能仅凭好看的点云确认接触精度。[论文](https://arxiv.org/abs/2404.15506)

## 定位、输入与输出

首次公开2024；优先级P1。输入单张RGB并结合相机内参进行规范化和恢复，输出度量深度与表面法向。v2包含深度—法向联合优化，不能将v1配置和v2结果混用。本文只关注局部几何输出，不展开论文的SLAM应用。[作者项目页](https://jugghm.github.io/Metric3Dv2/)

## 方法流程与核心机制

不同焦距会使外观相似的物体对应不同深度。规范相机变换把训练样本转换到共享相机条件，再由网络预测深度；推理时利用内参逆变换回原尺度。另一模块迭代优化深度与法向，使二者通过几何一致性互相约束。注意迭代细化不是视频时间融合，同一张图内运行若干步不能自动提供帧间稳定性。[全文方法部分](https://arxiv.org/html/2404.15506)

## 训练数据与监督

论文使用跨相机、跨场景的大规模深度数据，并在可用时利用法向标签。联合目标让法向分支从更多深度数据中受益，缓解法向标注覆盖不足。官方仓库给出数据字段中的相机内参、深度单位比例与规范空间配置，说明数据预处理是方法的一部分。[官方实现](https://github.com/YvanYin/Metric3D)

## 实验证据与边界

公开深度、法向任务和跨相机场景支持其泛化能力；作者项目展示度量结构恢复。但“零样本”是相对于特定数据与训练协议的表述，不保证所有新相机和极近距离场景无偏。精确抓取需要的局部误差，不能由整图平均指标替代。[作者项目页](https://jugghm.github.io/Metric3Dv2/)

官方将仿射不变评价与米制评价分开列出，阅读时必须看是否进行真值对齐；经过尺度对齐的低误差不等同于原始米制输出精度。[官方评价入口](https://github.com/YvanYin/Metric3D)

## 工程迁移判断：内参、点云和法向

以下为原创推导与建议。使用光轴深度Z反投影时，点为Z乘K逆乘像素齐次坐标。这里的Z不同于沿射线的距离；把两者混用会在图像边缘产生结构性误差。裁剪或缩放图像后，也要更新焦距和主点。正好适合复用你已有的相机几何知识，并通过数值实验检查整个预处理链。

法向是方向，不含平移；从相机系变到基座系时只乘旋转部分。人形头部姿态变化后，用于判断桌面倾角或脚前局部坡度的法向要与重力方向处于同一坐标系。IMU提供的姿态或重力估计可参与这一步，但原网络不直接融合IMU，也不能把剧烈运动中的原始加速度直接当作精确重力。

即使内参准确，单张图仍依赖物体尺寸、透视和语义统计先验。建议将网络预测视为带系统偏差可能性的估计，用独立深度测量验证；不要因为字段单位标为米，就默认误差具有标准测距传感器的性质。

## 局限与应补知识

补规范相机变换、深度与法向关系、坐标系方向、深度评价中的对齐协议。反射、遮挡边缘、极近场和机械部件可能表现不同。法向平滑可让平面更整齐，也可能掩盖小台阶或薄边，操作场景应评价任务关键区域。

多相机切换时，应分别记录内参、畸变校正、裁剪和最终输入分辨率，而不是把所有相机统一resize后复用一个焦距。对LiDAR对照，先确认测量时间与可见性，再解释两种深度的差异。

## 最小学习实验（建议，未执行）

拍摄具有独立距离测量的平面和非对称物体，使用两种焦距或两台已标定相机，各取近、中、远距离。按官方预处理运行，保留原始米制输出，不做真值尺度对齐。统计分距离的绝对误差、平面残差、法向角误差。

设计两项故障注入：图像缩放后忘记改内参；焦距数值加入固定比例偏差。比较误差形态，检查规范恢复逻辑。再做头部转动序列，将法向转换到基座或重力参考系，观察静止平面是否一致。IMU与图像须先时间对齐。产出误差表、内参变换记录与典型点云，而不是只展示整齐平面。
