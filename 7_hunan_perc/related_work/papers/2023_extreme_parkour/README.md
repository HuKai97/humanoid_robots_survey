# Extreme Parkour with Legged Robots

- 首次公开：2023；正式发表：ICRA 2024。作者：Xuxin Cheng、Kexin Shi、Ananye Agarwal、Deepak Pathak。
- 优先级：P1；定位：低频深度、历史记忆与感知到运动接口。
- 具身：Unitree A1四足；仅用于人形方法迁移，不是人形实验。
- 核查日期：2026-09-29；状态：调研完成，实验未执行。

## 先读总结

这篇工作用前视深度和机载本体信息驱动四足跑酷，值得学习的是如何把训练中理想地形信息转化成部署时带延迟、噪声和有限视野的视觉输入。它先学习能访问特权地形的策略，再把地形表征与行进方向蒸馏到深度编码器，借助历史记忆弥补当前帧的局限。对人形感知而言，最有价值的主题是时序、遮挡与感知输出接口，而不是直接复制跳跃动作。真实四足成功不等于更高重心、不同支撑条件的人形也能成功。[论文](https://arxiv.org/abs/2309.14341)｜[项目](https://extreme-parkour.github.io/)

## 研究问题与输入输出

需要解决的感知问题是：当相机频率低、视野随运动剧烈变化、深度边缘存在伪影时，如何及时得到适合下一步动作的环境信息。学生输入深度、本体及任务命令，输出关节目标；视觉分支同时提供地形相关潜变量和目标朝向。教师使用的scandots是仿真地形采样信息，不能理解成部署时必须配备的LiDAR。[论文第3节](https://arxiv.org/html/2309.14341v1#S3)

## 方法机制：从理想到可部署输入

作者先用特权地形、环境状态及路点方向训练策略，再以CNN与GRU处理深度，替代原来的地形输入。通过DAgger让学生执行并接受教师动作监督；方向也需要学习，初期不可靠的方向预测采用教师与学生混合处理。这样训练分布更接近学生实际会访问的状态。[方法与训练流程](https://arxiv.org/html/2309.14341v1#S3)

读者可以这样理解：脚边区域可能已经离开前视相机视野，但它此前出现在远处。历史模块有机会保留这一信息，然而记忆是否对应当前身体位置取决于运动历史和训练。网络潜变量不等于可逐像素核查的地形地图，因此系统调试应同时记录原始深度、潜变量时间戳与动作时刻，而不能只保存最终动作。

## 训练监督与实现入口

训练包含地形难度课程、策略优化和视觉蒸馏两个主要阶段。官方仓库将基础策略与带相机蒸馏训练分开，命令中的相机与延迟选项影响实际实验含义。复现应先核对这些选项，再讨论模型优劣。[官方训练说明](https://github.com/chengxuxin/extreme-parkour)

原文部署使用D435深度相机，视觉与基础策略以不同频率工作，并处理感知/本体时延。[部署说明，第4.1节](https://arxiv.org/html/2309.14341v1#S4) 对工程学习更重要的不是记住某个频率，而是画出传感器曝光、传输、预处理、推理、动作消费的时间线。固定延迟和随机抖动是两种不同问题，平均FPS无法代表后者。

## 实验证据与限制

项目展示跨越间隙、高台和倾斜地形等四足行为；作者同时展示消融与失败案例，例如缺少方向蒸馏或边缘相关奖励的影响。[作者实验展示](https://extreme-parkour.github.io/) 这些证据支持其特定硬件、地形与训练设置，不能推导任意动态环境或人形负载行走的可靠性。

感知工程师还应区分“地形看错”“方向选错”“身体执行误差”三类失败。单一任务成功率很难定位责任。视觉网络也可能利用地形家族的固定外观或课程顺序，面对混合结构时失效；这是需要额外设计测试的风险，而非本笔记声称原文已证实的问题。

## 对人形感知的启发（推断）

最值得迁移的是特权到传感器的训练范式：在仿真中用可靠局部几何作教师，部署时让深度与IMU/关节历史预测任务所需的表征。对于人形，应进一步考虑脚掌面积、摆腿扫掠空间、胸前双臂遮挡和负载变化；四足的边缘容忍度与人形并不一致。

如果团队已有局部高度图，可以先训练“深度历史→局部地形”的独立学生，再评估是否需要动作级联合训练。保留可视化中间量有助于把感知工作与控制工作分工。本文给出的是一种端到端接口参考，不要求感知岗位接管整套强化学习。

## 轮式背景需要补什么

理解teacher/student、特权信息、DAgger与循环网络的含义；明确IMU和关节历史既反映运动，也可能间接反映接触。已有的时延测量和驱动调试经验非常重要。应补足的几何概念是支撑边缘和未来落足，而非再学一套全局定位后端。

## 最小学习实验（设计，未执行）

1. 录制或仿真相机从远处接近一级台阶的深度序列，同时保存姿态与时间戳。构造“台阶边缘当前已出视野”的测试片段。
2. 对比单帧CNN、固定窗口CNN、CNN加GRU，监督输出相对机体的台阶边缘与高度；所有模型用相同场景和输入分辨率。
3. 注入固定延迟、随机抖动与连续丢帧三组扰动，分别画误差曲线，不把它们混为一种噪声。
4. 对隐藏状态重置做消融，并检查模型是否在场景切换后保留错误记忆。

验收：离开视野后的误差是否随时间失控、记忆何时应该失效，以及端到端延迟分布。该实验不执行跑酷，也不声明复现作者硬件性能。
