# Kalibr 基础：Unified Temporal and Spatial Calibration for Multi-Sensor Systems

## 先读总结

多传感器融合的第一步，是确定不同传感器在什么位置、各自时间戳指向什么时刻。Furgale、Rehder、Siegwart 的 2013 年工作以连续时间轨迹为纽带，联合求解空间变换与时间偏移，是 Kalibr 的基础参考之一。它不是人形感知网络，但很适合成为你的第一篇：在人形机器人转头、躯干摆动时，时间错位很容易被误认为视觉或点云模型失效。本笔记聚焦相机—IMU 标定，后续多 IMU、滚动快门功能属于工具箱其他论文，不能都归到这一篇。

## 问题、输入与输出

相机提供图像和标定板观测，IMU 提供带时间戳的角速度与比力；还需相机模型、板子尺寸及 IMU 噪声配置。目标是相机相对于 IMU 的刚体变换与时间偏移，而不是生成检测框、深度或环境地图。工具通过样条轨迹和批量优化联合解释这些观测，输出变换、时差和残差报告。[官方教程](https://github.com/ethz-asl/kalibr/wiki/camera-imu-calibration)

## 方法怎么理解

以下是便于学习的通用解释，非逐式复述原文：假设有一条连续轨迹，每个传感器都在自己的采样时刻观察这条轨迹。相机外参改变预测的图像位置，时间偏移改变“到轨迹的哪个时刻取值”。二者都影响残差，因此联合估计比先随意配帧、再固定时差更有原则。

可把目标函数概念化为“图像残差 + 陀螺仪残差 + 加速度计残差”，各项需要按噪声强度加权。IMU 测量不能被当成无噪声真值；Kalibr 的统计模型区分快速测量噪声与缓慢变化的偏置。[噪声模型](https://github.com/ethz-asl/kalibr/wiki/IMU-Noise-Model)

没有神经网络训练集。决定标定是否可靠的是传感器模型、标定板质量、运动激励和时间戳质量。官方建议充分激励各轴、控制模糊并检查时间戳抖动。本文不把官方示例频率写成你平台必须满足的规格。

## 对人形系统的迁移判断

**以下是工程判断。**头部相机与头部 IMU 若在同一刚体上，可以标定固定变换；头部相机与骨盆 IMU 隔着可动关节，则不应直接假设存在一个固定外参。应标定各刚体内的固定参数，再用关节状态和运动学连接它们。转头时测得“外参在变”，可能是模型假设错了，而不是优化器精度不足。

另一个常见陷阱是把消息抵达主机的时间当成曝光时间。某个常数时差能拟合一段数据，不表示解决了时钟漂移、随机抖动或传输排队。应把这些误差分开测量。

## 实验证据与局限

本次没有核验原文数值，不能给出“精度达到多少”的承诺，也没有在当前机器执行标定。工具输出的小残差不足以单独证明外参准确：缺乏激励、错误噪声权重、少量重复视角，都可能让结果在当前片段看起来很好。独立片段复验和跨次标定稳定性是必要的工程检查。

Kalibr 解决标定，并不直接处理所有 LiDAR 模型、机器人结构弹性或运动关节的几何误差。iKalibr 是另一套框架，不是 Kalibr 的版本升级。

## 从轮式感知背景需要补什么

优先补齐 SO(3)/SE(3) 的变换方向、角速度与比力的区别、IMU 连续时间噪声参数、采样时间与到达时间、可观测性。暂时不必学习 SLAM 回环或后端。

## 最小学习实验（建议，未执行）

准备同一刚性传感器模组的两段短数据：一段有多轴旋转和平移，另一段仅平面转动。在相同设置下独立标定，记录旋转、平移、时间偏移的跨段差异，并在第三段数据检查重投影。若暂无设备，先设计配置与记录表，不伪造实验值。验收物是“变换方向图 + 时间戳直方图 + 参数稳定性表”，不是单张看起来重合的点云图。

## 自测

1. 外参误差与时间偏移为何会在快速旋转中相互混淆？
2. 头部与骨盆之间存在关节时，固定外参假设哪里失效？
3. 残差下降但独立片段变差，应先查哪几类输入问题？
