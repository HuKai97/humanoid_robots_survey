# iKalibr：统一的无靶标时空标定

## 先读总结

iKalibr 把 IMU、相机、LiDAR、雷达的时空标定放入同一个连续时间框架，通过动态初始化和多轮批量优化估计传感器之间的外参与时差。对于你关注的相机—LiDAR—IMU 组合，它提供的是融合前的基础，而非某种检测网络。重点学习不同测量如何关联到统一时间和运动模型，以及为什么丰富运动和正确传感器模型比“多接一个传感器”更重要。它虽然使用轨迹与几何约束，但本调研仅讨论离线标定，不展开其相关的定位或建图算法。

## 输入、输出、任务边界

输入是带时间戳的多传感器记录与各传感器模型，系统包含至少一个 IMU。输出主要是传感器相对参考系的旋转、平移与时间偏移，以及优化所需的运动状态。作者通过惯性、视觉和几何观测建立统一约束；“无靶标”表示不需要额外人工标定物，不表示没有场景结构要求。[论文](https://arxiv.org/html/2407.11420v2)

## 核心流程

方法先恢复旋转的连续表示，再让不同传感器提供的运动线索与惯性观测对齐，获得初始参数；随后建立数据关联，用惯性残差、视觉重投影、LiDAR 点到面等测量约束进行批量细化。按传感器组合选择有效约束，而不是要求每种设备都存在。官方实现同时强调充分运动激励，并明确它不是 Kalibr 的扩展。[官方说明](https://github.com/Unsigned-Long/iKalibr)

**理解这套方法的关键**是区分两种融合：标定融合在估计“谁在什么时间、什么位置看见了什么”；任务融合在估计“是什么物体、哪里可以踩”。前者错误会污染后者的训练标签、特征投影和评价真值。学习 BEVFusion 之前，应能手算点从 LiDAR 系到相机系的变换，并说清它们对应的采样时刻。

## 数据与监督

这属于几何优化，不是依赖目标类别标签的监督学习。论文用真实多传感器系统和公开数据检验参数一致性、重复性与运行开销。需要区分论文时点的模块和当前仓库后来增加的支持；RGB-D 专门的速度模型是下一篇扩展，不能反写为原版所有实验的共同设置。

## 对人形感知的工程评议

刚性安装的胸部相机、LiDAR、IMU 可以形成一个标定单元；头部独立转动时，应通过头颈关节链连接，而不能把整个机器人视作刚体。标定数据中的大幅动态动作也不应简单复制工作步态：落脚冲击、结构振动和图像模糊会同时破坏理想测量模型。先在可控条件下获取充分但清晰的激励，再检查正常工作状态下的投影误差。

LiDAR 与相机看见相同物体也可能不在同一时刻。多传感器的平均帧率接近，不等于点级或曝光级时间对齐。标定获得常数时差以后，还要检查时钟比例误差以及点云每点时间字段。

## 能证明什么，不能证明什么

论文支撑统一离线标定框架在所测系统中的可行性；它不证明任意人形安装方式都可观测，也不保证接入后检测精度必然提高。此处不引用未经逐表比对的精度值。将它部署到不同品牌 LiDAR、非刚性连接或恶劣反光场景，需要额外验证传感器模型和数据关联。

## 学习前置与最小练习（未执行）

前置知识：刚体变换、手眼标定的基本形式、B 样条的作用、最小二乘与鲁棒损失、运动激励。

建议先画相机、LiDAR、IMU 三节点图，给每条边写清变换方向与时钟关系。然后用一段已知标定的数据人为加入常数时间偏移或外参扰动，查看点云投影边缘错位如何变化。一次只改变一个因素，同时记录慢速和快速旋转片段。重点是学会诊断，不必一开始重写完整标定器。
