# BEVFormer：用空间与时间注意力建立视觉 BEV

## 先读摘要

BEVFormer 将多相机图像组织成统一的鸟瞰特征：空间交叉注意力负责从不同视角取信息，时间自注意力把历史 BEV 与当前帧结合，供三维检测等任务使用。它虽然是视觉为主的工作，却能帮助你理解多传感器融合之前最关键的一步——如何建立可对齐的空间表示。人形机器人的头部运动、自遮挡与短时视野缺失使时序信息尤其值得研究，但历史特征先要正确补偿运动，不能把过去看过的位置当成当前确定可见。本文没有证明车载 BEV 网络能直接适应人形大幅俯仰与关节运动。[原论文](https://arxiv.org/abs/2203.17270)

## 基本信息与阅读位置

- 全名：BEVFormer: Learning Bird's-Eye-View Representation from Multi-Camera Images via Spatiotemporal Transformers。
- 作者：Zhiqi Li、Wenhai Wang、Hongyang Li 等。
- 首次公开：2022；会议：ECCV 2022。
- 定位：多视角、时序视觉三维感知；**优先级 P1，理解 BEV 的时序组织**。
- 本笔记讨论原始 camera-only BEVFormer，不混入后续同系列或 LiDAR 扩展。[官方仓库](https://github.com/fundamentalvision/BEVFormer)

## 问题、输入与输出

输入包含当前多相机图像、历史 BEV，以及投影与时间对齐所需的几何信息；输出是统一 BEV 特征，再由任务头产生三维框或语义分割。多相机不是多种传感器模态：它们共享 RGB 成像机制。其学习价值在于为 LiDAR、深度或姿态信息建立可兼容的空间接口，而不能在综述中直接标作 Camera–LiDAR 网络。[作者摘要](https://arxiv.org/abs/2203.17270)

## 方法机制与流程

给每个 BEV 网格一个可学习 query。空间交叉注意力为该网格构造不同高度的三维参考点，将参考点投影到可见相机，在相邻图像位置采样特征。这样避免对全部图像像素做全局注意力。时间分支先依据自运动对齐历史 BEV，再通过时间自注意力汇聚历史与当前信息。[方法第 3 节](https://arxiv.org/html/2203.17270)

这里有两个不同问题：自运动补偿用于让静态世界对齐；动态目标自身运动仍需网络处理。前者出错会污染大范围历史特征，后者不能靠一个全局刚体变换解决。对初学者，画出“一格 BEV 在两个时刻、三个相机中对应哪里”比先背注意力公式更有效。

## 训练监督与数据要求

原方法通过三维检测或语义任务监督表示，需要相应标签；不是仅靠连续视频就自动学出可靠深度。多帧训练还需确保序列边界正确，不能把不同场景的历史缓存接起来。官方实现有不同尺寸的配置和模型，后续运行必须固定图像骨干、分辨率与历史长度再比较。[官方实现与模型配置](https://github.com/fundamentalvision/BEVFormer)

## 实验能证明什么，不能证明什么

论文的自动驾驶实验支持时空融合可改善视觉三维感知，特别关注速度估计和低可见性目标。它不能证明“历史越长越好”，也不能保证当前被遮挡的目标仍在原处。本文主要是相机方案，不能把其结果解释为 LiDAR 消融。移动底盘上的评价更不等同于人形摇摆、转头与近场精细操作。[论文摘要及实验](https://arxiv.org/html/2203.17270)

## 局限与人形迁移判断

以下为本调研判断：人形可借鉴短时感知记忆，而不必投入 SLAM 后端研究。工程接口应由其他模块提供时间对齐的姿态/运动信息，你负责检查其不确定性如何影响感知。IMU 旋转补偿有帮助，但单独 IMU 并不直接提供无漂移的平移或完整传感器位姿；若头部跨关节运动，还需关节角与传感器安装变换。

汽车多相机常接近刚性固定，人形可能只有头部双目或 RGB-D，且头部相对身体转动。照搬固定相机数量、视场、BEV 范围和高度参考点通常不合适。脚边盲区与被手臂遮挡的区域要标明“最近观测时刻”，对动态目标设置过期策略，不能让历史记忆变成幻影障碍或幻影自由空间。三维操作区域可保留体素/点特征分支，避免把层间关系压成二维。

## 从轮式背景需要补什么

补 deformable attention、参考点投影、时序特征缓存、静态与动态补偿的区别。你熟悉的坐标变换在这里仍是核心，只是被搬到特征层。还需建立观测时效概念：同一输出中有些部分来自当前测量，有些来自历史推断，应能分别评估。

## 最小学习实验（设计，未执行）

1. 用已知相机姿态的短室内序列，选择一个静态桌边和一个移动目标。
2. 构造“当前帧、正确对齐历史、错误对齐历史”三组，可先用语义/边缘特征而非完整网络验证。
3. 对姿态、时间延迟分别加扰动，观察历史叠加后是否出现双边缘和目标拖影。
4. 固定缓存长度后测试遮挡恢复；统计目标召回、静态边界偏移、虚假障碍持续时间及缓存开销。

先证明对齐与过期机制有效，再讨论加入更复杂注意力。此实验未执行，不代表官方结果。
