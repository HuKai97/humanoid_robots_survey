# CReF：深度与本体状态的跨模态时序融合

## 先读总结

CReF 是与你的方向直接相关的人形工作：把前向深度和本体状态融合，直接服务复杂地形行走。核心思路是让身体状态决定从深度图中读什么，再用门控和循环记忆整合历史；部署时不先重建显式高程图。它展示了“多模态”不必包含语言，深度、IMU 派生状态和关节信息本身就是关键组合。对感知岗位，最值得学习的是状态条件化特征和时序记忆，而非把整套动作控制原样复制到另一台机器人。

## 信息与证据

- 全名：CReF: Cross-modal and Recurrent Fusion for Depth-conditioned Humanoid Locomotion。
- 首次公开 2026；本笔记依据 v3（2026-07-27）。优先级 P0，近期方法。
- 实机：AGIBOT X2 Ultra；深度相机为 D435i。证据层级：**全文 HTML 方法/实验选读 + 作者项目页**。
- [论文 v3](https://arxiv.org/html/2603.29452v3)、[项目](https://cometlogic.github.io/cref/)。核查日期：2026-09-29；未核验可复现的完整代码发布。

## 输入输出与具体机制

输入包含深度、身体角速度、重力方向、关节位置与速度、指令和历史动作，输出为关节目标。深度被编码成局部 tokens，本体表示作为 query 读取深度，再经过门控残差融合和 GRU，融合当前与历史信息。另有速度估计器。训练使用 PPO 与带特权信息的 critic，并有落脚相关奖励；“部署不用显式地图”不等于训练完全不用几何或真值。[方法](https://arxiv.org/html/2603.29452v3)

## 为什么和轮式感知的差别大（学习解释）

对固定外形的轮式机器人，许多任务只需环境类别和地面障碍。对人形，同一台阶在不同支撑脚、身体倾斜和运动方向下，对下一步动作的意义不同。本体状态作为条件，可以让环境特征服务当前动作阶段。这是对架构的学习性解释，不能把注意力可视化直接当作因果证明。

记忆则处理“现在看不见但刚才看见过”的问题，例如前向相机无法始终观察脚底。它也会带来历史污染：相机移动、深度失效或动作切换后，旧信息是否还应被保留，需要额外检查。一个 gate 并不自动等于经过校准的置信度。

## 训练和实机证据边界

论文比较移除跨注意力、门控残差和 highway gate 的变体，并做地形与硬件验证。实验设置中说明真实相机时钟到系统时钟的处理，可见端到端学习仍依赖工程时间对齐。原文还区分上台阶、下台阶及分布外设置，不能只读总体成功率。[实验部分](https://arxiv.org/html/2603.29452v3)

本笔记不将单平台结果外推为跨机器人通用能力；不同相机安装角、图像预处理、关节结构和执行延迟都可能改变输入分布。也不把前向地形通过能力扩展成背后或侧面全身避障能力。

## 面向感知工程师的重点

你可以把该系统拆成两个可研究问题：深度与身体状态怎样融合；融合表示怎样在缺帧、遮挡和异步情况下维持任务信息。即使不训练控制器，也能通过代理任务检验表示是否保留台阶边缘、支撑区域和短时几何。明确代理任务改善并不等同于真实行走改善。

前置学习：cross-attention 的 Q/K/V、GRU、teacher/critic 的特权信息、本体状态与原始 IMU 的区别、传感器到控制器的数据年龄。

## 最小学习实验（建议，未执行）

在离线地形序列上比较深度特征、深度与本体拼接、状态 query 的跨注意力三种输入，统一网络容量和监督。测试只用当前帧与短时记忆的差异；按转身、遮挡、上下阶、缺帧分桶。先预测几何或可见支撑区域，记录误差与延迟，不把此实验宣称为 CReF 完整复现。

## 自测
