# DPL: Depth-only Perceptive Humanoid Locomotion via Realistic Depth Synthesis and Cross-Attention Terrain Reconstruction

- 首次公开：2025；作者：Jingkai Sun 等；本笔记以2026-08-03的arXiv v3为准。
- 优先级：P0；定位：深度、本体/IMU历史到局部地形的直接人形感知工作。
- 具身：TienKung Ultra全尺寸人形；外感传感器为单台Orbbec 335L深度相机。
- 核查日期：2026-09-29；状态：调研完成，实验未执行。

## 先读总结

DPL是本调研中与当前学习目标直接相关的论文：它用深度图和本体历史重建机器人附近的高度图，再让行走策略使用带误差的重建结果。关键思想是把身体运动、时序记忆与局部几何结合，同时在仿真中模拟身体遮挡和结构化深度噪声。题名里的depth-only只表示外部视觉传感的简化，系统仍利用关节、角速度、重力方向等本体信息。它有全尺寸人形实机证据，并不要求全局SLAM；但网络补出的不可见地形仍是推断，不能当作真实测量。[论文与版本](https://arxiv.org/abs/2510.07152)

## 研究问题与接口

感知难点是人在走动时深度不断受姿态、自遮挡和缺失影响，而落足需要局部几何。DPL以深度历史和本体历史为输入，输出局部高度图，后接带盲行走骨干的感知策略。局部高度参考身体，而非维护全局一致地图。[全文方法](https://arxiv.org/html/2510.07152v3#S4)

这类接口对不做SLAM的感知岗很合适：可以负责近场几何与可靠性，把长期定位作为外部条件。工程上仍应清楚“无需全局定位”不等于“无需姿态、速度或传感器标定”。

## 方法机制：先重建，再让策略适应误差

论文把本体嵌入作为query、深度嵌入作为key/value进行交叉注意力；融合后的历史信息经过循环记忆和解码得到粗高度图，再以带深度条件的U-Net细化。训练分别约束粗重建和细化结果。仿真深度同时考虑地形与机器人网格，增加连续误差及边缘相关缺失；策略使用重建结果，并结合教师动作监督与强化学习优化。[方法第IV节](https://arxiv.org/html/2510.07152v3#S4)

机制解释：本体query相当于用身体当前运动条件决定哪些视觉信息更相关。它不直接取代几何变换，而是学习在部分观测下提取任务信息。记忆提供过去看过区域的线索，细化网络强化地形结构；后者也可能使输出“看上去更规整”，因此必须同时评估真实边缘偏差，不能只检查平滑程度。

重要的工程问题是区分三类格子：当前实测、历史观测、从先验补全。三类来源的可信程度并不相同。如果把补全区域统一当作已知空间，下游很难知道何时应降低速度或重新观察。这是阅读者建议增加的接口，原文不等于已经输出这些置信标签。

## 训练监督与证据边界

作者用仿真真值监督地形重建，并以特权教师指导学生；学生在不完美地形输入上适应动作。v3还明确解释了感知重建进入训练环路的作用。真机平台和相机型号以v3为准；早期版本在硬件命名上有差异，不应混写。[v3方法与实验](https://arxiv.org/html/2510.07152v3)

论文报告地形重建、组件消融及真实地形穿越。其真实重建表中完整方法MAE为3.25±0.56厘米；这个数值属于该实验设置，不能直接与别人的地形、真值来源和可见区域定义不同的数值比较。[v3表III](https://arxiv.org/html/2510.07152v3#S5) 本笔记不将示范视频或平均误差解读为零失败率。

## 局限与需要追问的点

以下为阅读者分析。第一，低MAE可能掩盖少量严重台阶边缘错误，而脚掌往往恰好受这些错误影响。第二，遮挡区域存在多种几何解释，网络即使给出清晰表面也不代表唯一正确答案。第三，针对某一深度相机调出的噪声模型，换成双目、ToF或不同曝光条件后需要重新核查。第四，学习记忆并不保证长期空间一致；它与SLAM维护的地图目标不同。

论文展示可在缺失观测下补全几何，但从观测论角度，完全不可见的形状只能依赖历史或先验。遇到训练中少见的洞、薄板或可动结构时，必须专门测试，不能把“补得完整”直接当作优点。

## 对人形感知的启发（推断）

建议优先复现独立重建模块的概念，然后与已有点云投影局部图比较，暂时固定下游控制器。记录误差如何随头胸俯仰、摆臂、步态阶段和深度失效率变化，能够直接生成适用于团队感知工作的改进方向。

用户已有轮式系统经验可用于深度质量诊断与标定；新增工作是把身体自遮挡和运动历史纳入输入契约。即便未来加入LiDAR，也应保留其扫描时间与可见性差异，不要直接把所有XYZ拼接后当作同时观测。

## 轮式背景需要补什么

补局部浮动基座坐标、重力投影、关节历史、GRU、交叉注意力和特权教师。控制方面只需先理解高度图如何改变步态参数与关节目标，不必重学全部动力学优化。重点是把感知误差与脚掌支撑几何关联起来。

## 最小学习实验（设计，未执行）

1. 生成平面、台阶、间隙的短深度序列，记录机体姿态、关节及局部高度真值；加入一个会挡住相机的简化手臂网格。
2. 对比直接深度投影、深度历史网络、深度加本体交叉注意力。固定数据和参数预算，先不接强化学习。
3. 用相同基础噪声，分别加随机独立孔洞和沿几何边缘聚集的孔洞，检查哪种更接近自己的真实传感器。
4. 分开统计可见、历史可见和从未可见区域的高度MAE、台阶边缘误差、把不可落足区误判为可落足区的比例，以及推理延迟。
5. 构造外观相同但隐藏底部深度不同的间隙，检查模型是否无根据地给出确定补全。

验收：不仅得到一张漂亮高度图，还要知道误差出现在哪里、哪些输出有测量支持。该实验为自行设计，不声称复现DPL完整控制性能。
