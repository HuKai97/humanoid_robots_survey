# Learning Vision-Guided Quadrupedal Locomotion End-to-End with Cross-Modal Transformers

- 首次公开：2021；正式发表：ICLR 2022。作者：Ruihan Yang 等。
- 优先级：P1；定位：深度图像与本体/IMU信息融合的基础案例。
- 具身：四足；人形相关性是方法迁移，本文不提供人形验证。
- 核查日期：2026-09-29；状态：调研完成，实验未执行。

## 先读总结

LocoTransformer把前视深度图与本体状态分别编码成视觉区域token和状态token，再通过共享Transformer交换信息，为运动策略提供联合表征。它值得感知工程师学习的原因，是移动相机看到的图像变化既可能来自障碍，也可能来自机器人自身姿态变化，本体信息因而能够帮助解释视觉。论文有四足仿真和真实环境验证，但不能直接视为人形落足精度的证据。阅读时应优先看模态编码、融合位置和消融对照，再看强化学习部分。[论文](https://arxiv.org/abs/2107.03996)｜[项目](https://rchalyang.github.io/LocoTransformer/)

## 研究问题与输入输出

研究问题是如何让机器人在接触前预见地形，而非只根据接触后的本体反馈调整。输入包括堆叠的前视深度图和姿态、惯性相关观测与关节等本体信息（并非简单拼接原始六轴IMU流）；输出为策略动作，价值分支用于训练。这里“多模态”指外感与本体信息，不涉及语言，也不是LiDAR与相机点云的显式配准。[论文方法第4节](https://arxiv.org/html/2107.03996v3#S4)

## 方法机制：沿数据流理解

论文用CNN提取深度空间特征，用MLP处理本体状态，保持视觉区域而不是过早压成单个向量，再把这些特征投影到同一维度。共享Transformer对两种token联合做自注意力，更新后的表征用于动作与价值预测。其意义是允许状态信息影响视觉区域之间的信息交换，而不仅在最终预测头前做拼接。[作者方法介绍](https://rchalyang.github.io/LocoTransformer/)

下面是阅读者的机制解释：假设两帧中台阶边缘都向上移动，可能是机器人低头，也可能是接近台阶。只给单帧深度时，网络需要从图像统计中猜测；引入同步角速度、姿态及关节状态后，就增加了区分两者的条件。注意力提供一种可学习的信息选择方式，但并不自动保证几何一致性；时间戳、单位或坐标系出错仍可能让网络学到虚假相关。

## 训练监督与工程入口

作者通过强化学习联合优化视觉编码与策略，并进行仿真到真实四足迁移。官方实现位于vision4leg；它同时包含LocoTransformer和另一项多模态延迟随机化工作，复现时必须选择对应配置，不能把同仓库的所有增强都归到本论文。仓库提供PyBullet环境、PPO训练与配置入口。[官方代码及配置说明](https://github.com/Mehooz/vision4leg)

对感知岗，先理解“任务奖励会反向塑造视觉特征”即可，不必第一天复现完整行走。监督学习中检测框准确率是显式目标；这里感知特征的好坏主要通过后续动作带来的回报体现，因此特征可迁移性不能只由训练回报判断。

## 实验证据与边界

项目展示室内障碍与室外环境中的真实四足验证；论文比较视觉、本体和融合设计，支持加入视觉与跨模态交互具有价值。[项目实验展示](https://rchalyang.github.io/LocoTransformer/) 这不是公开世界中任意障碍的可靠性保证，也不是全尺寸双足、人群穿行或负载搬运的证明。

阅读者需要额外检查：训练和测试是否使用相同相机俯角；几何扰动与动力学扰动是否分开；是否只报告到达率而缺少擦碰率；视频成功片段是否有对应分母。注意力热图能够帮助排查网络看哪里，但不能单独证明该区域对决策具有因果作用。

## 对人形感知的启发（推断）

可以把“本体条件化视觉”作为人形融合基线：头部/胸部深度特征与IMU角速度、重力方向、关节历史共同建模。人形的俯仰和垂向运动更明显，训练时应保留这些变化，不宜只拿稳定推车采集图像做训练。若后续增加LiDAR，应该单独设计其时序与几何编码，不能把稀疏雷达数据直接当作同分布深度图。

建议同时保留一个可解释的局部几何输出，例如可见区域高度或边缘位置，以区分“融合网络缺少信息”和“动作头没有利用信息”。这是学习建议，不是原文已有模块。

## 轮式背景需要补什么

先补三件事：关节编码器与IMU形成的本体向量；部分可观测条件下的历史窗口；策略、价值函数和PPO的基本关系。已有相机内外参、坐标变换、数据同步经验可以直接迁移。需要改变的是任务度量：轮式绕障的通道宽度，与人形脚掌支撑面及身体摆动余量并不相同。

## 最小学习实验（设计，未执行）

1. 生成含平地、一级台阶、箱体的简单深度序列，保存每帧相机俯仰、机体高度与同步本体量；按场景而非按帧划分训练和测试。
2. 固定训练预算，对比深度CNN、本体与深度末端拼接、联合token注意力三个编码器。为降低门槛，先监督预测台阶边缘位置与可见高度图，不接动作策略。
3. 测试额外俯仰扰动、本体延迟一至数帧、深度缺失，报告边缘位置误差、可见区域高度误差和推理时间。
4. 加入随机打乱本体的负对照。若打乱后性能基本不变，不能声称模型真正使用了本体信息。

验收产物应是三组曲线与失败样本，而不是一张注意力图。这个实验检验融合机制，不能复现论文的行走结论。

## 自测

1. 为什么“视觉特征拼接本体向量”与“编码阶段跨模态注意力”不是同一件事？
2. 深度相机安装角度变化时，IMU哪些量有帮助，哪些外参信息仍缺失？
3. 如何证明网络利用了同步本体，而不是只从视觉预测动作？
