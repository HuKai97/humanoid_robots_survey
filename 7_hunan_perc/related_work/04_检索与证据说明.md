# 检索范围、来源与证据边界

## 需求与纳入规则

用户有传统轮式机器人感知背景，转向人形机器人，已明确重点是视觉、LiDAR、深度相机与 IMU，不做 SLAM。文献按“能帮助理解一类机制或人形迁移问题”选择，不按热度机械堆砌。

纳入：时空标定、深度与三维表征、视觉与点云融合、局部地形、传感器退化、人形感知到动作接口。通用视觉基础模型、四足方法和车载融合只在与主线有关时纳入，并显式注明验证平台。

排除主线：VIO/LIO/SLAM 算法、闭环全局地图、纯动作模仿与盲行走控制、无传感器细节的演示新闻。DP3 与 GR00T N1 仅作 P2 接口扩展。局部高程/MEM 的位姿视为外部输入，感知融合与定位后端分工明确。

## 检索记录

检索与核验日期：**2026-09-29**。通过公开网页检索、arXiv 摘要与 HTML 正文、作者项目页和官方 GitHub 仓库交叉核查；没有调用抓论文脚本，没有保存 PDF 或 LaTeX。此轮是有明确取舍的入门调研，**不是穷尽数据库的系统性文献综述，也不保证覆盖截止日所有新论文**。

使用的查询主题包括：

- camera LiDAR fusion / PointPainting / TransFusion / BEVFusion / BEV depth；
- RGB-D IMU spatiotemporal calibration / Kalibr / iKalibr；
- metric depth / stereo foundation model / 3D object pose / point transformer；
- humanoid perceptive locomotion depth / lidar / multi-camera / terrain reconstruction；
- local elevation multimodal mapping / proprioception cross-modal attention。

先以代表工作建机制骨架，再检查 2025–2026 人形相关工作。对于新预印本，优先阅读实际传感器、训练/部署差异、硬件限制及失败边界，避免按标题判断能力。

## 证据标签怎样读

| 标签 | 本次实际做了什么 | 不代表什么 |
|---|---|---|
| 全文 HTML 方法/实验选读 | 在线阅读相关方法、设置、消融或结果文字 | 不等于逐式推导、复查全部图像或复现代码 |
| 摘要 + 官方项目/仓库 | 核验研究问题、核心机制、资源归属与条件 | 不保证所有定量指标已核实 |
| 官方教程/仓库 | 核验工具操作与模型说明 | 不能冒充已读对应原始论文全文 |
| 工程判断/迁移推断 | 用测量模型和任务要求分析适用性 | 不是原作者在人形上报告的实验结果 |
| 最小学习实验 | 本调研设计的练习 | 没有实际运行，也不是论文官方复现成绩 |

Kalibr 基础论文没有读取原始全文，笔记依据官方教程与书目；其他篇目的具体章节与版本见单篇末尾。某些作者网页打不开时，保留论文中给出的地址并写“未核实”，不把第三方页面冒充作者来源。

## 年份、版本与代码

目录年份统一使用首次公开年份；正式会议/期刊年份在正文注明。因此 PointPainting 是 2019 预印本/2020 CVPR，若按会议年份检索应同时考虑两者。后续 arXiv 版本可能改变题名、硬件配置和实验，笔记写明实际采用的版本。

“有仓库”“有推理代码”“有训练代码”“有权重”“有可合法使用的数据”是不同状态。代码链接只提供查阅入口，并不说明本次安装或运行成功。AnyGrasp SDK、RPL 待发布代码、GR00T 系列版本更新等问题在单篇说明。正式复现时必须固定具体 commit、模型版本、数据版本和许可条件。

BEVFusion 存在两篇同名工作。本资料核心指 MIT 的 `2205.13542`；另一篇 `2205.13790` 只做同名澄清，不交叉借用实验结论。

## 如何比较论文

本次没有把不同数据集的数字放在同一排行榜。自动驾驶 mAP、室内分割 mIoU、深度误差和实机动作成功率具有不同分母与任务条件，不能直接排序。个别笔记保留原文数值时附对应版本和表格上下文，不将其当作本地测得结果。

结论强度应按“原文设置下的结果 → 对该机制的支持 → 本项目可检验的迁移假设”逐层降低。论文中展示一个动作，不足以说明它解决了通用感知；在四足或汽车上有效，也不能直接标注成人形已验证。
