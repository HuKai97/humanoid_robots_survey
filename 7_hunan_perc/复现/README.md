# 复现入口

当前没有安装模型或执行实验。建议先完成三项低成本离线基线，再讨论研究创新。

| 顺序 | 范围 | 最小输入 | 交付 |
|---|---|---|---|
| 1 | 时空与投影审计 | 已有RGB/LiDAR或RGB-D、标定、时间戳 | 坐标链、扰动曲线、独立序列误差 |
| 2 | 局部几何与语义 | 给定短时位姿、点云/深度、语义输出 | 高程、三维障碍、未知掩码、失败样例 |
| 3 | 深度与本体时序 | 带时间的深度/点云与本体序列 | 当前帧/历史/融合对照，按运动分桶结果 |

具体步骤见 [学习路线](../related_work/02_学习路线.md)，数据见 [dataset.md](../dataset.md)。每个方法建立单独目录，用 [报告模板](复现报告模板.md)记录。实际下载代码、模型与数据时核查版本和许可；本次未下载。
