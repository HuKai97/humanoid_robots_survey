## 已识别的坑

- VLN-CE 是连续环境，动作仍可离散，原代理不是双足动力学模型。
- R2R val_seen 与训练场景重叠；泛化主看 val_unseen/held-out 场景，不能声称所有官方 split 均 scene-disjoint。
- ETPNav 原设置用模拟器真值位姿与 12 向 RGB-D，全景/位姿获取不能在真实部署时被忽略。
- 当前 NaVid 公开权重训练设置不同于原论文部分跨数据实验；VLN-CE 原文和 README 基线成绩也有差异，不能混写。
- VLN-PE/StreamVLN/JanusVLN 的原作者实机是四足；人形仿真或后续适配另记。
- NaVILA 论文有 T1，人形 G1 项目展示与正文试验分开；Go2 低层使用 LiDAR 高度图。
- InternNav 是平台，InternVLA-N1 是系列，DualVLN 是具体论文/配置；RGB 与 RGB-D 配置分开。
- HumanoidVLN 资源注明录用后发布；TANGO 项目访问失败，代码未核实。TANGO 使用低层 tracker 做可执行性筛选，动作监督保留参考动作；复杂障碍实机使用行为显式语言。
- 原文中的“real environments”有时指扫描的真实房屋图像，不能据标题宣称人形实机。
