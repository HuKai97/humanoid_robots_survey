# 术语表：按系统位置记忆

| 缩写/术语 | 中文解释 | 初学者常见误解 |
|---|---|---|
| Embodied AI | 智能体通过感知和行动与环境交互 | 有机器人外形就意味着做了真实交互评估 |
| VLN | Vision-and-Language Navigation，视觉语言导航 | 任何识别物体的机器人任务都是 VLN |
| VLN-CE | VLN in Continuous Environments，连续环境中的 VLN | 连续环境必然输出连续关节力矩 |
| VLN-PE | 面向物理具身环境的 VLN 平台/评测工作 | 与所有人形 VLN 基准完全等价 |
| PointNav / ObjectNav | 给位置目标／给物体类别目标的导航 | 物体类别等于唯一物体实例 |
| Grounding | 把语言里的描述对应到图像、物体、位置或动作 | 生成听起来合理的解释就是正确 grounding |
| Egocentric | 以智能体自身视角观察 | 第一视角不等于单视角，也不等于全局鸟瞰 |
| RGB-D | 彩色图像和深度图 | 仿真深度与真实深度噪声相同 |
| Pose / Odometry | 位姿／通过运动估计相对位姿变化 | 测试时总能直接读取真值位姿 |
| SLAM | 同时定位与建图 | 必须使用 SLAM 才能做任何导航 |
| Topological map | 用节点和边表达地点及连接关系 | 拓扑相连就一定可被当前身体穿过 |
| Metric map | 保留距离、坐标等几何信息的地图 | 几何地图自动理解语言目标 |
| Occupancy map | 空闲、障碍、未知区域表示 | 平面占据图描述了手臂和头部所有碰撞 |
| Waypoint | 中间路点/子目标 | 输出一个路点等于实际到达该路点 |
| Local planner | 将附近目标转成局部可执行路线 | 上层正确就无需检查局部规划 |
| VLM / LVLM | 视觉语言模型／大视觉语言模型 | 通用图文理解能力等于闭环导航能力 |
| VLA | Vision-Language-Action，视觉语言动作模型 | 所有 VLA 都输出关节动作，或都能导航 |
| IL / BC | 模仿学习／行为克隆，用专家演示监督策略 | 单步预测准确就不会在闭环中积累错误 |
| RL | 强化学习，用交互奖励优化策略 | VLN 必须从头用 RL 训练 |
| Teacher forcing | 训练时沿专家状态/动作条件进行预测 | 与策略自己走到的状态分布完全相同 |
| DAgger | 汇集策略访问状态及专家标注的模仿学习方法 | 仅做静态数据扩充就等于 DAgger |
| Zero-shot | 对指定目标任务/数据不做对应训练的评测设置 | 完全没用任何预训练、任何环境数据 |
| Sim-to-real | 仿真学习或评估向真实机器人迁移 | 仿真成功就证明实机可靠 |
| Locomotion | 机器人本体移动与步态控制 | 速度跟随本身就完成语义导航 |
| Whole-body control | 同时协调身体多个部分的控制 | 只控制底盘位置就充分代表全身控制 |
| DoF | 自由度，独立运动变量的数量 | 所有自由度都必须由大模型直接预测 |
| POMDP | 部分可观测马尔可夫决策过程 | 当前图像足以知道整个场景和过去状态 |
| Episode | 从初始状态、指令开始的一次完整任务 | 一个数据样本和一个视频帧相同 |
| SR / SPL | 成功率／以路径效率加权的成功率 | SPL 能完整衡量是否按语言规定路线行走 |
| NE / OSR | 终点导航误差／路径曾到达目标邻域的比例 | OSR 高说明停止动作也正确 |
| nDTW / SDTW | 轨迹与参考路径的相似度／成功加权 nDTW（失败 episode 记 0） | 这些指标能替代人形平衡和碰撞测量 |

这是项目教学词表。任务与指标定义可核对 [R2R](https://arxiv.org/abs/1711.07280)、[导航评测建议](https://arxiv.org/abs/1807.06757)、[nDTW](https://arxiv.org/abs/1907.05446)、[VLN-CE](https://arxiv.org/abs/2004.02857)。具体论文如何使用上述词语，以各篇的方法与配置为准。
