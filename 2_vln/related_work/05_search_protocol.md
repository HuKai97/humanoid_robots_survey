# 调研范围、检索方法与证据边界

## 本次交付范围

检索日期为 **2026-09-29**。这是面向入门和后续选题的精选调研，覆盖经典 VLN、连续环境、视觉语言模型导航、物理机器人导航和直接人形前沿。保存 28 个工作档案，其中 DualVLN/InternVLA-N1 为区分版本的系列档案，另含两篇综述；不能把档案数当作去重后的精确论文统计。

没有声称完成系统综述或穷尽所有引用关系。论文的新颖性、所有实验表格、代码可运行性和全部外部下载链接不在本次验证范围内。未下载 PDF、LaTeX 源码、权重、数据或安装环境。

## 如何选择

纳入标准至少满足一项：定义重要任务/指标；代表一条关键方法路线；连接图/连续/物理执行；有人形导航或跨身体评测证据；对理解当代 VLM 导航特别有帮助。优先原论文、作者项目与代码。博客、聚合榜单和搜索摘要只用于发现线索，方法结论回到一手来源。

旧文献按任务、方法和基准追溯；近期文献组合搜索 `humanoid vision language navigation 2025 2026`、`humanoid VLN benchmark`、`VLN-PE`、`NaVILA`、`StreamVLN`、`InternNav` 等词，并检查原论文版本历史与项目 README。

## 资料深度怎样标注

- **摘要/项目级**：可以解释目标、总体机制和作者报告的范围；不据此编网络细节或实验因果结论。
- **HTML 重点章节级**：已读指定方法、设置、附录或局限段落；不等于所有公式、图和结果表均经精读。
- **代码 README 级**：确认作者提供的入口、依赖、权重与版本说明；不等于完成源码审计或成功复现。
- **本调研分析**：针对人形迁移、局限和学习练习的推论，明确与作者已实验证明的内容区分。

每篇均按上述实际情况写明。arXiv 摘要页与同篇 HTML 属同一原始作品，不能当作两项独立实验支持。找不到第二个独立一手内容时如实说明，例如 TANGO 的项目地址本次访问失败。

## 本次特别核对的易错点

| 易错点 | 本次处理 |
|---|---|
| 首发年份与正式发表年份不同 | 单篇记录，如 R2R 2017/2018、ETPNav 2023/2024；目录年份只是检索标签 |
| nDTW 原论文与 SPL 建议文混淆 | 分开引用 2019 Ilharco 等与 2018 Anderson 等 |
| 连续环境等同连续关节控制 | 单列环境、动作、控制器 |

| 人形仿真等同人形实机 | 明确机器人类型及原论文/后续适配归属 |
| 模型系列、平台与论文名混淆 | 区分 InternNav、InternVLA-N1 与 DualVLN 配置 |
| GitHub 有仓库等同资源齐全 | 只写已核查 README 的内容；HumanoidVLN 待发布，TANGO 代码未核实 |
| 不同版本成绩冲突 | 保留差异；VLN-CE 原论文与当前 README、NaVid 权重说明均有专门备注 |

## 如何持续更新

每次更新先读 AGENTS 与 handoff；在本文件记更新日期和范围。新条目使用 [论文模板](templates/paper_note.md)，核查版本、来源和实机证据后加入 `_meta` 与索引。对新“最好成绩”先核查同设置；旧笔记因版本变化失效时保留说明，不悄悄替换结论。

## 重要但本轮未展开的分支

数据增强与预训练还有 EnvDrop、PREVALENT、Recurrent VLN-BERT 等经典方法；对话导航、长程多任务、社会导航、移动操作以及底层人形 locomotion 可各自扩成一轮专题。本轮用 Speaker-Follower、HAMT、DUET 代表部分历史路线，优先把时间用于连续执行与人形相关工作。此处只列延伸检索线索，不将未做独立解析的条目算入已完成档案。
