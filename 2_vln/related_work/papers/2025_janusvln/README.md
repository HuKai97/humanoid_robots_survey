# JanusVLN：把语义记忆与空间记忆分开

**论文**：JanusVLN: Decoupling Semantics and Spatiality with Dual Implicit Memory for Vision-Language Navigation。首次提交 **2025-09-26**，已查 v2 更新于 2026-02-25；摘要与官方仓库确认 **ICLR 2026**。优先级 **P1**。核查日期：2026-09-29。

## 先读总结

JanusVLN 认为只记住“看到了什么”不够，还要保留“物体和空间怎样组织”。它融合语义编码器与三维几何编码器，并分别保存有限大小的隐式记忆。原论文真实机器人为 **Unitree Go2**；后续 HumanoidVLN 将其用于人形物理仿真。该工作的主要贡献是导航感知和记忆，不是人形全身动作控制。[摘要](https://arxiv.org/abs/2509.22548)

## 问题、输入与输出

语言指令可能要求“走到最远的椅子旁”。单纯认出椅子类别不足以判断距离、方向和相对位置。JanusVLN 从 RGB 视频和指令出发，预测前进、左转、右转、停止等导航动作。原文任务定义中的前进和转动属于模拟器动作尺度，接到人形后仍需一个执行接口。[HTML §3.1](https://arxiv.org/html/2509.22548v2)

## 方法如何工作

语义分支以 Qwen2.5-VL 为基础，几何分支引入预训练 VGGT，提供从 RGB 提取空间结构的先验。两路特征融合后参与动作预测；历史信息通过 KV cache 保存，并结合初始窗口与滑动窗口增量更新。存储规模受到限制，避免路线增长时一遍遍重算全部历史。[作者项目页](https://miv-xjtu.github.io/JanusVLN.github.io/) [HTML 方法](https://arxiv.org/html/2509.22548v2)

**概念解释（本调研分析）**：隐式记忆是一组模型内部特征，不是可以直接查看的完整地图。它能帮助决策，却不一定能告诉研究者“门到底宽多少”。“推理时用 RGB”也不代表模型从未接触过三维监督：几何基础模型的预训练知识仍是重要前提。

## 实验与人形关系

原论文在 R2R-CE、RxR-CE 上评估，并做空间记忆、语义记忆和几何先验等消融；实机定量实验使用 Go2、25 条指令、每条重复三次。原始实机证据支持空间记忆帮助这些导航任务，不是人形机器人稳定行走的证明。[HTML 实验与附录 C](https://arxiv.org/html/2509.22548v2)

2026 年的 [HumanoidVLN](https://arxiv.org/abs/2608.12860) 把 JanusVLN 与其他模型接到统一人形平台进行比较。这是另一研究团队在其控制器、身体、场景和指令条件下的结果；不能回写成 JanusVLN 原作者做了四个人形实机实验，也不能把该基准平均分与 R2R-CE 原表直接合并。

## 局限与待验证问题

原文失败分析提到停止过早，并讨论几何特征缺少真实尺度可能影响距离判断。固定大小记忆也天然存在选择保留哪些历史的问题。[HTML 附录 D](https://arxiv.org/html/2509.22548v2)

**本调研分析**：人形的俯仰、侧摆可能影响空间特征的一致性，但这需要受控实验验证。可以先固定路线、身体与控制器，对比真实相机姿态和稳定相机观察；同时看 SR、停止距离、错误路口与内存开销，不能只看一个成功率。
