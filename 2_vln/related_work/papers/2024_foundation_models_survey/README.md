# 2024 基础模型时代 VLN 综述

## 一分钟总结

这篇综述适合建立“论文解决了哪一类问题”的阅读框架。它从环境表示、人类意图理解、导航智能体三方面组织文献，能帮助你把大量模型缩写放回问题本身。建议先读任务表和分类框架，再按遇到的问题回查；它不覆盖 2025–2026 的全部人形新进展。

- 阅读范围：arXiv 元信息，HTML 正文的框架、任务表、历史/记忆与未来方向部分；未对每条参考文献完成独立查证。

## 论文如何组织问题

作者采用 LAW 框架，将环境表示、理解用户和智能体决策放到同一导航流程中。环境侧关注历史与跨场景泛化；用户侧关注语言与意图；智能体侧关注 grounding、推理、规划及基础模型的用法。[正文 §1–6](https://arxiv.org/html/2407.07035v2)

这里的 world model 是较宽的环境表征概念；不能看到这个词就认定每个方法都训练了生成未来视频的动力学模型。阅读综述时保留作者原本的术语范围很重要。[框架定义](https://arxiv.org/html/2407.07035v2)

## 对初学者怎样使用（本项目建议）

拿一篇陌生方法，按以下顺序问：它主要改变环境记忆、指令解释还是动作决策？用已有模型替代了哪个模块？增加了哪些输入？它的泛化结论是跨场景、跨语言，还是跨机器人？这样能避免把“使用更大的 VLM”本身当作完整研究问题。

可把每篇论文画成一个五格图：观察、记忆、指令、决策、执行。用颜色标记论文真正改动的格子，再列出未改动模块依赖的假设。这是本项目的笔记练习，不是原文的一项实验。

## 实验与结论边界

这是一篇综述，不是同一控制变量下重跑所有模型的统一实机排行榜。它汇总的基准和成绩应回到原论文核对传感器、预训练数据、搜索预算及评估划分。因此，本笔记不将综述表格里的跨设置数字直接抄成性能排名。

## 与人形方向的关系（分析）

三类问题仍然适用于人形机器人，但还需增加身体执行层：相机随身体晃动影响世界表示，走路失败影响指令执行进度，身体尺寸和全身姿态影响可达性。建议把本篇与 VLN-PE、HumanoidVLN 配对阅读，观察哪些隐含的具身假设开始被显式测试。

## 读完应有的产出

一张自己的研究地图：每一支放两篇代表文献，并写一句“这支研究在减少哪种失败”。随后任选一个分支精读原论文，而不是继续无边界地增加综述阅读量。
