# NaVid：Video-based VLM Plans the Next Step for Vision-and-Language Navigation

**检索日期：2026-09-29｜优先级：P0｜类别：单目视频 VLN-CE、sim-to-real。** 首次 arXiv：2024；正式发表：RSS 2024。作者：Jiazhao Zhang 等。

## 先读总结

NaVid 用在线 RGB 视频与语言指令预测前进、转向、停止及相应参数，是从图节点 VLN 进入真实导航的重要阅读点。最关键的区分是：导航模型只读 RGB，不代表整台真实机器人没有定位或控制传感器。[官方项目](https://pku-epic.github.io/NaVid/)

## 问题、输入输出与训练

任务为 VLN-CE：机器人在连续环境中执行运动，不能靠已知导航图瞬移。输入是当前及历史单目图像、完整指令；输出包括动作类型与移动距离或转角。它基于视频 VLM 进行导航数据训练，并联合视觉语言辅助任务；不是仅靠提示的零样本方法。

## 核心机制

1. 同时提取与指令相关的视觉信息以及保留场景结构的信息。
2. 历史帧使用较少 token，当前帧保留更细的视觉表示，控制长序列开销。
3. 通过标记区分历史、当前观测和指令，再预测文本形式动作。
4. 解析器把输出转成动作类型与数值，执行后读取新帧，形成闭环。

训练还加入非最优轨迹来缓解只学专家路径的分布偏移。[HTML 正文 §III–IV](https://arxiv.org/html/2402.15852v2)

## 实验事实与版本差异

论文研究 R2R-CE、R2R→RxR 的跨数据集迁移，以及真实室内语言导航。当前官方评测仓库公开的 NaVid 权重说明采用 Uni-NaVid 训练策略，并使用 R2R/RxR 训练划分，因此它不等同于原论文只用 R2R 训练的跨数据集设置。项目页与早期 arXiv v2 的数据规模表述也存在版本差异；本笔记不混用这些数量或成绩。[官方评测 README](https://github.com/jzhzhang/NaVid-VLN-CE)

## 实机证据与局限

已读 v2 附录 A-C 明确使用 TurtleBot 4：NaVid 从远端服务器接收 RGB、输出命令，机器人利用激光里程计跟踪运动。因此“RGB-only”限定于高层导航模型输入。现有证据是轮式平台，不能写成人形验证。[实机设置原文](https://arxiv.org/html/2402.15852v2)

**本调研分析：** 人形可借鉴视频历史与参数化动作接口，但上下起伏、头部摆动、运动模糊会改变观察分布。连续环境也不等于双足动力学仿真。必须补充命令跟踪、避障、停止距离与失步失败记录；视觉 token 压缩可能损失长程关键地标，需通过失败分类和消融检验。

## 初学者学习与后续复现

先对比“选择图节点”和“预测前进距离”需要哪些不同信息，再学习视频 token、行为克隆和 DAgger。后续可选官方固定权重，在场景隔离的少量 R2R-CE episode 上记录轨迹、动作解析、停止错误与耗时。评测 README 仍列历史 Habitat 依赖，应锁定论文相匹配的代码版本。改权重、训练混合或相机参数都要建立新配置，不能混入原版成绩。本次未运行。

阅读自测：假设模型命令前进一米，而底层实际只前进半米，下一帧能否让策略纠正？如果图像在转头期间模糊，它会把身体朝向变化误认为路径进展吗？先通过这类纸面例子明确观察、决策与执行的边界，再决定需要记录哪些日志。
