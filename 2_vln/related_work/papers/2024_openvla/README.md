# OpenVLA：An Open-Source Vision-Language-Action Model

**检索日期：2026-09-29｜优先级：P2｜类别：通用 VLA 背景，机器人操作。** 首次 arXiv：2024；本笔记按预印本标记，不推测正式会议。作者：Moo Jin Kim、Karl Pertsch、Siddharth Karamcheti 等。

## 先读总结

OpenVLA 用机器人示范把视觉语言模型变成能输出动作的策略，并开放模型与微调工具。它主要服务机械臂操作，适合补充“VLM 如何变成 VLA”的概念；本篇没有构成人形 VLN 的实验依据。入门导航时可晚于 NaVid 阅读。[论文摘要](https://arxiv.org/abs/2406.09246)

## 问题、输入输出与训练

输入为图像与语言操作指令，输出与训练机器人定义相匹配的动作。官方示例采用 7 维动作接口及数据集特定的反归一化统计；该维度不能直接对应人形全身自由度。模型为 7B，基于多种机器人操作轨迹进行监督训练，并支持新任务微调。机器人形态多样意味着训练数据覆盖多个操作平台，不能自动解释为任意人形即插即用。[官方 README](https://github.com/openvla/openvla)

## 核心机制

1. 融合 DINOv2 和 SigLIP 视觉特征，再投影到语言模型输入空间。
2. 将各维连续动作离散化为 token，让 LLM 学习预测动作序列。
3. 推理时把 token 还原为数值，并用对应数据统计恢复实际尺度。
4. 在新任务上利用 LoRA 等方法适配模型，而不是每次从头预训练。

原版动作离散化每维使用 256 个区间，训练目标集中在动作 token 上。该设计与导航里“左转多少度”的动作语义、尺度和频率都需要分别定义。[HTML 正文 §3](https://arxiv.org/html/2406.09246v3)

## 实验事实与证据边界

官方项目展示 WidowX、Google Robot 与微调后的 Franka 操作实验，分析语言选择目标、物体干扰以及新平台适配。其成功率属于操作任务，不能放入 VLN 的 SR/SPL 表。项目也指出一些困难语义泛化场景仍存在不足。[作者项目与实验](https://openvla.github.io/) 本笔记不复述未逐表核验的整体提升数值。

## 局限与人形 VLN 关系（分析）

把动作转成 token 并不会自动得到空间记忆、路径顺序理解或平衡控制。长程导航需要处理部分可观察性、停止判据与持续误差；操作预训练数据也未必覆盖导航场景。可迁移的部分是动作编码、数据组织、检查点适配和评估方法。若尝试人形全身 VLA，还需要明确本体状态、动作空间、控制周期与训练示范来源；这些都是待验证工作。

## 初学者学习与后续复现

先区分“回答该往哪里走”和“输出可执行数值”的差别，再学习行为克隆、动作归一化、离散 token 和 LoRA。建议先纸面追踪单样本的图像→token→动作恢复流程，并检查不同机器人统计量不能混用。未来若需要操作模块，再讨论运行官方任务；目前不将其列为 VLN 首个复现 baseline。仓库已链接后续 OFT 等工作，它们属于不同模型/训练配置，不能把后续改进归到 2024 原版结果。本次未安装或运行。

阅读自测：同样的数值在两个机器人的动作统计中是否代表同样的移动量？模型识别出目标之后，为什么还可能因为执行尺度不一致而失败？这个问题对后来设计人形导航动作接口同样有用。
