# Uni-NaVid：A Video-based Vision-Language-Action Model for Unifying Embodied Navigation Tasks

**检索日期：2026-09-29｜优先级：P1｜类别：多任务视频导航 VLA。** 首次 arXiv：2024-12；正式发表：RSS 2025。作者：Jiazhao Zhang 等。[官方代码](https://github.com/jzhzhang/Uni-NaVid)

## 先读总结

Uni-NaVid 将路径指令跟随、物体导航、具身问答和跟人四种任务统一到视频加语言输入中，并用在线 token 合并减少长历史的推理开销。对入门者，它把“VLN 模型”扩展为“多任务导航模型”，但四足实机结果不能自动算作人形结果。[论文摘要](https://arxiv.org/abs/2412.06224)

## 问题、输入输出与训练

输入是单视角 RGB 视频与自然语言。导航输出为前进、左右转、停止等动作序列，问答任务还输出文字。模型需要多任务监督训练，论文报告约 360 万导航样本，并辅以视觉语言数据；这里的样本不能误读成同等数量的独立路线或场景。它的连续环境动作接口仍需底层执行器。

## 核心机制

1. 视觉编码器将每帧转成视觉 token。
2. 在线合并相似的时空信息，保留较近历史更多细节、压缩较远历史。
3. 与文字指令共同输入语言模型，预测未来一段动作，减轻逐步等待。
4. 不同任务使用一致的数据组织形式共同训练；执行时根据新观测更新动作。

关键学习点是历史表示与控制频率之间的折中。[HTML 正文方法](https://arxiv.org/html/2412.06224v2)

## 实验与实机事实

官方项目展示多个导航任务与混合长程任务；任务间要用各自指标评估，不能把 EQA 准确率与 VLN 的 SR 合并排名。[项目页](https://pku-epic.github.io/Uni-NaVid/) 已读 HTML 的实机附录使用 Unitree GO2 四足机器人，远端 A100 执行模型，机载 LiDAR 参与本地控制。约 5 Hz 是特定推理条件下报告值，网络通信与执行仍有额外延迟；不能当作人形闭环控制频率。

## 开源版本差异

官方 README 提供微调、离线推理和外部 VLN-CE 评估入口，公开训练样例是一个子集。它还说明因许可限制未使用 L3MVN 方法生成 ObjectNav 模仿学习数据，可能使公开版本的 ObjectNav 表现下降。因此不能预设公开权重在全部任务上逐项复现论文成绩。[代码数据说明](https://github.com/jzhzhang/Uni-NaVid#data)

## 局限与人形 VLN 关系（分析）

统一格式解决的是学习接口，不保证各任务互相促进或面对动态障碍时稳定执行。历史压缩可能丢掉重返地点的依据，提前输出多步动作又可能在场景变化时过期。人形迁移可先研究高层动作接口与观测扰动，但双足稳定性、停步过程和全身碰撞还需独立控制与评测。代码样例里出现“走到 humanoid robot”只是目标描述，不是机器人本体为人形的证据。

## 初学者学习与后续复现

先读 NaVid，再画出在线合并前后的历史 token 数量变化，解释延迟如何影响动作有效性。后续先复查官方离线例子的动作格式，再评估单一 VLN-CE 设置；固定权重版本、训练划分、token 合并参数与动作执行接口，逐步增加任务。不要从四任务全量重训开始。本次未下载数据、权重或运行评测。
