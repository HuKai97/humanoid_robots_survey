# HAMT：把长时历史变成可查询的多模态记忆

**论文：** History Aware Multimodal Transformer for Vision-and-Language Navigation，Shizhe Chen 等。**年份：** 2021 首发，NeurIPS 2021。**优先级：P1。** 本次范围：HTML §3、实验与部分附录；作者项目页；官方仓库 README。属于关键章节解析，未完整代码审计和复现。

## 先总结

HAMT 用分层 Transformer 编码过去的全景观测和动作，把语言、历史与当前画面一起用于下一步决策。它适合帮助初学者理解“导航为什么需要记忆”，以及预训练任务如何服务序列决策。[作者项目页](https://cshizhe.github.io/projects/vln_hamt.html)

## 背景、输入输出与假设

输入包括整条指令、历史全景和动作、当前全景及可达候选；输出下一候选节点或 STOP。主要设定为离散图上的 VLN。模型能看到的信息取决于全景与候选生成协议，不能将它直接当成单目视频机器人策略。[正文 §3](https://arxiv.org/html/2110.13309)

**学习解释：** “经过沙发后第二个门右转”需要记住沙发是否已经经过以及门数。把全部过去压成一个循环隐状态可能难以保留细节；显式历史允许当前决策重新关注旧观测。不过，能访问历史不保证一定学会计数和空间关系，还需要用任务和实验验证。

## 方法怎样组织

1. 用 ViT 编码每个视图，在同一全景内部建模空间关系，再汇聚为一步历史表示。
2. 加入动作与时间信息，用时序编码连接历史步骤。
3. 跨模态 Transformer 融合文字、历史和当前观测，给候选动作打分。
4. 先做掩码建模、指令—轨迹匹配、动作和空间关系等代理任务，再结合 imitation learning 与 reinforcement learning 微调。[正文 §3.1–3.3](https://arxiv.org/html/2110.13309)

官方实现区分固定视觉特征的预训练与解冻 ViT 的端到端阶段，并提供多个下游任务脚本。[官方实现](https://github.com/cshizhe/VLN-HAMT)

论文覆盖 R2R、RxR、REVERIE、CVDN 及更长路径任务。附录 Table 15 中，采用 ViT、预训练和端到端视觉优化的配置，在 **R2R val-unseen** 为 **SR 65.7%、SPL 60.9%**。这行分数绑定其完整训练设置，不能只归因为 Transformer 或历史长度。[正文及附录 Table 15](https://arxiv.org/html/2110.13309)

## 局限与人形关系

**事实边界：** 本文不提供人形实机 VLN 或关节控制证据。

**本项目分析：** 人形连续视频中，相邻帧高度相似且带步态抖动；直接把每帧都当一个历史节点会浪费计算，也可能让“走过多少步”与“看到多少帧”混淆。迁移时可研究关键帧选择，但这只是候选问题，需要先复现模型并量化失败类型。另一个重点是处理定位和方向噪声：仿真提供的稳定角度编码到了真机上可能不再准确。

记忆模型也可能用环境外观记住训练建筑，因此未见建筑的结果比训练集高分更有解释力。运行预算要记录历史长度、输入视图数和端到端时延，不能只比较参数量。

## 初学者阅读与复现准备

先看项目页分层历史图，再看 §3.1 的历史 token；之后区分预训练代理任务与在线导航目标。建议手工画出 `t=1,2,3` 时模型各自拥有的观测，检查是否包含未来帧。

后续先评估已有权重，再逐项比较短历史、长历史和冻结视觉特征；保持数据、视觉骨干和动作空间不变。官方依赖较旧，应先记录环境版本再计划隔离环境；本次没有安装或启动训练。[仓库说明](https://github.com/cshizhe/VLN-HAMT)
