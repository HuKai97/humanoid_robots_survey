# VLMaps：Visual Language Maps for Robot Navigation

**检索日期：2026-09-29｜优先级：P1｜类别：开放词汇语义地图、空间目标导航。** 首次 arXiv：2022；正式发表：ICRA 2023。作者：Chenguang Huang、Oier Mees、Andy Zeng、Wolfram Burgard。

## 先读总结

VLMaps 把视觉语言模型的语义特征放进有几何坐标的地图，让“椅子”“沙发与电视之间”等语言能够对应到可规划的位置。它是理解“语言落地到空间”的重要工作，但实验任务与 R2R 路径指令基准并不相同。最值得学习的是语义定位、空间运算、路径执行三层接口。[项目页](https://vlmaps.github.io/)

## 问题、输入输出与训练

传统几何地图知道哪里有障碍，却不容易理解“窗边的桌子”；图文模型认识桌子，又缺乏全局坐标。方法用带相机位姿的 RGB-D 观测构图，查询阶段接收自然语言，输出地标位置或一串导航 API 调用，再交给路径规划器。它使用预训练视觉语言模型和语言模型，无需为目标环境新增语言标注和模型微调；这不意味着没有建图、定位或环境覆盖成本。[论文摘要及年份](https://arxiv.org/abs/2210.05714)

## 核心机制：按数据流理解

1. 从 RGB 图像提取稠密语义特征，通过深度和位姿投影到空间地图。
2. 把文字地标编码到对应语义空间，通过相似度检索地图中的目标区域。
3. 将“中间”“左侧若干米”等表达转成地标坐标上的空间运算。
4. 语言模型生成对预定义机器人函数的调用，规划器依次执行子目标。

同一语义地图还能根据机器人形态选择不同障碍类别。地图中的“认识物体”和控制器的“能够到达”仍是两件需要分别验证的事。[作者机构方法说明](https://research.google/blog/visual-language-maps-for-robot-navigation/)

## 实验事实与证据边界

官方页面报告仿真及真实环境中的语言空间目标导航，展示地面机器人与无人机共享地图的例子。其跨形态展示不能自动解释为双足人形验证。本笔记未逐表核对论文结果，因此不抄录聚合提升数字。官方代码包含建图、目标物体导航与空间目标导航评测入口；README 也坦陈拐角碰撞、障碍膨胀堵住窄门等规划问题。[代码 README](https://github.com/vlmaps/vlmaps)

## 局限与人形 VLN 关系（分析）

地图质量依赖深度与位姿，人的移动、物体搬移会使语义位置过时。二维可通行区域不足以表达低矮横梁、台阶与脚底支撑条件。对人形机器人的可迁移价值是语义地图和指令分解接口；仍需验证身体包络、动态平衡和通过门洞的能力。论文中的跨形态观点是研究启发，不能替代这些验证。

## 初学者学习与后续复现

先补 RGB-D 反投影、坐标系变换、余弦相似度、栅格路径规划。学习时手算一个例子：已知沙发和电视坐标，如何得到中间目标，再检查目标是否落在障碍上。后续先做静态地图中的语言检索，再测试子目标到达；把检索错、坐标错、规划错分别记录。复现时需固定代码提交、数据许可和语言模型版本，不能把旧 API 示例视为今天必然可运行的配置。本次未安装、下载数据或运行。
