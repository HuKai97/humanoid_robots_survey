# 人形机器人视觉语言导航（VLN）调研与学习

本项目帮助 VLN 初学者建立基础知识、阅读重要论文，并逐步进入人形机器人上的语言导航研究。当前阶段是调研和学习，不预设已证实的创新主张。会议、截止日期、硬件和计算预算待用户补充。

## 每次工作先读

1. 本文件。
2. `handoff.md`（建立后）。
3. 开始实验前读 `experiment/evaluation.md` 和 `experiment/results.md`。

## 结构与依据

依据 https://github.com/skJack/research-workflow 的 SKILL.md 和模板，按用户要求调整：不下载论文 PDF 或 LaTeX 源码；每篇保存来源链接和中文笔记，先总结再详细介绍。

| 目录/文件 | 用途 |
|---|---|
| `related_work/` | 入门指南、领域综述、逐篇文献解析、检索记录与索引 |
| `复现/` | 后续 baseline 复现计划与报告 |
| `experiment/` | 预先约定的评测规范和只追加的实验记录 |
| `DataSet/`、`dataset.md` | 数据说明；本次不下载数据 |
| `brainstorm.md` | 待验证问题，复现后才能升级为研究假设 |
| `handoff.md` | 已完成内容、限制、下一步 |

## 写作与研究规范

- 中文解释，保留标准英文名和缩写：VLN、VLN-CE、ObjectNav、PointNav、VLM、VLA、SR、SPL、nDTW、sim-to-real、locomotion。
- 区分经典指令跟随 VLN、目标物体导航、视觉导航、人形运动控制。相关工作不自动等于人形 VLN。
- 逐篇标注资料范围（摘要/项目页/论文 HTML/官方代码），不把摘要阅读写成全文精读。
- 事实与自己的分析、迁移设想分开。只记录已查证的量化结果；不同数据划分、输入和动作空间的分数不能直接比较。
- 优先引用论文和作者官方项目/代码；附可点击来源。首次提交年份与正式发表年份要区分，未核实的会议信息不猜测。
- 原有文件不可无故覆盖。每版实验命名并保存失败结果，不虚构已完成复现、数据下载或实机验证。
- 先复现 baseline，再建立研究假设；评测划分按场景/楼宇隔离，防止数据泄漏；实验结果只追加。
- 本次仅进行调研和计划，禁止自动安装大型环境、训练、下载论文和数据。
